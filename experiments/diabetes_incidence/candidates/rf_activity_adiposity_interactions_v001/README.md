# rf_activity_adiposity_interactions_v001

- 담당자: 양준혁
- 상태: 연구용, 운영 미승인

## 실험 가설

현재 RF가 원변수만으로 충분히 포착하지 못한 운동량·비활동과 BMI의 결합을 명시하면
Recall 0.80 조건에서 Specificity 또는 순위 지표가 개선될 수 있다.

## 사용 데이터와 입력 변수

- 데이터 버전: `official_v1`
- 분할 버전: `pid_group_70_15_15_stratified_any_event_rs42_v1`
- 입력 특성 스키마: `klosa_stage3_25_plus_activity_adiposity_interactions_v1`
- 공통 입력: 현재 RF와 동일한 t0 25개 변수

## 제외 변수와 제외 이유

- 미래 시점 변수: 데이터 누수 방지
- 당뇨 진단·치료 변수: 정답 직접 노출 방지
- PID·가구 ID·target: 모델 입력 제외
- 운동 응답 일관성 flag: 완전 응답 51,790행 중 불일치가 0건이라 제외
- 파생변수는 같은 행의 t0 값만 사용하며 모집단 통계를 학습하지 않음

## 모델과 하이퍼파라미터

공통 모델은 현재 비가중 RF(500 trees, depth 8, minimum leaf 20, `sqrt`)다.

파생변수:

- `weekly_exercise_minutes`: 운동일×회당 운동시간, 분/주
- `log1p_weekly_exercise_minutes`: 주간 운동량의 `log(1+x)` 변환
- `bmi_x_inactivity`: BMI×비규칙적 운동 indicator
- `age_x_inactivity`: 연령×비규칙적 운동 indicator
- `bmi_x_log1p_weekly_exercise_minutes`: BMI×로그 주간 운동량

비교 변형:

- 현재 25개
- 원시 주간 운동량 26개
- 로그 주간 운동량 26개
- BMI·연령×비활동 27개
- 로그 운동량과 상호작용 전체 29개

## 임계값 결정 방법

Train PID 5-fold OOF에서 Recall 0.80 이상 → Specificity → AUPRC → AUROC →
최저 fold Recall → 적은 변수 순으로 변형을 선택한다. 선택 변형만 전체 Train에
재학습하고 숫자 임계값은 Validation Recall 0.80 기준으로 결정한다. Test는 마지막
보고에만 사용한다.

## 한계와 다음 실험

이 결과는 진단이나 처방이 아닌 위험 선별·건강교육 목적의 연구 결과다.

- 주간 운동량은 자기보고 값의 곱이므로 측정오차가 확대될 수 있다.
- RF는 원변수의 비선형 상호작용을 이미 학습할 수 있어 명시적 곱 변수가 중복될 수 있다.
- 기존 Test가 반복 조회됐으므로 외부·시간 기반 검증 전 운영 모델로 사용하지 않는다.
- RF가 원래 학습할 수 있는 상호작용을 중복 표현하면서 표본별 분할이 불안정해졌을
  가능성이 있다. 다음 후보에서는 이 변수를 추가하지 않고 원 운동변수 일부를 대체하는
  축약 비교가 필요하다.
