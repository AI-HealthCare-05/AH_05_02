# rf_missing_weekly_comorbidity_v001

- 담당자: 양준혁
- 상태: 연구용 피처 엔지니어링 비교, 운영 미승인

## 실험 가설

현재 최고 RF 25변수에서 범주형 결측을 독립 범주로 보존하고 운동량·질환 요약을 추가하면 Validation Recall 0.80 조건에서 Specificity가 개선되는지 확인한다.

## 사용 데이터와 입력 변수

- 데이터: `official_v1`
- 분할: `pid_group_70_15_15_stratified_any_event_rs42_v1`
- 대조군: 현재 RF 25변수, 최빈값 범주 대치
- 비교군: missing 범주 25개 / 주간 운동량 포함 26개 / 질환 요약 포함 27개 / 전체 28개

## 파생변수

- `weekly_exercise_minutes`: 주당 운동일 × 회당 운동시간, 분/주
- `comorbidity_count`: 8개 기저질환의 명시적 `yes` 개수. 하나라도 결측이면 결측 유지
- `cardiovascular_comorbidity_any`: 고혈압·심장질환·뇌혈관질환 중 하나라도 `yes`이면 `yes`; 모두 명시적 `no`일 때만 `no`
- 범주형 결측: 최빈값에 합치지 않고 `__MISSING__` one-hot 범주로 보존

## 모델과 평가

- 비가중 Random Forest 500 trees, depth 8, minimum leaf 20, `max_features=sqrt`, random state 42
- 모든 전처리 학습은 Train에 한정
- 임계값은 각 변형 Validation에서 Recall 0.80 이상을 만족하는 최고 Specificity로 결정
- 변형 선택은 Validation Specificity, AUPRC, 적은 변수 수 순이며 Test 확인 전에 완료
- Test는 사전 지정한 다섯 변형의 마지막 보고에만 사용
