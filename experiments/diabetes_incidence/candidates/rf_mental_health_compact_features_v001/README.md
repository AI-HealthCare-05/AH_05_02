# rf_mental_health_compact_features_v001

- 담당자: 양준혁
- 상태: 연구용, 운영 미승인

## 실험 가설

상관성이 높은 만족도 3종과 우울·수면 빈도를 행 단위 요약으로 축약하면 정보 중복을
줄이면서 Recall 0.80 조건의 Specificity와 fold 안정성을 개선할 수 있다.

## 사용 데이터와 입력 변수

- 데이터 버전: `official_v1`
- 분할 버전: `pid_group_70_15_15_stratified_any_event_rs42_v1`
- 입력 특성 스키마: `klosa_stage3_mental_health_compact_variants_v1`
- 공통 코호트와 비정신건강 입력: 현재 RF와 동일

## 제외 변수와 제외 이유

- 미래 시점 변수: 데이터 누수 방지
- 당뇨 진단·치료 변수: 정답 직접 노출 방지
- PID·가구 ID·target: 모델 입력 제외
- 직접 스트레스·인지: pooled 전 차수의 공통 정의가 확인되지 않아 제외
- 결측 증상 코드는 0점으로 처리하지 않고 결측을 유지

## 모델과 하이퍼파라미터

공통 모델은 현재 비가중 RF(500 trees, depth 8, minimum leaf 20, `sqrt`)다.

축약 피처:

- `wellbeing_mean_score`: 건강·경제·삶의 질 만족도 평균
- `wellbeing_range_score`: 만족도 3종의 최대-최소 범위
- `mental_symptom_burden_score`: 우울·수면 빈도 0~3점의 합, 0~6
- `frequent_mental_symptom_count`: 3일 이상 증상 항목 수, 0~2
- `wellbeing_deficit_x_mental_symptom_burden`: `(100-평균 만족도)×증상 부담`

원자료 코드 방향은 `code_1` 하루 미만, `code_2` 1~2일, `code_3` 3~4일,
`code_4` 5~7일로 확인했다.

비교 변형은 현재 25개, 만족도 축약 추가 27개, 증상 축약 추가 27개, 전체 축약
추가 29개, 원 정신건강 5개를 핵심 축약 4개로 대체한 24개, 상호작용까지 대체한
25개다.

## 임계값 결정 방법

Train PID 5-fold OOF에서 Recall 0.80 이상 → Specificity → AUPRC → AUROC →
최저 fold Recall → 적은 변수 순으로 변형을 선택한다. 선택 변형만 전체 Train에
재학습하고 숫자 임계값은 Validation Recall 0.80 기준으로 결정한다. Test는 마지막
보고에만 사용한다.

Train PID OOF는 현재 25개 원변수를 선택했다. 만족도 요약과 증상 요약을 추가하면
정보 중복이 늘어 Specificity와 순위 지표가 대체로 낮아졌다. 5개 원변수를 4개 핵심
요약으로 대체한 24개 모델은 AUPRC가 0.00025 높았지만 Specificity가 0.66%p,
AUROC가 0.0013 낮아 선택되지 않았다. 상호작용까지 사용한 대체형은 Specificity가
1.64%p 낮아 가장 불리했다.

최종 선택이 대조군이므로 Validation 임계값과 Test 성능은 현재 RF를 그대로 재현했다.

둔다.

## 한계와 다음 실험

이 결과는 진단이나 처방이 아닌 위험 선별·건강교육 목적의 연구 결과다.

- 만족도와 증상 빈도는 자기보고이며 임상적 정신건강 진단으로 해석하지 않는다.
- 행 단위 축약은 서로 다른 만족도 영역의 차이를 숨길 수 있다.
- 기존 Test가 반복 조회됐으므로 외부·시간 기반 검증 전 운영 모델로 사용하지 않는다.
- 만족도 3영역과 증상 빈도의 세부 범주가 당뇨 위험과 서로 다른 방식으로 연결될 수
  있어 단순 평균·합계가 유효 정보를 제거했을 가능성이 있다.
