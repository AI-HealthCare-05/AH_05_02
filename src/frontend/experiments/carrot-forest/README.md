# 당근의 숲 아이디어 검증용 데모

`당근의 숲`은 간당간당 메인 MVP와 분리된 선택형 게이미피케이션 패키지의 구현 가능성을 확인하는 독립 프론트엔드 데모입니다.

## 실행

저장소 루트에서 다음 명령을 실행합니다.

```bash
python -m http.server 4173 --directory src/frontend/experiments/carrot-forest
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

Node.js나 `npm install`은 필요하지 않습니다.

## 확인할 수 있는 기능

- 가족·친구 5명의 공동 챌린지 진행도
- 개인 일일 퀘스트 3개 완료
- 무료 당근 보물상자와 아이템 획득
- 아바타 의상·헤어·액세서리 변경
- 당근을 사용한 공동 숲 오브젝트 배치
- 새로고침 후에도 유지되는 로컬 데모 상태
- 공동 챌린지 완료 현황

## 메인 MVP와의 분리

- 기존 `src/frontend/index.html`, `app.js`, `styles.css`를 import하거나 수정하지 않습니다.
- API·DB·인증 없이 브라우저 `localStorage`만 사용하는 아이디어 데모입니다.
- 핵심 예측 화면과 분리된 선택 기능입니다.
- 팀 논의에서 채택되기 전까지 정식 요구사항이나 운영 기능으로 간주하지 않습니다.

## 정식 채택 시 필요한 후속 작업

- `FamilyGroup`, `GroupMember`, `UserAvatar`, `AvatarItem`, `UserInventory` 엔터티
- 챌린지 완료 이벤트 기반 보상 API
- 그룹 초대·탈퇴·권한·개인정보 동의 정책
- 이미지 에셋 저작권 및 디자인 시스템 검토
- 보상·인벤토리 운영 정책
- 접근성·모바일·성능 테스트
