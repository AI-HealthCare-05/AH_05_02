# 작업 창구 3/5 — 서비스 화면

## 목적

사용자가 직접 이용하는 메인 서비스와 당근의 숲 확장 기능의 화면 변경을 한 곳에서 추적한다.

## 담당과 브랜치

- 담당: 이수인 (`in2su-code`)
- 브랜치: `codex/latest-frontend-release-20260914`
- 병합 대상: `develop`
- 선행 작업: PR #56·PR #58

## 포함 범위

- 회원가입·로그인·동의
- 적합성·응급증상 확인
- 건강정보 설문·검진표·웨어러블 불러오기
- 오늘이·내일이·모레노 결과 화면
- XAI 위험·보호요인 설명
- 대시보드
- 생활습관 챌린지·사진 인증
- 건강교육·퀴즈
- 주간·4주·전체 리포트
- 가까운 의료기관·건강도구
- 가족·친구 함께하기
- **당근의 숲 확장팩**
  - 아바타·재화·인벤토리·상점
  - 공동 챌린지·보상
  - 숲 꾸미기·오브젝트 배치
- 반응형·고령층 접근성·오류·대기 화면

## 작업 규칙

- 공통 스타일은 디자인 토큰과 공통 CSS로 관리한다.
- 위험 단계는 색상뿐 아니라 텍스트와 아이콘으로 표현한다.
- 예시·연구·미승인 결과를 실제 결과처럼 표시하지 않는다.
- 화면 변경 시 현재 UX 기준 테스트와 API 계약을 함께 확인한다.
- 건강정보와 예측 결과는 가족·친구에게 기본 공유하지 않는다.
