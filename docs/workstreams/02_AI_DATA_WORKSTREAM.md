## 포함 범위

- **오늘이**: 현재 당뇨 신호 선별
- **내일이**: 미래 당뇨 신규 발병 위험 예측
- **모레노**: 이산시간 생존분석 기반 연령별 발병 위험 전망
  - 연구·선택 기능이면 운영 모델과 구분
- **XAI**: SHAP 기반 주요 영향요인 및 결과 설명
- **Vision AI**: 식단 사진의 채소 포함 여부·시각적 비율 판별
- **건강검진 OCR**: Clova OCR 결과의 건강정보 구조화
- 국민건강영양조사 KNHANES·고령화연구패널조사 KLoSA
- 공통 전처리·결측 처리·데이터 누수 방지
- 임계값·Recall·Specificity·PPV·NPV·Positive Rate 평가
- Model Artifact·버전·입력 스키마·Model Registry
- Apple Health·Android Health Connect 데이터 정제

## 작업 규칙

- 원본 의료 데이터와 대용량 모델은 Git에 커밋하지 않는다.
- 데이터 분리 전 전체 데이터로 전처리 통계를 학습하지 않는다.
- 정답을 직접 결정하는 변수를 입력에 사용하지 않는다.
- 모델 변경 시 설정·재현 명령·평가표·테스트를 함께 수정한다.
- 결과는 진단·처방이 아닌 위험 신호 선별로 표현한다.
