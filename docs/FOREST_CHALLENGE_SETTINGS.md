# 오늘 할 일 설정 연결과 쉬운 안내 (v139)

- 로그인 만료/미로그인 상태에서 저장할 수 없는 설정 폼을 보여주던 문제를 수정했다. 대신 ‘로그인하고 챌린지 설정하기’를 표시한다.
- 고정된 `/?returnTo=forest-challenges` 경로로 가입·로그인과 건강정보 동의/이용 확인을 연결한다. 이용 가능한 경우 숲 설정으로 복귀한다. 기진단·긴급 증상·미동의·미성년 제외는 유지하며 임의 외부 주소로 이동하지 않는다.
- 로그인한 사용자는 ‘챌린지 설정’ 버튼으로 폼을 열고 닫는다. 폼을 다시 생성하지 않아 수정 중 값이 유지된다. 설정 중 탭 복귀/다른 창 알림으로 입력을 덮어쓰지 않는다.
- 사진 담당자 확인, 보관 기간(최대 7일), 동의 철회 시 삭제, 외부 자동 분석 서비스 미전송, 진단·처방 아님 안내는 유지한다. AI/T1/V2 등 구현 용어와 개발용 API 설명을 쉬운 표현으로 바꿨다.
- 숲의 지역 저장 기록과 계정 챌린지를 임의 합치거나 인증을 우회하지 않는다. 예측 모델 연결, 메인 일반 가입 흐름과 주간 리포트 개편은 이 변경 범위가 아니다.
- 공통 모듈 2.1.2, 메인 진입 스크립트 v22, 숲 스크립트 89, PWA v139로 캐시 갱신.

검증: `node --test tests/challenge-settings.test.cjs` 5개 통과, JavaScript syntax check 통과, 관련 Python 회귀 85개 통과. 별도 가상 계정에서 로그인 후 숲으로 자동 복귀, 설정 열기·닫기 중 입력 유지, 식사 횟수 변경 저장(200 응답) 및 재접속 후 저장값 유지 확인. 실제 사용자 계정/기록은 변경하지 않았다.
