# 오브젝트 잘림과 움직임 정리 (v151)

## 원인과 변경

- v4 보관함 아틀라스의 등불·꽃수레·화분·버섯·벤치·물뿌리개 6칸 안에 이웃 그림 조각이 포함되어 있었다. `forest-objects.js`의 검증된 영역을 공통으로 사용해 창고·배치 프리뷰·Phaser에서 같은 결과를 그린다. 기존 본체의 좌표·축척은 유지한다.
- v2 애니메이션 원본은 그림 경계가 128px 격자와 다르다. 분수·반딧불 랜턴·바람개비의 실제 전체 경계를 추출하여 동일한 기준선의 128px 프레임으로 렌더링한다.
- 오리의 물·돌·풀 배경을 제거한 독립 RGBA 누끼를 사용한다. 가로 이동·회전·크기 변화를 없애고 수직 움직임을 ±0.45 월드 픽셀로 제한한다.
- 분수·랜턴·바람개비의 받침은 첫 장면으로 고정한다. 물빛과 반딧불만 1px 미만으로 움직인다. 바람개비 날개는 분리된 레이어로 36초에 한 바퀴 회전한다.
- 모닥불은 불 뒤에 가려진 부분까지 복원한 하나의 돌·장작·재 받침을 켜짐/꺼짐 양쪽에 공통 사용한다. 켰을 때 원본 불꽃만 덧그리며, 256px 투명 여백·94px 표시 크기·기준점을 동일하게 유지한다. 예전 작은 OFF 이미지는 더 이상 불러오지 않는다.
- 젖소는 `setDisplaySize` 후 `setScale(1)`이 적용되어 커지던 문제를 수정했다. 원래 표시 축척을 기억하고 바닥은 고정, 몸만 작게 움직인다.

## 이미지 편집 기록

내장 ImageGen 편집 모드를 사용했다. 실제 알파 채널을 확인했고 생성 결과는 아래 프로젝트 자산으로 복사했다. 원본은 보존한다.

- `src/frontend/assets/carrot-forest-duck-cutout-v1.png`
  - 최종 프롬프트: 기존 애니메이션 시트 첫 칸의 노란 오리 튜브만 추출. 물·돌·풀·꽃 및 다른 프레임을 제거하고, 원래 방향과 스타일을 유지한 실제 투명 RGBA 누끼로 출력.
- `src/frontend/assets/carrot-forest-campfire-base-v5.png`
  - 최종 프롬프트: 기존 모닥불과 같은 낮은 타원형 돌·짧은 장작을 유지하고 불꽃 대신 숯·재와 가려진 뒤쪽 돌을 복원. 체크무늬 배경을 제거한 실제 투명 RGBA 누끼로 출력. 불꽃·연기·추가 장식 없음.

## 회귀 검증

- `node --test tests/forest-*.test.cjs`
- `.venv\Scripts\python.exe -m pytest tests/test_carrot_forest_pixel_game.py -q`
- 실제 PNG 픽셀 경계 테스트, 고정 받침·느린 이동·모션 감소 설정·젖소 축척 테스트.
- 창고 썸네일과 필드의 동일 소스 사용, 오리 알파, 모닥불 공유 받침 및 자산 캐시 연결 검사.

실행 결과: Node 58개 + Python 56개, 총 114개 통과. 실제 브라우저에서 24종 비교 렌더링, 모닥불 클릭 ON/OFF, 임시 배치한 바람개비 날개 회전, 연못 위 오리 투명 프리뷰를 확인했다. JavaScript 오류·경고 없음. 검증용 바람개비는 창고로 반환하고 오리 배치는 취소했으며 기존 모닥불·등불 ON 상태를 복원했다. 날씨 서비스의 기존 연결 대기 상태는 이번 그래픽 수정과 별개다.

보관된 코디·배치 좌표·회전·상호작용 ON/OFF 상태는 마이그레이션하거나 초기화하지 않는다.
