# 모닥불 불꽃 움직임 (v140)

- 기존 모닥불 그림의 밝은 불꽃 부분에만 위로 갈수록 커지는 좌우 물결과 약한 높이 변화를 적용한다. 돌·장작 아래쪽 픽셀과 오브젝트 위치는 고정한다.
- 원본 PNG와 창고 썸네일은 변경하지 않는다. 페이지 시작 시 원본 타일에서 16프레임을 한 번 만들고 공유하여 초당 12프레임으로 재생한다. 매 프레임 이미지 처리나 추가 다운로드는 없다.
- 클릭/Q로 켰을 때만 재생한다. 끄면 정지하고 기존 재가 남은 그림으로 전환한다. 낮/밤과 날씨·시간 효과 OFF에서도 불꽃은 움직인다.
- 기기의 움직임 줄이기 설정에서는 정지 프레임을 사용한다. 모닥불마다 시작 프레임을 달리하여 일제히 같은 모양으로 움직이지 않게 한다.
- 검증: 불꽃 픽셀 변화, 바닥 고정, 원본 불변, ON/OFF·움직임 줄이기 테스트와 JavaScript 문법 및 기존 숲 회귀 검사.
