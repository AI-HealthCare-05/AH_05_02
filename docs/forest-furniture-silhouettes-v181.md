# 가구 잘림 및 정렬 복구 (v181)

- v4 시트는 우편함·허수아비·당근 상자 등의 위쪽 픽셀 자체가 누락됐으며 숲등불은 셀 안에서 왼쪽에 치우쳐 있다.
- 숲등불, 우편함, 허수아비, 당근 상자, 손수레는 온전한 v3 원본 셀을 각각 분리해 사용한다.
- 알파 영역을 기준으로 중앙·하단 정렬 및 12px 여백을 적용한다. 128px 샘플을 최근접 확대해 기존 필드와 픽셀 밀도를 맞춘다.
- 원본의 나무 갈색, 잎 초록, 당근 주황 팔레트를 유지한다. 나머지 가구와 기존 모닥불·분수 효과는 유지한다.
- 창고 썸네일과 배치한 가구가 같은 복구 아틀라스를 사용하며 기존 오브젝트 ID와 저장 위치를 유지한다.
- 실제 PNG 회귀 테스트에서 다섯 항목의 전체 윤곽, 상하좌우 여백, 중앙 정렬, 원본 셀 분리와 캐시 일치를 검사한다.
