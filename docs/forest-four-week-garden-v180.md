# 당근밭 4주 구성 (v180)

- 주차를 1~4주차로 표시하고 현재 1주차에만 당근 5개를 심는다. 2~4주차는 표지판과 빈 밭을 유지한다.
- 당근 표시 크기를 36×40에서 54×60으로 50% 확대하고 주차 간격도 40에서 60으로 넓힌다.
- 표지판과 글씨를 확대하며 중앙 통로와 입구를 가리지 않는다.
- 표시용 당근 수 변경은 챌린지 수행 기록, 회차, 실제 적립·수확 보상에 영향을 주지 않는다.
- 검증: 주차·당근 개수, 빈 주차 유지, 확대 크기, 통로 영역, Canvas/Phaser 일치, 보상 중복 방지 및 캐시 버전 일치.
