# v163 · 몬스터 위 공격 버튼

- 수정 대상은 토끼·쥐에 마우스를 올렸을 때 나타나는 필드 공격 버튼이다. 좌하단 조작 패널의 공격 버튼 디자인·배치는 변경하지 않는다.
- 주황·코랄색 입체 버튼, 크림색 글자, 선명한 검 아이콘과 몬스터를 가리키는 작은 표시를 사용한다. 검은 코드로 그려 기기별 이모지 모양에 영향을 받지 않는다.
- 버튼 위에 마우스를 올리면 밝은 테두리와 은은한 외곽 강조가 나타난다. 누르면 버튼 표면만 낮아지며, 자동 접근 중에는 초록색과 `접근 중…` 문구로 진행 상태를 구분한다.
- 표면 반응 때문에 클릭 영역이 흔들리지 않도록 텍스트의 112×38 영역과 기준 위치를 고정한다. 동작 줄이기 설정에서는 표면 이동 없이 색 변화만 사용한다.
- 확대 화면에서는 전체 맵이 아니라 현재 카메라에 보이는 범위 안으로 버튼을 보정한다. 매우 좁은 세로 화면에서는 글자·배경을 같은 비율로 줄이며, 확대를 해제하면 원래 크기로 돌아온다. 이동 한 프레임과 외곽 강조·아래쪽 표시까지 포함한 여백을 확보한다.
- 몬스터에서 버튼으로 마우스를 옮길 때의 유예 시간, 모바일 터치, 자동 접근 후 장착 무기 공격, 배치·실내·모달 중 비활성 처리를 유지한다.
- v162의 토끼 당근 +1 / 쥐 보상 없음과 결과 알림은 그대로 유지한다.

관련 검사: `forest-pointer-controls.test.cjs`, `forest-catch-reward.test.cjs`, `forest-rabbit-behavior.test.cjs`, 전체 숲 회귀 검사.
