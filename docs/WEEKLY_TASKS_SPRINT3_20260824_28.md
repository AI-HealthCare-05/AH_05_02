# Sprint 3 Weekly Tasks (8월 24일~28일)

# Weekly Objective

- 월요일에 완성한 실행 가능한 MVP를 이번 주 개발 기준선으로 고정한다.
- KLoSA 당뇨병 미래발병 모델 실험을 공통 구조로 재현하고 실제 웹 추론 계약에 연결한다.
- `건강정보 입력 → 비동기 예측 → 결과 안내 → 챌린지 → 대시보드` 흐름을 실제 API·DB 기반으로 통합한다.

- Docker 환경에서 핵심 E2E 흐름과 오류·재시도·접근성 QA를 완료한다.

# 금요일 완료 기준

- 실제 모델 또는 승인 전 개발 후보가 동일한 Provider 계약으로 교체 가능하다.
- 모델 버전·특성 스키마·임계값 버전이 예측 결과와 함께 추적된다.
- 정상·부적합·기진단·실패·시간초과 흐름이 문서와 화면에서 일치한다.
- Docker 환경에서 핵심 E2E 시나리오가 재현된다.
- 데이터·모델 바이너리·비밀정보가 Git에 포함되지 않는다.
- 테스트·리더보드·모델 카드·API 문서·릴리즈 노트가 최신 상태다.
