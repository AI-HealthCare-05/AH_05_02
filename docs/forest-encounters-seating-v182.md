# 쥐·토끼 생성과 앉기 (v182)

- 숲 입장 후 쥐 생성 간격은 60초. 토끼 생성과 독립적으로 계산하며 누적 쥐 8마리에서는 추가 생성을 연기한다.
- 쥐 등장 18초 후 이동을 멈추고 기존 꼬리 프레임을 반복한다. 개별 클릭·키보드·펫 사냥 판정은 유지한다.
- 멈춘 쥐가 남아 있는 동안 `쥐가 당근을 노리고 있습니다.` 경고를 표시하고 모두 잡으면 해제한다. 당근 차감은 추가하지 않는다.
- 토끼는 10~15초 머물며 사라지거나 잡힌 뒤 약 2~4초 후 다시 등장한다.
- 조작 패드의 탈것 자리를 `앉기 (X)`로 교체한다. 다시 누르면 `일어서기 (X)`로 토글되며 E 키의 기존 탈것 기능은 유지한다.
- 원본 앉기 시트가 있는 코디는 마지막 앉기 프레임을 고정한다. 전체 코디에 공통 앉기 시트가 없으면 공통 정지 프레임의 몸과 옷을 함께 낮추는 대체 자세를 사용한다.
- 프리셋 1~6의 실제 자산 목록으로 앉기/서기 렌더를 검증한다.
