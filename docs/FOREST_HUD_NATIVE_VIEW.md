# 당근의 숲: 원본 비율 화면과 포인터 조작

2026-09-07 · HUD v150

## 변경

- 기본 게임 표시 크기는 Phaser의 원래 월드 크기인 768×512입니다. 창이 좁으면 3:2 비율을 유지해 축소합니다. CSS로 가로·세로를 각각 강제 늘리던 설정을 제거했습니다.
- `− / +`는 25% 단계로 25–150% 범위의 표시 배율을 선택합니다. 공간이 부족하면 잘리지 않도록 맞춰 표시하고 실제 표시 배율을 보여줍니다. 공간 상한에서는 확대 버튼을 비활성화하고, 축소는 실제 표시 배율에서 다음 단계로 이동합니다(71→50%, 45→25%).
- UI는 왼쪽 아바타·옷장·창고, 오른쪽 조작기·배치한 오브젝트·할 일로 분리합니다. 작은 화면에서는 게임 아래로 배치합니다.
- UI 숨기기/보이기와 조작기·오브젝트 개별 숨기기/보이기를 제공합니다. 숨겨도 UI 복원 및 크기 조절은 가능합니다.
- 숲 이름 옆 연필로 최대 24글자 이름을 저장합니다. 해당 브라우저의 localStorage에 저장하며, 집/당근밭의 장면 이름은 유지합니다. 서버 공동 모임 이름 변경은 포함하지 않습니다.
- 기존 숲 채팅을 제목과 같은 상단 가로 바에 옮겼습니다. 메시지는 기존처럼 현재 브라우저의 대화 표시이며 실시간 다중 사용자 채팅 서버를 새로 연결하지 않았습니다.
- 빈 필드를 좌클릭/터치하면 기존 통행 가능 영역을 따라 이동합니다. 집·밭·연못·가구·펫 상호작용 및 배치 모드는 기존 클릭 동작을 유지합니다.
- 쥐에 마우스를 올리면 근처에 공격 버튼을 표시합니다. 터치는 쥐 탭 → 공격 버튼 탭 순서입니다. 멀면 접근한 뒤 장착 무기의 기존 모션으로 한 번 공격합니다.
- 키보드 이동은 클릭 이동을 취소합니다. 모달/배치/장면 전환에서는 예약 이동과 공격을 취소합니다. 최종 도착 좌표도 저장합니다.

## 토끼 디자인 후보 (미교체)

추천은 [Redshrike LPC Rabbit](https://opengameart.org/content/bunny-rabbit-lpc-style-for-pixelfarm)입니다. 흰 토끼의 4방향 깡충 이동·풀 뜯기 동작이 제공되고, [표준 방향·격자 재정렬판](https://opengameart.org/content/reorganised-lpc-rabbit)이 있어 현재 LPC 캐릭터와 조합하기 좋습니다. 무료이며 CC-BY 3.0을 선택하면 원저자·출처·라이선스·변경 여부 표시 조건으로 상업적 사용/수정이 가능합니다. 아직 쥐 스프라이트는 교체하지 않았습니다.

대안: [Last tick 32×32 Bunnies](https://last-tick.itch.io/32x32-pixel-bunnies-animated-npc)는 둥근 회색 토끼이며 상업/비상업 사용을 허용하는 무료 팩입니다. 원본 에셋 재배포/재판매/재포장은 금지되어 있습니다.

## 검증

- Node 회귀 테스트: 숲 HUD, 클릭 경로/공격, 기존 모션·달리기·프리셋·날씨 등 39개 통과.
- Python 게임 통합/자산 계약 테스트: 55개 통과.
- 실제 브라우저: 이름 저장, 100% → 75%(576×384), 전체 UI 및 개별 패널 숨김/복원, 빈 필드 클릭 이동 확인.
- 390×844 모바일과 1024×768 화면에서 캔버스 3:2와 가로 넘침 없음, 상단 채팅 정렬 및 양옆 UI 겹침 없음 확인.
