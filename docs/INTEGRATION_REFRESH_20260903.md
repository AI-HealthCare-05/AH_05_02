- #23/#32 최신 코드에서는 고정 좌표 자동 대체가 제거되어 주소 직접 입력으로 전환된다.
- 넥스트러너스 대체 검색은 팀장이 지정한 시연 요구사항이다. 이를 일반 오류로 취급하지 않는다. 다만 이번 통합에서는 팀원 최신 구현을 유지했고 자동 대체를 복원하지 않았다. 시연 시 확정된 장소 주소를 직접 입력할 수 있다.

- 모델 바이너리를 새로 학습·업로드하거나 운영 승인을 변경하지 않았다.
