- 실제 모델은 버전·특성 스키마·임계값 버전을 가진 교체 가능한 계약으로 이식하기로 했다.

## 확인된 불일치

- 정식 FastAPI 앱은 `/api/v1/ai-jobs`, 확정 API와 프로토타입은 `/api/v1/prediction-jobs`를 사용한다.
- 정식 앱은 `queued/running/completed/failed`, 문서는 `queued/running/succeeded/failed`를 사용한다.
- 프로토타입 mock은 정상·전당뇨·검사권고 3단계 확률을 노출하지만, 확정 모델 목적은 미래 발병 이진분류이다.
- 프로토타입 입력항목과 KLoSA 운영 후보의 특성 계약이 완전히 일치하지 않는다.
- 모델 후보에서는 위험요인 설명이 아직 구현되지 않았으므로 SHAP 결과처럼 표시하면 안 된다.
