# MVP 재연결 기록 (2026-09-10)

## 목적

최신 메인 MVP와 당근의 숲 화면을 기준으로 유지하면서, 별도 작업에 있던 웨어러블·건강검진 입력 흐름을 다시 연결한다.

## 통합 기준

- 화면·회원가입·동의 철회·챌린지·당근의 숲: `codex/demo-integration-20260909` 기준 유지
- Apple·Android 웨어러블 정제와 샘플 체험: `codex/wearable-healthcheck-mvp`에서 선별 반영
- 건강검진 결과통보서: 합성 OCR 텍스트의 추출·확인·부분 갱신 흐름 반영
- 사진이나 PDF를 실제로 OCR 처리하는 것처럼 표시하지 않으며, 현재 지원 범위를 `.txt`로 명시
- 원본 웨어러블 파일과 개인정보는 저장하지 않고 사용자가 확인한 요약값만 반영

## 사용자 흐름

### 웨어러블

`건강도구 → Apple/Android 샘플 체험 또는 내보내기 파일 선택 → 일별 요약 확인 → 이 정보로 갱신 → 운동 관련 건강정보와 활동 챌린지 연결`

### 건강검진

`건강도구 → 2025 합성 예시 또는 OCR 처리된 텍스트 선택 → 인식 항목 확인·수정 → 건강정보 부분 갱신`

## 유지한 안전장치

- 건강정보 동의가 철회된 사용자의 신규 건강정보 갱신 차단
- 웨어러블·OCR 후보값 자동 확정 금지
- 신원정보·기기 식별정보 미추출 및 원본 미보관
- 분석 결과는 진단·치료가 아닌 위험 신호 선별과 건강교육으로 표현
- API 실패를 브라우저 저장 성공으로 대체하지 않음

## 검증 기준

- 메인 화면에서 Apple·Android 샘플과 2025 합성 검진 예시를 바로 실행할 수 있다.
- 파일 미리보기와 사용자 확인 후 갱신 API가 정상 동작한다.
- 오늘이·내일이, 회원가입, 동의 철회, 챌린지, 리포트, 당근의 숲의 기존 테스트가 유지된다.
- Python 통합 테스트와 프론트 Node 테스트를 통과한다.
