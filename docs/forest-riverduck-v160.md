# v160 · 리버덕과 회전 바람개비

## 동작

- 기존 `duck_float` 코드와 보관·배치 데이터는 유지하며 화면 이름을 `리버덕`으로 변경한다.
- 연못 왼쪽 수면의 실제 둑·나무 다리 윤곽 안에서 쉬거나 천천히 헤엄친다. 클릭·터치하면 반대 방향으로 약 1.1초 피한다. 공격, 사냥 보상, 켜기/끄기 동작과 연결하지 않는다.
- 이동 좌표는 일시적인 렌더링 상태다. 보관된 배치 좌표를 계속 저장하거나 변경하지 않으며, 다른 설정 저장 시에도 헤엄치던 위치를 유지한다.
- 수면 접촉 영역은 가로 32px, 세로 16px로 검사한다. 기존에 둑 위에 놓인 데이터는 저장값 변경 없이 안전한 수면 위치에서 표시한다.
- 실내, 배치 중, 숨겨진 탭에서는 멈춘다. 동작 줄이기 설정에서는 정지한 오리를 표시한다.
- 정원 바람개비는 받침대·기둥·중앙 축을 고정한 채 분리된 날개만 초당 40도 회전한다. 기존 색상만 바뀌는 방식은 사용하지 않는다. 모닥불·분수 디자인과 동작은 그대로 유지한다.
- 이전 오리 튜브 및 가구 PNG는 복구 가능한 원본으로 보관하고 새 렌더러에서는 튜브를 표시하지 않는다.

## 구현과 검증

`forest-riverduck.js`는 DOM·저장소와 분리한 수면 경계/이동 처리, `forest-riverduck-art.js`는 원본 스프라이트의 프레임 및 미리보기 규격을 공유한다. Phaser와 2D 대체 렌더러 모두 같은 동작 및 그림 규격을 사용한다.

관련 자동 검사: `forest-riverduck.test.cjs`, `forest-riverduck-art.test.cjs`, `forest-pinwheel.test.cjs`, `forest-object-motion.test.cjs`, `forest-placement.test.cjs` 및 기존 숲 회귀 검사. 수면 경계·클릭 반대 방향·시간 간격 제한·동작 줄이기·저장 좌표 보존·받침대 고정·원본 이미지 비수정이 포함된다.

2026-09-08 검증: Node 숲 회귀 검사 234개, Python 게임 검사 56개 통과. 로컬 브라우저에서 창고 아이콘, 연못 격자 배치/확정, 클릭 도주, 바람개비 날개 회전과 받침대 고정, 새로고침 후 배치 유지 확인. 브라우저 error/warn 없음. 기존 분수는 유지한 채 리버덕과 바람개비를 실제 배치하여 확인했다. 반응형 검증용 1440×900 viewport는 확인 후 해제했다.

오리 자산은 [Ulti의 CC0 Duck](https://opengameart.org/content/character-spritesheet-duck)이다. 원본 걷기·달리기 프레임의 몸/날개 변화와 수면 이동을 조합했으며, 물 아래 발은 공통 수면선으로 렌더링할 때만 가린다. 원본 파일은 수정하지 않는다. 출처·저작자·라이선스·SHA-256은 `src/frontend/assets/animals/riverduck-v160/SOURCE.md`를 참조한다.
