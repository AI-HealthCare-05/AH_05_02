# 당근의 숲 일일 반복·필드 정리 v178

## 오늘의 퀘스트

- 설정이 완료된 사용자는 식단·운동·음료 퀘스트를 각각 1개씩, 총 3개 본다.
- 메인 MVP 카탈로그를 종류(음료·식단·운동)와 난이도(쉬움·보통·도전)의 두 축으로 사용한다. 같은 날에는 안정적으로 유지되고, 다음 날에는 같은 조건의 다른 후보가 무작위로 선택될 수 있다.
- 이전 정책으로 저장된 중복 종류 계획은 오늘 조회 시 새 3종 계획으로 교체한다. 기존 배정·기록·보상은 삭제하지 않고 감사 이력으로 보존한다.
- `나에게 맞게 다시 설정하기`의 첫 화면은 `운동 위주`, `식단 위주`, `나만의 챌린지` 세 버튼만 표시한다. 나만의 챌린지에서만 난이도와 각 종류별 세부 행동군을 연다.
- 세 퀘스트를 모두 인증하면 같은 세 퀘스트를 다시 수행할 수 있다.
- 반복 수행은 화면이나 서버의 회차를 늘리지 않는다. MVP 보상만 로컬 당근 수확량에 누적한다.
- 상세 기록과 출처·안전 문구는 기존 데이터 구조를 유지한다.

## 필드와 몬스터

- 모닥불·분수의 현재 연출과 별도 동물 자산은 유지하고, 일반 가구는 당근집 변경 전 `carrot-forest-storage-atlas-v4` 픽셀 원본으로 복구했다. 이후 제작한 `furniture-v153/v156` 일반 가구를 화면에 사용하지 않는다.
- 놓친 쥐는 필드에 남아 누적되고, 토끼는 제한 시간 뒤 사라진 다음 다른 토끼 변형으로 교대한다.
- 몬스터 존재 상태는 Phaser가 전역 상태와 이벤트로 함께 전달한다. 몬스터가 버튼보다 먼저 생성된 경우도 패드 공격 버튼이 노란색으로 강조된다.
- 우리 집·당근 밭·연못의 클릭 판정은 보이는 오브젝트 가까이로 축소했다.

## 아바타와 패널

- 현재 아이템 안내, 피부색 자동 적용 문구, 픽셀 프리뷰 표기, 고양이 출처 카드를 제거했다.
- 펫의 비장착 항목은 `선택 안함`으로 표시한다.
- 좌우 패널 배경은 실제 콘텐츠 높이까지만 유지하고 불필요한 가로 스크롤을 숨겼다.
- 오른쪽 패널의 탭·일일 보상·퀘스트·재설정 버튼은 모두 문서 흐름에 두어 서로 겹치지 않는다.

## 일일 보상

- 일일 보상 버튼을 챌린지 카드 내부가 아닌 오늘 할 일·함께하기 공통 상단에 배치했다.
- 버튼 문구는 `일일 보상 받기`로 통일하고 글자를 키웠다.
- 서버가 세 퀘스트 완료 보상을 확정한 뒤 버튼을 누르면 기존 상자 개봉 음악과 전체 화면 연출을 그대로 사용한다. 서버가 이미 지급한 당근을 로컬에서 중복 지급하지 않는다.
- 하루 한 번만 열 수 있으며 반복 퀘스트 수행 횟수와는 별도로 관리한다.
