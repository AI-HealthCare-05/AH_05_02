## 3. 완료 정의

- 원본 의료 데이터·모델 바이너리·비밀정보가 Git에 포함되지 않는다.
- 실제 모델은 개발 Provider와 같은 입출력 계약을 따른다.
- 모델·특성 스키마·임계값 버전과 artifact checksum을 추적할 수 있다.
- 승인 전에는 개인 발병확률·위험 범주·SHAP 설명을 공개하지 않는다.
- 기진단자는 예측 작업이 생성되지 않고 의료진 지침 우선 안내를 받는다.
- `queued/running/succeeded/failed` 상태와 실패·시간초과 처리가 API·DB·화면에서 일치한다.
- 단위·통합·의료 안전·핵심 E2E 테스트가 통과한다.
