# 오래 머문 쥐의 공격 판정 복구 (v179)

- 원인: 12~18초의 추가 생성 주기 이후 기존 쥐를 표시용 복제본으로 남겨 공격 대상에서 제외했다.
- 기존 쥐의 이벤트 ID와 클릭 영역을 유지하고, 클릭 추적·키보드 공격·펫 사냥에서 함께 조회한다.
- 잡힌 쥐만 제거하고 보상 없이 기존 잡기 알림을 한 번 발생시킨다. 마지막 대상 제거 시 공격 버튼 활성화를 해제한다.
- 최대 8마리에서는 새 생성을 연기한다. 기존 쥐를 임의로 삭제하지 않는다.
- 회귀 검증: 시간 경과 후 개별 클릭 추적, 1시간 경과 후 처치, 최신 대상 없이 키보드 및 펫 처치, 중복 처치 방지, 누적 상한에서 생존 유지.
