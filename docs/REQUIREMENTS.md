# 만성질환 생활습관 챌린지 웹서비스 요구사항 정의서

| 항목 | 내용 |
|---|---|
| 문서 버전 | v0.1 |
| 작성일 | 2026-08-12 |
| 작성 책임 | 정세준(PM·기획·문서·QA) |
| 검토자 | 박빛샘·양준혁·이수인 |
| 상태 | Sprint 1 초안 |

> 본 서비스는 의료진의 진단·처방을 대체하지 않으며, 건강교육과 위험 선별을 목적으로 한다.

## 1. 서비스 정의

### 1-1. 한 문장 소개

65세 이상 사용자의 건강검진 및 생활습관 정보를 바탕으로 당뇨병·고혈압 위험을 선별하고, 생활습관 챌린지와 추적 대시보드를 제공하는 웹서비스이다.

### 1-2. 해결하려는 문제

65세 이상 사용자는 건강검진 결과를 받아도 개별 수치의 의미와 개선 방법을 이해하기 어렵고, 일상적인 행동 변화로 연결하지 못할 수 있다. 서비스는 건강정보를 이해하기 쉬운 위험·보호 요인으로 제시하고, 실행 가능한 생활습관 챌린지와 변화 추적 기능을 제공한다.

### 1-3. 프로젝트 목표

- 당뇨병·고혈압 위험 선별 모델을 서비스로 제공한다.
- 위험·보호 요인을 사용자가 이해할 수 있도록 설명한다.
- 생활습관 챌린지의 선택·수행·기록을 지원한다.
- 재평가 결과와 챌린지 수행률을 대시보드로 제공한다.
- 고위험·부적합 사용자를 검사 또는 의료기관 안내로 연결한다.

## 3. 서비스 범위

### 3-1. MVP 포함

- 회원가입·로그인
- 건강정보 처리 동의
- 서비스 대상자 적합성 확인
- 건강검진·생활습관 정보 입력
- 당뇨병·고혈압 위험 선별
- 위험·보호 요인 제공
- 생활습관 챌린지 추천·선택·기록
- 위험도·생활습관·챌린지 추적 대시보드
- 고위험·부적합 사용자 검사·의료기관 안내
- 고령자 접근성 지원

### 3-2. 축소 검토

- 템플릿 또는 제한된 LLM 기반 결과 설명
- 챌린지 선택 이유와 격려 문구

### 3-3. 제외

- 푸시·문자·이메일 알림 및 `Notification` 엔터티
- 이미지 기반 식단 분석
- 약물 시작·중단·용량 변경 추천
- 진단·처방 또는 의료진 대체 기능

## 4. 기본 사용자 흐름

```text
서비스 소개 → 회원가입·동의 → 적합성 확인
→ 건강검진·생활습관 입력 → 당뇨병·고혈압 위험 결과
→ 위험·보호 요인 → 챌린지 선택 → 일일 기록
→ 추적 대시보드 → 재평가
```

### 4-1. 예외 흐름

- 부적합 사용자: 예측 중단 → 검사·의료기관 안내
- 고위험 사용자: 결과 제공 → 검사 계획·의료기관 방문 권고
- 검진자료 미보유 사용자: 간편 설문 또는 검진 안내 범위 TBD
- 기진단 확인 사용자: 진행 중 챌린지 중단 → 병원 안내 → 과거 기록 보존
