> 본 서비스는 의료진의 진단·처방을 대체하지 않으며, 건강교육과 위험 선별을 목적으로 한다.
>
> 대상·제외 판정, 화면 문구, 금지 표현의 구현 기준은 [서비스 대상·제외 범위 및 의료 안전 문구](SERVICE_SCOPE_AND_SAFETY_COPY.md)를 따른다.

## 1. 서비스 정의

### 1-1. 한 문장 소개

만 40세 이상 당뇨병 미진단자의 건강·생활습관 정보를 바탕으로 미래 당뇨병 발병 위험을 선별하고, 일반 생활습관 챌린지와 추적 대시보드를 제공하는 웹서비스이다.

### 1-2. 해결하려는 문제

40대부터 당뇨병 위험에 대한 관심과 예방 행동의 필요성이 커지지만, 건강정보를 구체적인 행동 변화로 연결하기는 어렵다. 서비스는 미진단 사용자의 미래 발병 위험을 이해하기 쉬운 범주와 위험·보호 요인으로 제시하고, 실행 가능한 일반 건강 챌린지와 수행 추적 기능을 제공한다.

### 1-3. 프로젝트 목표

- 당뇨병 미진단자의 미래 발병 여부를 이진분류하는 모델을 서비스로 제공한다.
- 위험·보호 요인을 사용자가 이해할 수 있도록 설명한다.
- 생활습관 챌린지의 선택·수행·기록을 지원한다.
- 위험 범주와 챌린지 수행률을 대시보드로 제공한다.
- 고위험·부적합 사용자를 검사 또는 의료기관 안내로 연결한다.

### 2-1. 데이터 역할

| 데이터 | 우선 검토 역할 |
|---|---|
| KLoSA | 기준 시점 미진단자와 다음 조사차수 신규 진단을 연결하는 미래 발병 이진분류 후보 |
| 국민건강영양조사 | 타깃 연령 EDA, 생활습관·신체계측 변수 정의, 단면 베이스라인 검증 |

> 두 데이터셋의 행을 직접 결합하지 않는다. 공통 메타데이터로 변수 의미와 단위를 맞추되, 데이터셋별 모델과 평가 결과를 분리한다. 미래 발병 모델의 기준 시점에는 당뇨 기진단자와 타깃을 직접 결정하는 사후 정보를 제외한다.
>
> KLoSA 최초 표본은 2006년 당시 만 45세 이상이므로, KLoSA 단독 모델은 40~44세에 대한 별도 검증 근거가 생기기 전까지 해당 연령의 개인화 예측에 사용하지 않는다.

## 3. 서비스 범위

### 3-1. MVP 포함

- 회원가입·로그인
- 건강정보 처리 동의
- 서비스 대상자 적합성 확인
- 건강검진·생활습관 정보 입력
- 당뇨병 미래 발병 위험 선별
- 위험·보호 요인 제공
- 생활습관 챌린지 추천·선택·기록
- 위험 범주·생활습관·챌린지 추적 대시보드
- 고위험·부적합 사용자 검사·의료기관 안내
- 40대 이상 사용자를 위한 쉬운 문구와 고령자 접근성 지원

### 3-2. 축소 검토

- 검토된 템플릿 기반 결과 설명
- 챌린지 선택 이유와 격려 문구

### 3-3. 제외

- 푸시·문자·이메일 알림 및 `Notification` 엔터티
- 이미지 기반 식단 분석
- 약물 시작·중단·용량 변경 추천
- 진단·처방 또는 의료진 대체 기능
- 고혈압 및 기타 만성질환 예측 모델
- 생성형 AI 또는 RAG가 직접 생성하는 개인별 의료 조언

## 4. 기본 사용자 흐름

```text
서비스 소개 → 회원가입·동의 → 적합성 확인
→ 건강·생활습관 입력 → 당뇨병 미래 발병 위험 범주
→ 위험·보호 요인 → 챌린지 선택 → 일일 기록
→ 추적 대시보드 → 재평가
```

### 4-1. 예외 흐름

- 부적합 사용자: 예측 중단 → 검사·의료기관 안내
- 고위험 사용자: 결과 제공 → 검사 계획·의료기관 방문 권고
- 필수 입력 미보유 사용자: 예측을 실행하지 않고 필요한 항목과 건강검진 안내 제공
- 당뇨병 기진단 사용자: 예측 대상 아님을 안내 → 의료진 지침 우선 안내 → 개인화 기능 진입 차단
