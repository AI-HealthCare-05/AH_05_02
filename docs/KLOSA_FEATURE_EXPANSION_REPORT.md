# KLoSA 입력 변수 선택 확장 실험 보고서

## 결론

- 기존 8개 변수를 기준으로 고혈압 병력, BMI 이력, 건강상태 이력, 식사 이력, 행동 이력과 전체 패널 변화량을 분리해 비교했다.
- 검증 1위는 `기존 8개 + BMI 이력 + 고혈압 병력` 13개 묶음이었다. Recall은 `0.743 → 0.781`로 증가해 사전 설정한 `+0.02` 기준을 통과했다.
- 그러나 동일 임계값의 Test 결과는 Recall `0.718`, Specificity `0.486`으로 최소 Specificity를 통과하지 못했다.
- 검증 Specificity 목표를 0.55로 높이면 Test Specificity는 0.533으로 회복되지만 Recall은 0.667로 기존 8개 모델의 0.692보다 낮아졌다.
- 따라서 이번 확장 모델은 승격하지 않고 기존 8개 모델을 유지한다.
- `기존 8개 + BMI 이력` 12개 묶음은 Test Recall 0.703, Specificity 0.502로 유일하게 최소 기준을 지키며 소폭 개선됐으므로 다음 사전등록 후보로 남긴다.

## 실험 설계

- 타깃: t0 미진단자의 다음 인접 조사 신규 당뇨 진단 여부
- 모델: Logistic Regression + class weight + Sigmoid calibration
- 분할: 기존 PID 그룹 Train/Validation/Test 유지
- 탐색: 9개 변수 묶음 × C 4개 × 5-fold = 180회 적합
- 임계값: Validation에서만 선택하고 Test에 고정 적용
- 전처리: 각 Fold 학습 데이터에서만 결측 대치·스케일링 적합
- 원본 개인 단위 데이터와 모델 바이너리는 Git에 저장하지 않음

## 검증 1위 임계값 안전 여유

| Validation 최소 Specificity 목표 | Test Recall | Test Specificity | Test 양성 판정 비율 |
| ---: | ---: | ---: | ---: |
| 0.50 | 0.718 | 0.486 | 51.9% |
| 0.55 | 0.667 | 0.533 | 47.2% |
| 0.60 | 0.626 | 0.582 | 42.3% |

안전 여유를 높이면 Specificity는 회복하지만 기존 모델보다 Recall이 낮아져 확장 목적을 달성하지 못한다.

## 결정

1. 현재 서비스·연구 후보는 기존 8개 모델을 유지한다.
2. `기존 8개 + BMI 이력`은 다음 확증 실험의 사전등록 후보로 지정한다.
3. BMI 이력은 추가 설문이 아니라 이전 서비스 기록에서 자동 생성한다.
4. 운동 빈도·시간 등 신규 원문항은 전 차수 코드북 검증을 마친 뒤 별도 묶음으로 실험한다.
5. 외부검증 전에는 확장 후보의 개인 발병확률을 노출하지 않는다.
