# 오늘의 퀘스트 간단 보기 (v166)

## 표시 방식

- 당근의 숲에서 챌린지 설정을 마치면 `오늘의 퀘스트` 아래 서버가 배정한 3개 항목을 짧은 카드로 보여준다.
- 각 카드에는 챌린지 이름, 목표/진행 횟수, `인증하기`, `자세히 보기`를 표시한다.
- 설명, 난이도, 안전 안내, 원문 근거, 회차 기록, 사진 제출, 대체 챌린지 기능은 삭제하지 않고 각 항목의 `자세히 보기`에 유지한다.
- 중복 제목, 상시 설정 양식, 길게 표시되던 안내·보상 문구는 초기 목록에서 제외한다. 제목 옆 `설정`으로 기존 설정, 안내, 보상, 생활습관 검색을 다시 볼 수 있다.
- 메인 MVP의 챌린지 설정 화면과 미가입/로그아웃/연결 오류 화면은 기존 흐름을 유지한다. 서버가 아직 당일 과제를 발급하지 않은 경우에는 3개를 임의 생성하지 않고 예정 시작일을 표시한다.

## 인증 및 저장

- `인증하기`는 기존 회차 기록/사진 제출 양식을 열고 입력칸으로 이동한다. 사용자 대신 활동 시간·섭취량·사진·기록을 만들어 보내지 않는다.
- 서버 응답에서 해당 항목이 완료된 경우에만 버튼을 `인증완료`로 변경한다. 사진 검토를 기다리는 항목은 `확인 중`으로 구분한다.
- 기존 기록 API, 동의/안전 조건, 인증·보상 조건은 변경하지 않는다. 실제 계정에 테스트 완료 기록을 남기지 않는다.
- 열어 둔 항목은 새로고침 후에도 유지하며, 인증이 완료된 항목은 자동으로 접는다.

## 검증

- 전용 Node 회귀 테스트는 3개 요약, 자세한 정보 보존, 설정 저장 후 전환, 기존 MVP 호환, 인증 요청과 완료 상태, 로그인/연결 오류를 검증한다.
- 브라우저 표시용 `tests/fixtures/forest-quests-v166.html`은 가상 응답만 사용한다. 실제 계정·API에 기록을 전송하지 않으며 앱 배포 화면에 연결하지 않는다.

### 2026-09-08 결과

- Forest/설정 Node 테스트 318개 및 Python 화면·챌린지 API 테스트 79개 통과. 실패/건너뛰기 없음. Python에는 기존 FastAPI 응답 클래스 지원 종료 예정 경고 3건이 있다.
- 브라우저에서 production CSS/JS를 사용하는 격리 테스트 화면의 330px 패널, 3개 카드, 인증하기/확인 중/인증완료 표시를 확인했다. 인증하기를 누르면 자세한 정보와 회차 입력이 펼쳐지고 수행 시각 입력에 포커스가 이동했다.
- 실제 `/forest?quests=v166` 화면을 불러왔다. 현재 브라우저는 로그아웃 상태이므로 실제 사용자 계정의 인증 기록은 생성하지 않았다. 서버 저장 및 완료 상태 전이는 가상 응답/격리 DB 테스트로 검증했다.
