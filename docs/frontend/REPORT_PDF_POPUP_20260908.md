# 리포트 PDF 기간 선택 팝업 · 2026-09-08

`일자별 해야할일` 작업이 사용하는 8022 프론트에 리포트 PDF 기간 선택 UI를 이식했다.

- `PDF로 받기` 버튼을 누르면 버튼 아래에 280px 너비의 작은 팝업이 겹쳐 표시된다.
- 기간은 이번 주, 지난 4주, 전체 중에서 선택한다.
- 팝업은 바깥 영역 클릭 또는 Esc 입력으로 닫힌다.
- 키보드 포커스와 `aria-expanded`, `aria-controls`, `aria-haspopup` 상태를 함께 제공한다.
- 현재 백엔드 지원 범위를 유지해 실제 PDF 생성은 이번 주만 가능하며, 지난 4주·전체는 연결 준비 안내 후 요청을 보내지 않는다.

원본 프론트 전체를 덮어쓰지 않고 PDF 메뉴의 HTML, CSS, JavaScript 구간만 옮겼다. 팀 최종 색상 변수와 챌린지 화면 변경은 유지했다.
