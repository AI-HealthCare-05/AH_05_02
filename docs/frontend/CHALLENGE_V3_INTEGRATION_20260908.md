# 생활습관 챌린지 V3 — 8022 통합

- 기준: [노션 생활습관 챌린지 V3 개편 및 구현 결과](https://app.notion.com/p/2-3aacaf5650aa80898f5ad3e26fe844af?p=3d5caf5650aa8031ac20cb1e5c4dbbc6&pm=s), [PR 40](https://github.com/AI-HealthCare-05/AH_05_02/pull/40), 원격 `aaeea3b`의 챌린지 변경분.
- 실행 주소: `http://127.0.0.1:8022/`. 새 주소·쿼리 매개변수 없이 통합 프론트에서 사용한다.
- 기존 진행 사이클·일일 기록·보상은 유지하며 새 4주 사이클부터 V3를 적용한다. 기존 사이클을 자동 취소하거나 V3로 바꾸지 않는다.

## 반영 사항

음료·식이섬유 식사·유산소 활동 각 1개를 제안한다. 균형/식단/운동 중점과 쉬움/보통/도전 단계에 따라 식단 1·2·3끼, 운동 누적 10·20·30분을 조합하고 다른 후보 보기로 준비된 후보를 순환한다. 공통 음료 목표는 하루 한 번 개인 수분 지침과 음료 선택을 확인하며 물 섭취량을 늘리는 목표가 아니다.

기존 카드 전체 클릭과 나란한 배치를 유지한다. 완료 카드는 재저장 없는 확인 창을 연다. 진행 중인 사이클은 선택 완료 화면을 거치지 않고 기록 화면으로 이동하고, 사이클이 없으면 오늘 기록하기에서 빈 상태와 선택 이동 버튼을 보여준다. 일일 카드에 간편 체크/사진 인증 배지와 이 습관 살펴보기를 다시 추가하지 않았다.

사진형은 실제 파일 및 자기보고 실천량을 multipart로 제출한다. 1유형은 실제 채소 이미지 검토, 2유형은 유효 사진 제출과 목표량 확인, 3유형은 음료 자가 체크다. 완료는 `challenge_completed === true`와 `review_status === "accepted"`를 모두 확인한다. 사진형 자가 체크 우회와 미리보기의 가짜 사진 인증은 차단한다. 실패는 재시도 가능한 상태로 표시한다.

새 API 계약을 지원하기 위해 카탈로그·추천·사이클 메타데이터·사진 검증 서비스를 함께 반영했다. DB 스키마 변경이나 사용자 데이터 마이그레이션은 없다. Pillow 의존성을 명시했다. 날짜는 챌린지 기록 범위에서 서울 기준을 사용하고 계정/사이클이 바뀐 뒤 도착한 응답은 적용하지 않는다.

## 주 업무 화면 연결 확인

`일자별 해야할일`과 `챌린지 탭 프론트 수정` 작업은 같은 `AH_05_02-s2-api002/src/frontend`를 사용한다. 8022 실행 프로세스의 작업 경로도 동일하다. 별도 사본을 덮어쓰지 않고 공유 파일의 V3 변경과 팀 최종 팔레트를 유지했으며, 기본 index의 JS·CSS 캐시 버전을 `20260908-main-challenge-v3-final`로 갱신했다. 기본 주소와 기존 리포트 확인용 쿼리 주소 모두 같은 프론트를 제공한다.

## 완료 기록 취소 (2026-09-08)

이 작업에서 요청한 챌린지 수정은 앞으로도 `일자별 해야할일`이 사용하는 8022 공유 프론트에 바로 적용한다. 완료 카드를 누르면 기존 확인 버튼 옆에 `오늘 기록 취소하기`가 표시된다. 기존 PUT 로그 API에 서울 기준 오늘의 `is_completed: false`, `value: null`을 저장한 후 카드의 완료 표시와 오늘 집계를 갱신한다. 리포트에도 미완료로 반영되고 카드를 다시 눌러 기록할 수 있다. 완료되지 않은 카드에서는 취소 버튼을 숨긴다. API 실패 시 기존 완료 상태를 유지하고 창 안에서 오류와 재시도 버튼을 제공한다. 계정·사이클 변경 뒤 도착한 응답과 중복 클릭을 방어한다. 기존 사진 인증 이력·과거 날짜 기록·지급된 보상은 삭제하지 않으며 V3 사진형의 재완료는 원래 사진 제출 절차를 따른다.

취소 기능 검증: 완료 카드/V3 Node 테스트 15개, 격리 DB의 음료·사진형 취소 후 재기록 API 테스트 2개 통과. 1440px·380px 브라우저에서 취소 버튼 표시, 완료 해제, 재기록, 기존 흐름을 확인했다. 실제 사용자 기록은 테스트에 사용하지 않았다.
