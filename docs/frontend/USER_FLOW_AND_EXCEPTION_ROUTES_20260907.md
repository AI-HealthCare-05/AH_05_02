# 완료 기준 2 — 정상·예외 상황별 다음 이동 경로

대상: 9/7 로컬 통합 화면 `http://127.0.0.1:8022/`

## 1. 정상 흐름

`시작 → 가입 → 이용 대상 확인 → 건강정보 입력 → 분석 대기 → 결과 → 챌린지 → 대시보드`

| 현재 화면 | 성공 조건 | 다음 화면 |
|---|---|---|
| 시작 | 회원가입 선택 | 회원가입 |
| 회원가입 | 계정 생성·자동 로그인·프로필·건강정보 동의 저장 | 이용 대상 확인 |
| 이용 대상 확인 | 응급·당일 진료·기진단 없음, 연령·동의 조건 충족 | 건강정보 입력 |
| 건강정보 입력 | 필수값 검증 및 건강정보 저장 | 분석 대기 |
| 분석 대기 | 오늘이/내일이 중 사용 가능한 모델 결과 하나 이상 성공 | 결과 |
| 결과 | 안전 안내 확인, 챌린지 이용 가능 | 챌린지 선택 |
| 챌린지 | 하나 이상 선택, 4주 사이클 생성 | 대시보드 |
| 대시보드 | 실천 기록 저장 | 대시보드 유지·리포트 갱신 |

실제 가상 계정으로 위 흐름과 재로그인·건강정보 수정·재분석까지 통과했다.

## 2. 첫 화면 분리

| 사용자 상태 | 로그인 후 첫 화면 |
|---|---|
| 건강정보 없음·이용 대상 확인 없음 | 이용 대상 확인 |
| 건강정보 없음·최근 안전 분기 있음 | 해당 안전 안내 |
| 건강정보 있음·진행 중 챌린지 없음 | 저장 상태에 따라 결과 또는 챌린지 선택 |
| 건강정보 있음·진행 중 챌린지 있음 | 대시보드 |
| 프로필 또는 건강정보 동의 저장 미완료 | 계정 설정 복구 화면 |
| 동의 철회·조회 실패 | 개인화 화면 진입을 보류하고 재확인 안내 |

건강정보가 없는 기존 계정은 빈 대시보드로 보내지 않고 이용 대상 확인으로 이동한다. 건강정보·진행 중 챌린지가 있는 계정은 대시보드를 복원한다.

| 비밀번호 조건 누락 | 8자·대문자·소문자·숫자·특수문자 중 빠진 조건 표시 | 회원가입 유지, 비밀번호 칸 초점 |
| 서비스 약관 미동의 | 필수 동의 안내 | 회원가입 유지 |
| 건강정보 동의 미선택 | 건강정보 동의 필요 팝업 | 회원가입으로 복귀, 동의 칸 초점 |
| 만 14세 미만 | 가입 불가 안내 | 회원가입으로 복귀, 생년월일 칸 초점 |
| 이미 가입된 이메일 | 기존 계정 로그인 안내 | 로그인 |
| 가입 후 자동 로그인 실패 | 계정 중복 생성 방지 복구 안내 | 기존 계정 로그인 후 남은 설정 재개 |
| 프로필 저장 실패 | 입력값 유지·프로필 단계만 재시도 | 계정 설정 복구 |
| 동의 저장 실패/응답 유실 | 저장 상태 확인 후 필요한 단계만 재시도 | 계정 설정 복구 |

주의: 정확히 만 14세가 되는 생일 당일은 서버가 현재 422를 반환하므로 백엔드 경계 수정 전까지 미완료다.

## 4. 이용 대상·의료 안전 분기

| 상황 | 제공하지 않는 기능 | 안내·다음 경로 |
|---|---|---|
| 만 14세 미만 | 가입·개인화 예측·챌린지 | 가입 불가, 일반 공개 정보 |
| 14~18세 | 현재·미래 예측 | 생활습관 챌린지 가능 |
| 19~44세 | 미래 신규 발병 예측 | 오늘이 현재 건강 신호 확인 후 챌린지 |
| 45~105세 | 정책상 허용 시 현재·미래 분석 | 건강정보 입력 |
| 106세 이상 | 미래 신규 발병 예측 | 현재 건강 신호 확인 후 챌린지 |
| 건강정보 동의 없음 | 개인화 분석·챌린지 | 동의 필요 안내, 동의 입력으로 복귀 |
| 긴급 증상 있음/모름 | 모든 개인화 분석·챌린지 | 119 및 응급의료기관 안내. 검색을 기다리게 하지 않음 |
| 당일 진료 증상 있음/모름 | 분석 진행 | 오늘 의료기관 확인 안내 |
| 이미 당뇨 진단 | 신규 발병 예측·일반 챌린지 진입 | 일반 건강정보·의료진 관리 우선 안내 |
| 모델 적용 인구집단 밖 | 해당 모델 결과 | 적용 대상 아님 안내, 허용된 일반 기능 |
| 현재 또는 미래 신호가 높음 | 진단으로 단정하지 않음 | 검사·의료기관 상담 안내를 먼저 표시한 뒤, 서버가 허용한 경우에만 챌린지 |

키보드 경로: 안전 팝업이 열리면 초점이 팝업 안에 머물고, Tab/Shift+Tab 순환, Escape로 닫기, 이전 입력칸으로 복귀한다. 6개 분기를 380px에서 검증했다.

## 5. 건강정보 입력 예외

| 상황 | 처리 | 다음 경로 |
|---|---|---|
| 필수값 누락·범위 오류 | 오류 요약과 첫 오류칸 초점 | 현재 입력 단계 유지 |
| 선택값 모름 | 허용된 선택 항목은 `null`/모름으로 유지 | 다음 입력 단계 |
| 운동 안 함 | 운동 일수·시간 0 처리 | 입력 확인 |
| 건강정보 저장 실패 | 입력값 유지, 오류 표시 | 같은 저장 요청 재시도 |
| 세부 입력 API 404 | 세부 입력 미저장 상태를 분리 안내 | 기본 건강정보 기반 가능한 흐름만 진행; 계약 후 재연결 |
| 저장된 건강정보 수정 | 과거 기록 덮어쓰기 금지 | `reassessment` 새 기록 생성 후 재분석 |

## 6. 분석·결과 상태

| 상태 | 화면 | 다음 경로 |
|---|---|---|
| `queued` | 분석 요청 접수·대기 | 같은 작업 상태 조회 |
| `running` | 분석 중 | 같은 작업 상태 조회 |
| 오늘이·내일이 모두 성공 | 분리된 두 결과 카드 | 의료 안내 또는 챌린지 |
| 하나만 성공 | 성공 결과 유지 + 실패 모델 이름·코드 | 결과 유지, 실패 모델만 재시도 |
| 둘 다 실패 | 입력 보존 실패 화면 | 같은 입력으로 재시도 또는 입력 수정 |
| 제한 시간 초과 | 지연 안내·재시도 | 같은 모델 작업 재확인 |
| 빈 결과·prediction_id 없음 | 성공으로 표시하지 않음 | 재시도 |
| `ML_INPUT_INVALID` | 입력 오류 안내 | 건강정보 입력으로 이동 |
| `MODEL_UNAVAILABLE` | 모델 준비 실패 | 잠시 후 재시도 |
| `MODEL_CONTRACT_INVALID` | 서버·모델 계약 오류 | 사용자 재입력 강요 없이 관리자 확인/재시도 |
| `QUEUE_UNAVAILABLE` | 분석 큐 연결 실패 | 잠시 후 재시도 |
| `display_allowed=false` | 수치·확률·위험요인 숨김 | 승인 대기 안내, 챌린지는 별도 자격 기준 적용 |
| 높은 위험 신호 | ‘당뇨 확정’으로 표현하지 않고 현재/미래 결과를 각각 유지 | 의료 안내 확인 후 허용된 다음 단계 |

오늘이·내일이 성공 여부를 각각 저장하며, 현재 점수와 미래 점수를 평균하거나 하나의 확률로 합치지 않는다. 모레노 연구 결과는 MVP 결과 화면에 넣지 않는다.

## 7. 챌린지 예외

| 상황 | 처리 | 다음 경로 |
|---|---|---|
| 추천·목록 로딩 | 로딩 문구, 시작 버튼 비활성 | 로딩 완료 후 선택 |
| 목록 빈 결과 | 선택 가능 항목 없음 안내 | 재조회 또는 홈 |

| 의료 안내 선확인 필요 | 시작 버튼 차단 | 안내 확인 후 허용 여부 재평가 |
| 선택 없음 | 하나 이상 선택 안내 | 챌린지 화면 유지 |
| `prediction_id` 없음 | 비개인화 목록 요청 가능 | 허용된 일반 챌린지 선택 |
| `prediction_id` 타입 오류 | 문자열 대신 정수 ID만 전송 | 오류 수정 후 재시도 |
| 진행 중 사이클 409 | 중복 생성하지 않음 | 현재 사이클 조회 후 대시보드 |
| 맞춤 챌린지 저장 API 없음 | 선택 내용 유지·준비 중 안내 | 기본 챌린지 선택 |

## 8. 대시보드·리포트 예외

| 상황 | 처리 | 다음 경로 |
|---|---|---|
| 오늘 기록 조회 실패 | 이전 완료 상태를 거짓으로 지우지 않음 | 다시 시도 후 서버 기록 복원 |
| 오늘 기록 저장 실패 | 버튼·선택 복구 | 같은 기록 재시도 |

| 이번 주 PDF 실패/비PDF | 파일 저장 금지, 버튼 복구 | 다시 시도 |
| 4주·전체 선택 | 이번 주 파일로 대체하지 않음 | API 준비 안내 |
| 지도 위치 권한 거부 | 위치 설정 안내, API 호출하지 않음 | 권한 변경 또는 주소 검색 |
| 지도 시간 초과 | 재시도 안내 | 위치 재시도 |
| 기관 결과 없음 | 빈 결과 안내 | 범위/위치 변경 |
| 기관 API 실패 | 목록 실패와 119 안내 분리 | 재시도; 위급 시 119 |

## 9. 세션 만료·오프라인 복구 보완

- 인증된 API 요청이 `401`을 반환하면 만료된 토큰을 제거하고 로그인 화면으로 이동한다.
- 재로그인 후 저장된 건강정보를 다시 조회하고, 분석 중이었다면 기존 `checkup_id`로 분석 재시도를 제공한다.
- 네트워크 오류·시간초과에서는 결과를 만들지 않고 같은 입력으로 재시도한다.
- 저장 전 건강정보는 현재 탭의 `sessionStorage`에 최대 12시간 임시 보관하고 새로고침 후 같은 사용자에게만 복원한다.
- 비밀번호·인증 토큰·이메일은 임시본에 저장하지 않으며, 사용자 ID 불일치 또는 건강정보 저장 성공 시 임시본을 삭제한다.
