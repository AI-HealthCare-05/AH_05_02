# 챌린지 탭 흐름 통합 · 2026-09-08

사용자가 별도 미리보기 포트로 인한 혼동을 이유로 주 업무 화면에 합치기를 요청했다. `challenge-tab-preview-20260908/challenge-flow.patch`의 변경 구간을 현재 프론트에 적용했다. 기존 계정·리포트·건강도구·예측 변경은 유지했다.

## 적용 흐름

- 진행 중인 챌린지: 챌린지 탭에서 선택 완료 화면을 거치지 않고 기록 화면으로 이동.
- 새 챌린지 시작: 기록 화면과 선택 완료 안내 메시지 표시.
- 진행 중인 챌린지가 없을 때 오늘 기록하기: “기록할 챌린지가 없습니다”와 “챌린지 선택하러 가기” 버튼 표시.
- 선택 버튼으로 기존 선택 화면에 진입하며 안전 확인 로직 유지.
- 빈 화면에서는 목표 조정 입력란 숨김. 완료·취소 회차는 오늘 기록 대상에서 제외.
- 기록 화면에서도 상단 챌린지 메뉴 활성 상태 유지.

## 확인 주소와 범위

주 업무 서버: `http://127.0.0.1:8022/`

별도 미리보기의 서버 및 예시 데이터 주입 스크립트는 가져오지 않았다. 프론트 전체를 덮어쓰지 않고 변경 구간만 적용했다. 캐시 갱신을 위해 JS·CSS URL 버전을 갱신했다. GitHub 커밋·푸시는 수행하지 않았다.

## 검증

`node --check src/frontend/app.js`, `git diff --check` 및 `tests/frontend/challenge_flow_qa.cjs`로 검증.

브라우저 검증은 8022에서 데스크톱 1440px·모바일 380px의 빈 상태 → 선택 → 시작 → 기록, 재진입, 완료 상태 유지, 완료·취소 회차 제외, 키보드 접근, 가로 넘침·JS 오류를 확인한다. 기록 복원과 서버 오류 분기는 모의 API 응답으로 확인하며 실제 사용자 데이터는 쓰지 않는다. 스크린샷은 `tmp/challenge-flow-qa/`에 저장한다.

## 기록 버튼 정리

사용자 추가 요청에 따라 기록 카드의 “이 습관 살펴보기” 버튼을 제거했다. 간편 체크 확인창과 물컵 채우기·걷기 완료 모션은 삭제되지 않았으며 유지한다. 8022 화면에서 덜 달게 마시기 → 체크하기 → 오늘 물을 선택하셨나요? 확인창을 직접 확인했다. 완료 모션은 긍정 응답 후 450ms 동안 재생되고 창이 닫히는 기존 동작이다.

## 기록 카드 가로 배치 및 전체 선택

오늘 기록할 항목을 가로 그리드로 배치하고 화면 너비가 좁으면 다음 줄로 배치한다. 별도 체크하기·사진 올리기 버튼을 제거하고 카드 자체를 네이티브 button으로 변경했다. 카드 클릭 또는 Enter/Space로 기존 간편 체크·사진 인증 확인창을 연다. 완료 카드는 오늘 기록 완료 표시와 disabled 상태를 유지한다. 빈 상태·오류 안내는 전체 너비를 사용한다. 건강도구에서 해당 카드로 이동할 때 포커스 대상도 카드 자체로 수정했다.

8022 브라우저에서 세 카드 가로 배치, 물 카드 클릭에 따른 물컵 확인창, 식사 카드 Enter 입력에 따른 사진 인증창 및 좁은 화면의 줄바꿈·가로 넘침 없음을 확인했다. 구문 검사와 diff 공백 검사 통과. 기존 회귀 테스트에 카드 자체가 버튼이며 내부 별도 버튼이 없다는 검사와 Enter 입력 검사를 반영했다.

## 기록 방식 배지 제거

사용자가 지정한 기록 카드의 간편 체크·사진 인증 배지를 제거했다. 완료된 카드의 오늘 기록 완료 표시와 카드 클릭에 따른 기록 기능은 유지한다.

## 실제 계정의 완료 카드 다시 열기

기본 주소에서 완료 카드가 선택되지 않던 동작을 수정했다. 완료 카드의 disabled를 제거하고, 카드 선택 시 기존 기록창에서 저장된 완료 상태를 확인할 수 있도록 변경했다. 완료 상태에서는 확인 버튼만 제공하며 재저장·사진 재업로드를 수행하지 않는다. 미완료 상태에서는 기존 질문과 완료 모션이 유지된다. 서버 기록과 선택한 챌린지는 변경하거나 데모 데이터로 대체하지 않는다.

`node --test tests/frontend/completed_record.test.cjs` 3개 통과: 저장된 실천의 조회·닫기에서 쓰기 없음, 식사 완료 카드 조회 후 미완료 물 카드의 정상 질문 복원, 중복 저장 방지 및 새 기록 저장. JS 구문 검사와 diff 공백 검사 통과. 기본 주소는 현재 연결된 인앱 브라우저에서 비로그인 상태이므로 실제 계정의 저장 기록 UI는 로그인 후 확인이 필요하다.
