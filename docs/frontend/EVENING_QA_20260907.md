## 홈 변경 완료

후속 함께하기 수정: 중복된 하단 ‘당근의 숲 / 가족·친구와 함께하기 / 2주차·14일 남음’ 제목 줄을 제거하고, 기존 혈당이 캐릭터를 상단 제목 왼쪽으로 이동했다. ‘함께하기 → 캐릭터+당근의 숲 → 가족·친구와 챌린지 수행 상태를 함께 확인해요.’만 한 번 표시한다. 다른 탭에서는 캐릭터를 숨긴다. `forest_entry_qa.cjs`로 1440/380px 단일 제목·큰 글씨 가로 넘침 없음·홈 전환 시 캐릭터 숨김·키보드/이미지 클릭 게임 입장 통과. 모바일 제목 캡처 시각 확인. 키/환경파일 접근 및 추가 푸시 없음.

- [x] 홈 바로가기 카드 4개의 화살표 제거.
- [x] 별도로 보이던 건강정보 관리 접기 바 제거. 카드 클릭 전에는 관리 영역 전체를 숨김.
- [x] 클릭 후 새 건강정보 기록 버튼, 저장 이력, 최근 정보 불러와 수정 버튼 표시.
- [x] 같은 카드 재클릭·닫기·Escape로 닫기, aria-expanded 동기화, 초점 복귀. 홈으로 돌아오면 다시 숨김.
- [x] 1440/768/380px·큰 글씨·키보드 검증. 최근 기록 입력 복원 확인. 모바일 캡처 시각 확인.

새 기록 입력은 기존처럼 최근 정보를 참고하며, 수정 후 저장도 새 이력을 만든다. 과거 이력은 덮어쓰지 않는다. 임의의 과거 이력과 현재 추가 입력을 혼합하지 않도록 수정 버튼은 최근 기록에만 제공한다.
