# 결과 조합 안내 초안 — 9/7

상태: 수인님이 ‘확정안 없음 — 안내 초안부터 준비’ 선택. 실제 화면에는 아직 적용하지 않음.
근거: [9/4 멘토링 피드백 요약](https://app.notion.com/p/3d1caf5650aa8087bb6fd2bf941fa200).

## 공통 방향

- 현재 위험 신호 선별과 미래 신규 발병 위험은 별도 결과로 유지한다.
- 수치/등급/모델 응답을 합치거나 바꾸지 않는다. 미승인 결과를 설명 문구로 우회 공개하지 않는다.
- ‘확인 불가’는 멘토링의 검토 예시이며 확정 정책이 아니다. 등급 불일치를 API 실패로 취급하지 않는다.
- 위치 제안: 두 결과 카드 아래, 공통 안전 안내 위. 실제 적용 전 수인님 및 모델·백엔드 담당자 확인.

## 화면 문구 후보

### 1. 현재 높음 / 미래 낮음

제목: 두 결과가 다르게 보일 수 있어요

현재 위험 신호 선별과 미래 신규 발병 위험은 서로 다른 기준으로 계산됩니다. 미래 결과가 낮게 표시되어도 현재 결과에서 안내한 확인 필요성이 없어지는 것은 아닙니다.

현재 확인이 필요한 신호가 안내되었으므로 검사·상담 안내를 먼저 확인해 주세요. 두 결과는 진단이나 확정 발병확률이 아닙니다.

### 2. 현재 낮음 / 미래 높음

제목: 현재와 앞으로의 신호를 나누어 확인해 주세요

현재 결과가 낮게 표시되어도 미래 결과를 대신하지 않습니다. 두 결과는 서로 다른 기준으로 계산되므로 직접 비교하거나 합산하지 않습니다.

추가 확인이 필요한 신호에 대한 검사·상담 안내를 확인해 주세요. 두 결과는 진단이나 확정 발병확률이 아닙니다.

### 3. 높은 신호의 공통 보조 문구

추가 확인이 필요한 위험 신호가 확인되었습니다. 이 결과만으로 당뇨병을 진단할 수는 없습니다. 검사·상담 안내를 확인해 주세요.

## 적용 조건 초안

| 상태 | 제안 처리 |
|---|---|
| 두 결과 모두 공개 승인, 현재 높음/미래 낮음 | 후보 1, 검사·상담 CTA 유지 |
| 두 결과 모두 공개 승인, 현재 낮음/미래 높음 | 후보 2, 검사·상담 CTA 유지 |
| 주의 포함 조합 또는 동일 등급 | 현재의 공통 ‘별도 계산·비교/합산 금지’ 설명 유지. 확장 여부 담당자 확인 |
| 한쪽 미승인·누락 | 등급 조합 안내하지 않음. 비공개·누락 안내 유지 |
| API/모델 실패 | 이미 구현한 부분 실패 안내·실패 요청만 재시도 |
| 기진단/응급/당일 진료 | 기존 이용 제한·안전 분기 유지. 이 안내로 예측/챌린지 제한 우회 금지 |
