# 고령층 편의·접근성 체크리스트

## 적용 기준

| 점검 항목 | 적용 내용 | 상태 |
| --- | --- | --- |
| 기본 글자 크기 | 본문 기본 20px, 모바일 최소 18px 기준 | 적용 |
| 글자 확대 | 상단 `글자 크게` 기능 제공 | 적용 |
| 버튼 크기 | 주요 버튼과 입력 요소 최소 44×44px 이상 | 적용 |
| 명암 대비 | 본문·버튼·상태 문구에 높은 명암 적용 | 적용 |
| 상태 구분 | 색상뿐 아니라 아이콘과 텍스트를 함께 표시 | 적용 |
| 핵심 행동 | 화면별 주요 행동을 한 개 중심으로 배치 | 적용 |
| 이전 이동 | 주요 화면과 대시보드 메뉴에 이전 버튼 제공 | 적용 |
| 오류 안내 | 오류 항목 위치와 수정 방법을 함께 표시 | 적용 |
| 쉬운 문구 | 기진단자 등 어려운 표현을 사용자 중심 문구로 변경 | 적용 |
| 키보드 접근 | 포커스 표시, 탭 이동, 버튼 키보드 조작 지원 | 적용 |
| 보조기기 | `aria-live`, `role=alert`, 상태 설명 속성 적용 | 적용 |
| 모바일 배치 | 카드 1열 전환, 로고 한 줄 유지, 단어 단위 줄바꿈 | 부분 적용·계속 점검 |

## 고령층용 단계 축소

- 대시보드에 진입한 기존 사용자는 온보딩과 예측을 매번 반복하지 않는다.
- `오늘 기록하기`를 가장 먼저 보이는 주요 행동으로 배치한다.
- 챌린지 기록은 사진을 강제하지 않고 간편 체크로 완료할 수 있다.
- 건강정보 수정은 필요할 때만 별도 진입한다.
- 대시보드 진입 후 온보딩 8단계 진행바는 표시하지 않는다.

## 의료 안전과 이해 지원

- 위험 범주는 확정 진단이나 개인 발병확률로 표현하지 않는다.
- 높은 위험에서는 챌린지보다 검사·의료기관 안내를 먼저 표시한다.
- 예측 실패와 시간초과가 높은 위험을 의미하지 않는다고 안내한다.
- 약물 시작·중단·용량 변경을 권하지 않는다.
- 챌린지는 진단이나 치료가 아닌 생활습관 기록 기능이라고 안내한다.

## 실제 사용자 테스트에서 추가 확인할 항목

- 20px 글자가 실제 스마트폰에서 충분히 읽히는지
- `글자 크게` 버튼의 위치와 의미를 바로 이해하는지
- 카드 안의 문장이 과도하게 길지 않은지
- 버튼 사이 간격이 오터치를 막기에 충분한지
- 사진 인증 실패 후 간편 체크 전환을 쉽게 찾는지
- 대시보드에서 오늘 해야 할 행동을 5초 안에 찾는지
