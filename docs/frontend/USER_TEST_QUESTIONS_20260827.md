# 간당간당 프론트엔드 사용자 테스트 질문 초안

## 1. 테스트 목적

- 사용자가 챌린지를 선택하고 오늘의 실천을 기록한 뒤 대시보드에서 결과를 확인할 수 있는지 확인한다.
- 사진 인증과 간편 체크의 차이를 이해하는지 확인한다.
- 큰 글씨, 버튼 크기, 쉬운 문구가 고령층 사용자에게 충분한지 확인한다.
- 예측 결과와 챌린지를 진단이나 치료로 오해하지 않는지 확인한다.

## 2. 권장 테스트 대상

- 만 45세 이상 사용자 3명 이상
- 스마트폰 사용이 익숙한 사용자와 익숙하지 않은 사용자를 함께 포함
- 가능하면 보호자 또는 가족과 함께 서비스를 이용하는 사용자 포함

## 3. 테스트 시나리오

1. 서비스 안내를 읽고 가입·동의를 완료한다.
2. 이용 가능 여부를 확인한다.
3. 건강정보와 생활습관을 입력하고 입력 내용을 검토한다.
4. 예측 상태와 결과 안내를 확인한다.
5. 생활습관 챌린지를 선택한다.
6. 오늘의 챌린지를 간편 체크 또는 사진으로 기록한다.
7. 대시보드에서 오늘 기록과 주간 현황을 확인한다.
8. 리포트·함께하기·건강도구 메뉴를 찾아 이동한다.

## 4. 진행 중 관찰 항목

- 사용자가 설명 없이 다음 버튼을 찾을 수 있는가?
- 필수 입력 항목과 선택 항목을 구분하는가?
- 오류가 발생했을 때 수정할 위치와 방법을 이해하는가?
- 사진 인증이 필수가 아니라는 점을 이해하는가?
- 챌린지 기록 완료 여부를 즉시 알아보는가?
- 대시보드에서 오늘 가장 먼저 해야 할 행동을 찾는가?
- 화면 확대 없이 주요 문구와 버튼을 읽을 수 있는가?
- 키보드 또는 터치로 모든 주요 기능을 사용할 수 있는가?

## 5. 사용자 질문

### 전체 흐름

1. 처음 화면에서 이 서비스가 무엇을 하는 서비스라고 이해하셨나요?
2. 다음에 무엇을 해야 하는지 바로 알 수 있었나요?
3. 진행 중 길을 잃거나 이전 화면으로 돌아가고 싶었던 순간이 있었나요?

### 입력과 예측

4. 필수 입력 항목과 선택 입력 항목을 구분하기 쉬웠나요?
5. 입력한 내용을 확인하고 수정하는 방법을 쉽게 찾았나요?
6. `낮음·주의·높음`이 당뇨병 진단 결과가 아니라 위험 선별 결과라는 점을 이해하셨나요?
7. 결과 화면에서 가장 먼저 해야 할 행동이 무엇이라고 느꼈나요?

### 챌린지와 기록

8. 네 가지 챌린지의 차이를 이해하기 쉬웠나요?
9. 본인이 실천하고 싶은 챌린지를 고르기 쉬웠나요?
10. `사진 인증`과 `간편 체크` 중 어떤 방식을 먼저 선택하고 싶었나요? 그 이유는 무엇인가요?
11. 사진 인증이 실패했을 때 재촬영하거나 간편 체크로 바꾸는 방법을 찾을 수 있었나요?
12. 오늘 기록이 저장됐다는 사실을 분명하게 알 수 있었나요?

### 대시보드와 메뉴

13. 대시보드에서 오늘 해야 할 일을 바로 찾을 수 있었나요?
14. 오늘 기록이 대시보드와 리포트에 반영된 것을 확인할 수 있었나요?
15. 챌린지·리포트·함께하기·건강도구 메뉴의 차이를 이해할 수 있었나요?

### 접근성

16. 기본 글자 크기가 읽기에 적당했나요?
17. `글자 크게` 기능을 쉽게 찾고 사용할 수 있었나요?
18. 버튼 크기와 버튼 사이 간격이 누르기에 충분했나요?
19. 이해하기 어렵거나 의료용어처럼 느껴진 표현이 있었나요?

### 최종 의견

20. 가장 편리했던 부분은 무엇인가요?
21. 가장 불편하거나 헷갈렸던 부분은 무엇인가요?
22. 계속 사용한다면 가장 자주 사용할 것 같은 기능은 무엇인가요?
23. 꼭 수정되었으면 하는 부분을 한 가지만 고른다면 무엇인가요?

## 6. 테스트 결과 기록 양식

| 항목 | 기록 내용 |
| --- | --- |
| 참여자 구분 | 연령대, 기기, 스마트폰 숙련도 |
| 완료 여부 | 전체 완료 / 중간 이탈 / 도움 후 완료 |
| 막힌 화면 | 화면명과 행동 |
| 도움 요청 횟수 | 횟수와 도움 내용 |
| 주요 오해 | 예측·의료 안전·챌린지 관련 오해 |
| 접근성 문제 | 글자, 버튼, 명암, 터치, 키보드 |
| 개선 우선순위 | 높음 / 보통 / 낮음 |
| 사용자 직접 의견 | 핵심 발언 요약 |

## 7. 완료 판단 기준

- 사용자가 별도 설명 없이 챌린지 선택부터 일일 기록·대시보드 확인까지 완료한다.
- 사진 인증을 원하지 않으면 간편 체크로 전환할 수 있다.
- 위험 범주를 진단 결과나 확정 발병확률로 해석하지 않는다.
- 고위험 안내에서 챌린지보다 검사·의료기관 상담을 우선 행동으로 인식한다.
- 주요 버튼과 본문을 확대 없이 읽고 누를 수 있다.
