체크된 항목은 아래에 명시한 범위만 검증했다. 제어 응답 테스트는 실제 백엔드·모델 검증을 대신하지 않는다.

- [x] 여섯 조건의 안내·초점 진입·380px·닫기·분석 요청 없음: 제어 응답 브라우저 테스트 6개 통과.

## 담당자와 맞춰야 하는 연결·정책 문제

- [ ] **추가 세부 입력 저장: 실제 404.** `POST /api/v1/current-screening-inputs`가 없다. 입력값은 화면에만 남고 이번 분석에 반영되지 않았다는 안내를 유지한다. 저장·추론 완료로 체크하지 않는다.
- [ ] **입력 계약:** 현재 shared7 모델과 이전 KNHANES 22입력 스냅샷 요구의 관계를 백엔드/모델 담당자와 확정. 공복혈당은 현재 건강정보 DTO/요청에 없고 추가 입력도 미저장이다. 필드명만 추가한다고 연결된 것으로 간주하지 않는다.
- [ ] **가입 연령 정책:** 기존 사용자 요청·코드는 14세, 안전 문서는 19세다. 임의 변경하지 않고 기준 확정 후 프론트·백엔드·문서를 통일한다.
- [ ] **모델별 결과:** 현재/미래는 별도 작업, 생존 전망 독립 `diabetes_lifetime_risk` 작업은 프론트에서 미요청이다. incidence 응답에 포함된 로컬 전망 UI와 별개로 추적한다.
- [ ] 동의의 수집 항목·목적·보유기간·철회 방법 확정 및 상세 화면 연결.

## 화면별 API와 다음 경로

공통 접두사 `/api/v1`. 개발 점검 문서에만 표시하며 화면에 내부 API 코드를 노출하지 않는다.

| 화면 | 주요 API·필드 | 정상 다음 경로 | 실패/빈 상태 다음 경로 |
|---|---|---|---|
| 시작 | API 없음, 인증 상태 | 가입/로그인 | 서비스 안내 유지 |
| 가입 | POST `/auth/signup`: email/password/birth_date/gender/terms_agreed | 자동 로그인 | 폼 오류 또는 연령·동의 안내 |
| 로그인 | POST `/auth/login`: access_token; GET `/users/me`, `/consents`, `/eligibility-checks/latest`, `/health-checkups`, `/challenge-cycles/current` | 이력 없음→입력, 있음→홈 | 폼 유지, 동의/이용 대상 확인 |
| 프로필·동의 | PATCH `/users/me/profile`: birthday/gender; POST `/consents`: consent_item/version/is_agreed | 이용 대상 확인 | 입력 유지·동의 필요 안내 |
| 이용 대상 | POST `/eligibility-checks`: birth_date/has_diabetes_diagnosis/has_urgent_warning_sign/population_in_scope → reason_codes·기능 허용값 | 허용된 건강정보 입력 | 응급/기진단/연령별 안내 |
| 기본·생활습관 | POST `/health-checkups`: 신체·혈압·흡연·음주 유무·운동·주관적 건강·식사 횟수 → checkup_id | 추가 입력 저장 시도→분석 | 오류 항목 수정 |
| 세부 입력 | POST `/current-screening-inputs`: health_checkup_id·input_as_of_date·추가 입력 → snapshot ID | 지원 시 현재 모델 스냅샷 참조 | 현재404: 미저장 안내 |
| 분석 상태 | POST `/prediction-jobs`: checkup_id/model_key; GET `/prediction-jobs/{job_id}`: status/prediction_id/error_code | 결과 조회 | 대기·실패·재시도 |
| 현재·미래 결과 | GET `/predictions/{id}`, `/predictions/{id}/risk-factors`: 모델 키·버전·표시 승인·범주·메타데이터 | 일반→챌린지, 높음→검사 안내 우선 | 비공개·결과 없음 안내 |
| 챌린지 | GET `/challenges`, `/challenge-recommendations?prediction_id=정수`; POST `/challenge-cycles`: challenge_ids/start_date/prediction_id | 홈 | 목록 재시도, 의료 후속 안내 확인, 기존 사이클 복원 |
| 오늘 기록·홈 | PUT `/user-challenges/{id}/logs/{date}`; GET `/dashboard/summary`, `/dashboard/challenge-progress` | 저장 후 현황 | 저장 실패 재시도·빈 기록 안내 점검 필요 |
| 리포트 | GET `/weekly-reports/current`; GET `/weekly-reports/current/pdf?period=week\|four-week\|all` | 기간 선택·PDF 저장 | 오류 안내; 전체 기간 집계 추가 검증 |
| 함께하기 | `/connections`, `/invitations`, `/shared-challenge-groups`; 숲은 `/forest` 하위 화면 | 연결/공유/숲 | 빈 목록·실패·권한 분기 후속 점검 |
| 건강도구 | `/medical-facilities/nearby`, `/emergency-facilities/nearby`, `/health-education/questions`, `/food-analyses`, `/ocr-drafts` 등 | 기관·근거 안내/입력 확인 | 위치 거부·시간초과·없음·API 실패 후속 점검 |
