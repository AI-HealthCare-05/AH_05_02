# 9/7 멘토링 실행 준비 묶음

근거: [9/4 멘토링 피드백](https://app.notion.com/p/3d1caf5650aa8087bb6fd2bf941fa200).
실행 현황은 `DAILY_PRIORITY_CHECKLIST_20260907.md`가 기준이다. 아래는 제안·관찰 양식이며 실제 시행이나 담당자 동의 완료를 뜻하지 않는다.

## 1. 수인님이 확인할 문구

- 결과 조합 안내: `RESULT_GUIDANCE_DRAFT_20260907.md`. 아직 서비스 적용 전.
- 입력 재확인 초안: “입력하신 생년월일은 [생년월일], 계산된 나이는 만 [나이]세입니다. 맞는지 확인해 주세요.”
- 버튼 초안: `맞아요, 계속` / `수정하기`. 저장·가입 요청 전 확인이며 새로운 건강정보 변수를 추가하지 않음.
- 프로필 재확인 시 동일 정보의 반복 확인을 줄이되 생년월일 변경 시 다시 확인하는 방향. 기준 연령 자체를 변경하지 않음.
- 범위 내 오타를 자동으로 진단하거나 서버 기록을 삭제하지 않는다. 폐기/보유 정책은 백엔드·팀 확인 대상.

## 2. 실제 52세 참여자 관찰표

참여자 확보·동의·일정은 수인님 확인 필요. 자동 테스트를 이 관찰의 완료로 체크하지 않는다.
테스트 중 실제 증상이 있거나 기진단 조건에 해당하면 안전 분기를 존중하며 정상 경로로 우회시키지 않는다.
이름 대신 참여자 코드만 기록하고 촬영은 별도 동의를 받은 경우에만 한다.

| 단계 | 관찰할 행동 | 기록할 것 |
|---|---|---|
| 첫 화면 | 서비스가 무엇인지 설명하고 시작 찾기 | 이해하지 못한 문구, 첫 클릭 |
| 가입·동의 | 스스로 가입하고 동의 판단 | 오류, 도움 요청, 동의 이해 |
| 입력 | 기본→생활습관→세부→확인 | 항목별 막힘, 모름/빈칸 사용, 소요시간 |
| 결과 | 현재/미래 결과 차이와 다음 행동 설명 | 진단/안전 확정으로 오해했는지 |
| 의료 안내 | 안내 찾기, 위치 거부 시 다음 행동 | 위치 거부가 기능 전체 차단으로 느껴지는지 |
| 챌린지 | 선택하고 시작, 홈으로 이동 | 선택 개수·목표·다음 행동 이해 |
| 홈·재방문 | 오늘 기록 저장, 재로그인 후 찾기 | 기록 유지, 다시 하고 싶은 이유/싫은 이유 |

단계마다 시작/종료 시각, 성공/중단, 도움 제공 여부를 기록한다. 중단 원인을 참여자 탓으로 해석하지 않는다.
마지막 질문: 가장 헷갈린 곳 / 입력을 그만두고 싶었던 곳 / 내일 다시 이용할 이유 / 빼도 되는 기능.

## 3. 흐름 로그 설계 초안

이벤트 후보: `flow_step_view`, `flow_step_complete`, `flow_step_error`, `flow_retry`, `flow_next`.
허용 필드 후보: 단계 이름, 다음 단계 이름, 이벤트 종류, 경과시간 구간, 정규화한 오류 코드, 앱 버전.
금지 필드: 이메일, 비밀번호, 생년월일, 건강 측정값, 모델 원시 점수, 자유 입력, URL 전체/토큰, 원문 에러 메시지.

선택 동의 미동의 시 수집하지 않는 기본값, 동의 철회 후 중단, 보유기간, 가명 세션 처리, 서버 수신 계약을 먼저 확정한다.
브라우저 탭을 닫은 것을 확정 이탈로 단정하지 않는다. 마지막 완료 단계와 집계된 단계 전환으로 평가한다.
이번에는 추적 코드 설치·실제 수집·외부 전송을 하지 않았다.

## 4. 당근의 숲 보상 배치 초안

- 첫 입력 앞: “작은 실천을 기록하며 당근의 숲을 함께 가꿔요.” 지급량을 약속하지 않는 설명.
- 입력 중간: 진행 상태를 알려 주되 민감정보 추가 제공이나 동의를 보상의 조건으로 압박하지 않음.
- 첫 챌린지 기록 완료: 실제 서버 지급 여부가 확인된 보상만 표시.
- 재시도·새로고침 중복 지급 방지, 지급 실패 시 재조회 기준을 백엔드와 먼저 합의.

## 5. 팀 전달용 확인 목록 — 아직 발송하지 않음

준혁님: 현재/미래 조합별 안내 및 입력 계약, 독립 평가·threshold 비교·보정·하위집단 성능, 모델 버전/아티팩트 식별 자료가 필요합니다. 결과 조합 안내는 초안만 작성했고 모델값은 바꾸지 않았습니다.

빛샘님: 추가 입력 저장404, 동의 상세/분석 동의, 리포트 기간 API 지원 여부를 확인 부탁드립니다. 현재 `weekly-reports/current`는 최근 최대 7일 집계이며 PDF 라우트는 기간 인자를 받지 않습니다. 프론트는 지난 4주/전체를 주간 PDF로 잘못 내려받지 않도록 차단했습니다.

배포 담당: 테스트 서버 주소·접근 대상·시연 모델 버전·실패 시 복구 경로 확정이 필요합니다. 외부 공개 전 개인정보 노출과 로컬 데모 설정 혼입 여부를 점검해 주세요.
