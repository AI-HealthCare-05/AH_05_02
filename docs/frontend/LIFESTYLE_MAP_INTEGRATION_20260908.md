# 생활습관 지도 통합

2026-09-08 승인된 BMI 시안을 건강도구에 적용했다.

- 건강도구에서 기존 혈당이 생활습관 요약의 식사 / 활동 / 생활습관 / 정기 점검 구성을 사용하고, 체형 기록을 다섯 번째 항목으로 유지한다. 기존 hyeoldangi-risk-low.png 안내 이미지를 재사용하며 BMI와 챌린지·도움말을 상세 패널에 연결한다.
- 생활습관 지도는 건강교육과 같은 카드 선택 → 팝업 흐름을 사용한다. 식사·활동·생활습관·정기 점검·체형 기록·도움말 카드에 항목 이름과 혈당이 그림만 표시한다. 그림 아래 요약·BMI 수치·기록 보기 문구는 제거하고 기록 내용은 팝업에서 확인한다. 건강교육의 EducationCarousel.mount와 CSS를 공유하여 포인터 근접 확대, 좌우 버튼, 방향키·Home·End 이동과 좁은 화면 가로 스크롤을 동일하게 적용한다. 생활습관과 건강교육의 선택 상태는 각각 독립적이다.
- ‘챌린지 살펴보기/이어가기’ 버튼은 제거했다. ‘생활습관 도움말’은 질문하는 혈당이를 넣은 여섯 번째 독립 카드로 제공하며, 누르면 도움말 팝업이 열린다. 기존 다섯 항목의 기록 및 연결된 챌린지 실천 현황은 상세 팝업에서 유지한다.
- 상세 팝업은 닫기·Esc·배경 클릭으로 닫는다. 포커스는 팝업 안에 유지되고 닫으면 열었던 버튼으로 돌아간다. BMI와 도움말 폼 DOM을 다시 만들지 않아 팝업을 닫거나 항목을 바꿔도 입력이 유지된다.
- 문서의 두 활동·1/5회는 검증 예시로 사용한다. 실제 화면의 항목·횟수·날짜는 기존 사용자 챌린지와 리포트 데이터를 그대로 사용하며 예시 값을 저장하거나 하드코딩하지 않는다.
- 최신 저장 건강정보의 키·몸무게로 BMI를 자동 계산한다. 지도 입력은 계산용이며 건강정보 저장, 분석 입력, 예측 결과를 변경하지 않는다. 불러온 값으로 초기화할 수 있다. 계정 또는 저장 기록이 바뀌면 임시 계산값도 초기화한다.
- 최신 저장 건강정보의 식사 횟수, 운동 여부, 흡연·음주와 정기 점검 안내를 기존 요약 문구로 보여 준다. 미입력 값은 없다고 표시하며, 검사·상담 안내 여부는 기존 안내 판단 함수를 사용한다. 혈당이는 안내용 그림으로 고정하고 BMI 입력에 따라 모양을 바꾸지 않는다. 체형 기록의 BMI 자동 계산·허리둘레·초기화 동작은 유지한다.
- 현재 주기의 챌린지를 카탈로그 분류와 제목으로 습관에 연결한다. 분류할 수 없는 챌린지는 임의로 배정하지 않는다.
- 오늘 완료 여부는 기존 일별 기록 상태를 사용한다. 조회 실패를 미실천으로 바꾸지 않는다. 기간별 횟수는 기존 주간 리포트의 user_challenge_id로 연결하며, API가 일자별 내역을 제공하지 않으므로 임의 달력 체크를 그리지 않는다.
- 챌린지의 ‘이 습관 살펴보기’에서 같은 상세 팝업을 열 수 있다. 기존 기록 저장·안전 확인 흐름을 유지한다.
- 기존 건강교육 질문 폼과 결과 영역을 지도 내부 도움말로 이동했다. 기존 답변·출처 검증, 근거 부족 및 실패 처리를 유지한다.
- 건강교육·퀴즈는 유지했다. 워치/건강정보 다시 입력의 혈당이 이미지 경로를 유지하고, 준비 중·inert 및 비활성 버튼으로 제공한다.
- 후속 화면 수정: 두 카드 위의 작은 준비 중 배지를 제거하고, 기존 프론트의 큰 중앙 정렬 제목(데스크톱 최대 48px, 모바일 34px)으로 복원했다.
- 워치 카드 추가 수정: 큰 ‘준비 중’을 카드 안 중앙에 겹쳐 배치했다. 기존 혈당이·문구는 연한 배경으로 남고, 문구는 inert 카드 밖의 형제 요소여서 선명하게 표시된다.
- 검진표 카드도 동일한 카드 내부 오버레이를 적용하고, 카드 문구를 ‘검진표로 기록연동’으로 변경했다.

## 검증

- `node --test tests/frontend/*.test.cjs`: BMI의 누락·0·음수, ID별 리포트 결합, 계정 전환, 계산값과 저장값 분리 등 포함.
- `python -m pytest tests/test_frontend_integration_runtime.py tests/test_prototype.py -q`: 기존 화면 계약과 회귀 확인.
- 로컬 재방문 프리뷰에서 카드 선택, BMI 입력, 초기화, 챌린지 이동, 도움말, 준비 중 상태와 기존 혈당이 이미지를 확인한다. 이 프리뷰는 실제 계정의 저장 성공을 증명하지 않는다.

- 식사·활동 카드 이미지는 사용자가 지정한 AH_05_02의 hyeoldangi-card-meal.png / hyeoldangi-card-activity.png 원본을 현재 프론트 자산으로 복사해 적용했다.

- 생활습관·건강교육 공용 캐러셀 컨테이너의 그라데이션 배경과 외곽선을 제거해 페이지 배경 위에 카드를 표시한다. 카드 자체 색상과 캐러셀 동작은 유지한다.

- 두 캐러셀의 팝업·방향키 안내 문구와 해당 aria-describedby 참조를 제거했다. 내 생활습관 지도 전체 컨테이너도 흰 배경·테두리·안쪽 여백을 제거해 건강교육 영역처럼 페이지 배경에 배치한다.

- 건강도구의 두 영역은 항상 펼쳐 표시한다. 건강도구에 한해 공용 상단 제목·소개 문구를 숨기며 다른 탭에서는 다시 표시한다. 지도 상단의 ‘내 생활습관 지도’ 제목과 조회 기간 표시는 제거하고, ‘생활습관 요약 / 지금 살펴볼 생활습관’에서 바로 카드를 선택한다. 하단 BMI 안내 문구도 삭제했다.

- 지도 제목 앞 안내 혈당이를 제거하고 제목을 ‘생활습관 지도’로 변경했다. 생활습관 요약/제목은 건강교육 영역과 같은 dashboard-section 및 eyebrow 스타일을 사용한다. 체형 기록 카드에는 사용자가 지정한 hyeoldangi-card-body-record.png 원본을 적용했다.
