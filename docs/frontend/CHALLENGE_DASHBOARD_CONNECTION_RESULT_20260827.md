# 챌린지·일일 기록·대시보드 화면 연결 결과

## 작업 목적

사용자가 생활습관 챌린지를 선택한 뒤 오늘의 실천을 기록하고, 저장된 수행 결과를 대시보드와 리포트에서 확인할 수 있도록 화면 흐름을 연결했다.

## 구현한 화면 흐름

1. 챌린지 선택
2. 4주 챌린지 시작
3. 대시보드의 `오늘 기록하기` 또는 `챌린지` 탭으로 이동
4. 선택한 챌린지별 일일 기록
5. 기록 완료 상태 표시
6. 대시보드의 최근 실천·현재 챌린지·주간 현황 갱신
7. 리포트에서 주간·4주 전체·전체 기간 기록 확인

## 챌린지별 기록 방식

| 챌린지 | 기본 기록 방식 | 화면 처리 |
| --- | --- | --- |
| 가볍게 걷기 | 간편 체크 | 걷기 완료 버튼으로 기록 |
| 식사 리듬 지키기 | 사진 인증 또는 간편 체크 | 사진 등록 실패·거부 시 간편 체크 전환 |
| 덜 달게 마시기 | 간편 체크 | 단 음료 대신 물을 선택했는지 기록 |
| 정기 점검하기 | 간편 체크 | 건강 수치·검진 결과 확인 여부 기록 |
| 수면 유형 확장 | 간편 체크 | 사진 없이 수면 실천 여부만 기록하도록 구조 마련 |

## 예외 처리

- 기록할 챌린지가 없으면 챌린지 선택 화면으로 안내한다.
- 사진 인증이 실패하면 재촬영할 수 있다.
- 반복 실패하거나 사진을 원하지 않으면 간편 체크로 완료할 수 있다.
- 저장 중 중복 제출을 방지한다.
- API가 준비되지 않은 환경에서는 화면 확인용 상태로 흐름을 점검할 수 있다.

## 당근의 숲 처리

- 로컬 `/forest` 화면에서 `퀘스트 → 인증 → 보상 → 꾸미기` 데모 흐름을 연결했다.
- 퀘스트 완료, 개인·공동 진행도, 보상 상자, 옷장·창고, 아바타 꾸미기와 저장을 확인할 수 있다.
- 실제 API로 교체할 수 있도록 Demo Adapter와 API Adapter 경계를 마련했다.
- 당근의 숲 게임이 별도 수정 중이므로 현재 Draft PR에서는 게임 파일을 제외했다.
- Draft PR의 간당간당 화면에서는 확정되지 않은 게임으로 잘못 이동하지 않도록 진입 버튼을 `준비 중`으로 비활성화했다.

## 확인 결과

- 챌린지 선택 후 일일 기록 화면으로 이동 가능
- 기록 완료 후 대시보드 갱신 가능
- 사진 인증과 간편 체크를 화면에서 구분
- 사진 없이 완료하는 기록 방식 제공
- 사진 인증 실패 시 재촬영·간편 체크 전환 제공
- 게임 미연결 버튼으로 인한 초기 화면 이동 오류 차단
- 로컬 당근의 숲에서 퀘스트·보상·꾸미기 데모 흐름 확인
