## 커밋 권장 순서

1. `fix(fe): API 오류와 예측 상태 처리 정비`
2. `test(fe): 프론트 API 계약 회귀 테스트 추가`
3. `docs(fe): 계약 불일치와 팀 인계 사항 정리`
4. 회원가입 결정 후 별도 `feat(fe): 회원가입 계약 반영`

게임 파일은 위 커밋에 포함하지 않는다.
