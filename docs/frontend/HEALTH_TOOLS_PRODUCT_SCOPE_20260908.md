# 건강도구 제품 목적 및 향후 범위

기록일: 2026-09-08
확인 경로: 팀장 확인 내용

## 건강도구가 존재하는 이유

건강도구는 예측 결과만 보여주고 끝나는 화면이 아니라, 사용자가 입력한 건강정보를 이해하고 생활습관 관리로 이어갈 수 있도록 돕는 후속 기능 영역이다.

## 구성 방향

1. **건강정보 → 교육 → 퀴즈**
   - 입력한 건강정보와 관련된 교육 내용을 제공한다.
   - 교육 내용을 확인한 뒤 퀴즈로 이해도를 점검할 수 있게 한다.

2. **건강지도**
   - 현재 프론트의 `내 생활습관 지도`가 이 기능에 해당한다.
   - 사용자가 입력한 건강정보를 바탕으로 생활습관과 현재 기록을 더 상세하게 이해할 수 있도록 안내한다.
   - 추후 워치가 연동되면 걸음 수·활동 시간 등 워치 기록을 함께 활용해 더 구체적인 정보를 보여준다.

3. **모델 변수와 건강도구 정보의 구분**
   - 건강도구에서 활용하는 정보가 반드시 오늘이·내일이 예측모델의 입력 변수일 필요는 없다.
   - 모델에 포함되지 않은 건강정보나 워치 기록도 생활습관 설명·교육·상세 안내에는 활용할 수 있다.
   - 이 정보는 예측 결과나 진단처럼 표현하지 않고, 건강관리 참고 정보로 명확히 구분한다.

## 현재 구현 상태

- `내 생활습관 지도`: 화면에 구현되어 있음
- 건강교육·질문 기능: 화면에 구현되어 있으며 답변·출처·퀴즈 흐름 점검 대상
- 워치 연동: 이번 단계에서는 사용하지 않으며 `준비 중`으로 표시
- 검진표 자동 입력: 이번 단계에서는 사용하지 않으며 `준비 중`으로 표시

## 이후 프론트 작업 기준

- 건강도구를 예측모델 입력 화면과 동일하게 취급하지 않는다.
- 모델 결과, 일반 건강정보, 워치 기반 생활습관 정보의 출처와 의미를 화면에서 구분한다.
- 워치 연동 전에는 실제 연결·저장 기능처럼 보이지 않게 `준비 중` 상태를 유지한다.
- 워치 연동 후에는 사용자가 입력한 건강정보와 워치 기록을 함께 보되, 모델에 사용된 변수와 추가 안내용 정보를 혼동하지 않도록 표시한다.
