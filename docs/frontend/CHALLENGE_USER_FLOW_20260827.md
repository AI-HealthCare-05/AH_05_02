# 챌린지·기록·대시보드 전체 사용자 흐름

## 기본 사용자 흐름

```text
서비스 안내
→ 가입·동의
→ 이용 가능 확인
→ 건강정보 입력
→ 생활습관 입력
→ 입력 내용 확인·수정
→ 예측 요청·상태 확인
→ 위험 범주 확인
→ 챌린지 선택
→ 4주 챌린지 시작
→ 오늘의 실천 기록
→ 대시보드·주간 리포트 확인
```

## 챌린지 기록 분기

```text
오늘 기록하기
├─ 간편 체크 챌린지
│  └─ 완료 선택 → 기록 저장 → 대시보드 갱신
│
└─ 사진 인증 가능 챌린지
   ├─ 사진 등록 성공 → 기록 저장 → 대시보드 갱신
   ├─ 확인 어려움 → 재촬영
   └─ 사진 없이 진행 → 간편 체크 → 기록 저장
```

## 모델 적용 범위 외 사용자

```text
만 19~44세
→ 예측 모델 적용 범위 안내
├─ 건강정보 입력하고 챌린지 보기
│  → 건강정보 → 생활습관 → 확인·수정 → 예측 생략 → 챌린지
└─ 건강정보 입력 없이 챌린지 보기
   → 예측 생략 → 일반 생활습관 챌린지
```

## 이미 당뇨병을 진단받은 사용자

```text
당뇨병 진단 여부: 예
→ 개인화 예측 차단
→ 현재 치료·의료진 지침 우선 안내
→ 예측 결과와 개인화 위험요인 미표시
→ 일반 생활습관 기록 기능만 안내
```

## 높은 위험 범주 사용자

```text
위험 범주: 높음
→ 검사·의료기관 상담 안내 우선
→ 진단 결과가 아님을 안내
→ 의료 안내 확인 후 일반 챌린지 선택 가능
```

## 기존 사용자 재진입 흐름

```text
로그인
├─ 진행 중인 챌린지 계속하기 → 대시보드 → 오늘 기록
├─ 챌린지 선택·변경하기 → 챌린지 목록
└─ 건강정보 수정하기 → 건강정보 입력 → 생활습관 → 확인·수정
```

## 당근의 숲 확장 흐름

```text
간당간당 함께하기
→ 당근의 숲 소개 영역
→ 로컬 당근의 숲 데모 진입
→ 오늘의 퀘스트 선택
→ 간편 체크·챌린지 기록 인증
→ 개인·공동 진행도 반영
→ 보상 상자 열기
→ 옷장·창고 아이템 획득
→ 숲·아바타 꾸미기
```

현재 Draft PR에서는 수정 중인 게임 파일을 제외했기 때문에 간당간당의 게임 진입 버튼만 `준비 중`으로 표시한다. 이는 기능 미구현이 아니라 PR 범위 분리이다.
