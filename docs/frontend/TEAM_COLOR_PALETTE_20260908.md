# 팀 색상표 적용 기록 (2026-09-08)

> 현재 적용 취소: 사용자 요청으로 공통 팔레트 적용을 되돌렸다. 아래 표는 당시 제안 기록이며 현재 화면의 색상 기준이 아니다. 메인 화면은 기존 배경 `#F6F7F4`·버튼 `#176B5B`, 당근의 숲은 기존 초록 `#2D8A5F`와 아바타 보라색을 사용한다. 챌린지 V3·기록 취소·리포트·초대 UI·버튼 모션 등 기능과 배치는 유지한다.

## 의료 안전 예외 색상

의료 위험·주의·오류 상태는 일반 성공 색상과 혼동되지 않도록 기존 의미색을 유지한다.

| 역할 | 헥사코드 |
| --- | --- |
| 오류·위험 | `#A32828` |
| 주의·경고 | `#8A4B08` |
| 오류 배경 | `#FFF2EF` |
| 경고 배경 | `#FFF4DF` |

## 주요 버튼

```css
.primary {
  background: #176B5B;
  border-color: #176B5B;
  color: #F5F4EF;
}

.primary:hover {
  background: #0B4D42;
  border-color: #0B4D42;
}
```

메인 서비스와 당근의 숲 UI 셸은 같은 공통 팔레트를 사용한다. 당근의 숲 내부 픽셀 아트와 의료 안전 상태는 의미 전달을 위해 공통 팔레트 치환 대상에서 제외한다.

## 복원 검증

기존 색상 검사 2개 통과. 화면 계약 검사 35개 중 33개 통과하며, 이번 색상 변경과 무관한 초대 기능의 이전 문구 검사 2개는 현재 공유 프론트와 맞지 않아 실패한다. 해당 기능·검사 내용은 색상 복원 범위에서 수정하지 않았다. 기본 8022 화면에서 기존 배경 및 버튼 색상과 `오늘 기록 취소하기` 버튼의 유지 여부를 확인했다. 새 기능에서 사용하는 색상 변수는 기존 색에 연결해 교육·건강 도구 화면의 참조가 끊어지지 않도록 했다.
