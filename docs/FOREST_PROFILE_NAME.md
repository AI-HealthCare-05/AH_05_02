# 닉네임은 메인 MVP 개인정보에서 관리

2026-09-07, v154

- 메인 MVP `/service?account=profile` → 마이페이지의 **개인정보 수정**에서 닉네임을 편집한다. 기존 이름 필드 `User.name`을 사용하며 2~20자다.
- 숲의 왼쪽 닉네임 입력·저장 버튼과 구형 로컬 프로필 팝업은 제거했다. 아바타 꾸미기와 캐릭터 머리 위 닉네임 표시는 유지한다. 상단 프로필 버튼은 메인 개인정보로 이동한다.
- 구형 `/` 화면의 숲 전용 표시 이름 입력도 제거했다. 외형 저장은 이름을 전송하지 않는다.
- `forest-profile.js`는 같은 출처의 세션과 `GET /api/v1/users/me`로 닉네임만 읽는다. 입장·탭 복귀·개인정보 저장 알림 시 갱신한다. 토큰과 계정 닉네임을 숲 체험 저장 데이터에 쓰지 않는다. 연결이 없으면 기존 체험 닉네임을 유지하고, 로그인한 이름 없는 계정은 `숲지기`로 표시한다.
- 다른 탭에 전달되는 `gandang-account-profile-revision`은 갱신 시각만 포함한다. 개인정보·토큰은 전송하지 않는다. 늦게 끝난 이전 요청이 최신 이름을 덮어쓰지 못한다.
- 서버는 프로필 저장 시 기존 숲 아바타 이름도 같은 트랜잭션에서 동기화한다. 과거 클라이언트의 `/forest/avatar.display_name`은 호환을 위해 선택 필드로 받되 무시한다. 코디·보유 당근·가구 배치·다른 계정은 바꾸지 않는다.

## 확인

`tests/forest-profile.test.cjs`, `tests/suin-profile.test.cjs`, `tests/test_forest_profile_name.py`에서 이름 읽기·저장·실패·비로그인·교차 계정 격리·기존 코디 보존을 검증한다. 실제 브라우저에서는 숲의 수정란 제거와 상단 프로필 → 메인 로그인/개인정보 진입 경로를 확인했다. 사용자의 실제 계정 이름을 시험용으로 변경하지 않았다.
