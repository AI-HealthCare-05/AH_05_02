## 자료의 성격과 한계

확인 자료는 창업진흥원이 2020년 12월 발행한 「예비창업패키지 사업 안내 가이드」. 2019년 우수 졸업기업 29개사의 인터뷰 자료이며, 제출 당시의 합격 사업계획서 원문이 아님. 공개 원문·선정 사실을 함께 검증한 합격 신청서는 이번 조사에서 확보하지 못함. 따라서 ‘합격 원문 분석’이나 특정 표현의 합격 효과를 주장하지 않음. 과거 사업화 설명 사례로만 활용하며 현행 지원 조건·평가 기준의 근거로 사용하지 않음.

## 읽은 사례와 적용 판단

- 비엔시스템: PDF 10~11번째 페이지. 현장 업무의 문제를 서비스 설명과 연결하고, 고객 대화에서 수요를 파악해 시장을 넓힌 경험. 간당간당에서는 봉사 활동 → 참여 장벽 → 서비스 기능 순서로 창업 배경을 편집.
- 리드베이션: PDF 20~21번째 페이지. 사용자 수요에 따라 서비스를 조정하고 지자체 프로그램 계약으로 제공한 사례. 간당간당에서는 수혜자와 구매자를 구분하고 실증 결과 → 연간 계약의 흐름을 명확히 표현.
- 진코어: 추출문 내 고객의 계약 대가 대비 추가 요구 경험 확인. 간당간당에서는 기존에 정한 계약 범위·추가 보고·맞춤 개발의 별도 비용 원칙 유지.

위 사례에서 문장을 옮기지 않고 편집 방향만 도출. 타 기업 실적·계약·효과를 간당간당의 근거로 사용하지 않음.

## 주요 편집

- ‘챌린지의 파급력’ → 함께 목표를 정하고 참여를 독려한 경험
- ‘사회에 도움이 되는 창업’ → 재능기부 경험을 지속적인 서비스 제공과 수익 창출이 가능한 사업으로 발전
- ‘AI 모델과 게임 결합’ → 이용자·공동체·기관의 역할을 먼저 설명하고 각 기술의 목적을 후술
- ‘수익원 확장’ → 민간기관 유료 실증, 연간 계약, 공공기관 사업의 순서 명시
- ‘사업성 검증’ → 참여 지속·운영시간·유료 계약 등 확인 가능한 지표 제시

사용자가 지정한 제목과 예시 문항 순서 유지. B2G/B2B/B2C 가격·원가·목표 수치는 변경하지 않음. 팀 소개 분량과 ‘~합니다’ 반복을 피하는 문체 유지.
