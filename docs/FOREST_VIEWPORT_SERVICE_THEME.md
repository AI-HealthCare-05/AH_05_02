# 당근의 숲: 두 배 화면과 수인 UI 디자인 연결

2026-09-07

## 화면 크기와 카메라의 분리

- 이전 최대 표시 크기 `768×512`의 가로·세로·대각선을 각각 두 배로 늘려 최대 `1536×1024`로 표시합니다.
- 화면이 작으면 작업 영역의 가로와 세로 중 제한되는 쪽에 맞춰 3:2 비율을 유지합니다. 실제 표시 크기는 두 축의 사용 가능한 공간을 넘지 않습니다.
- `+ / −`는 화면 요소의 크기를 바꾸지 않고 기존 카메라 배율만 바꿉니다. 표시 범위는 50–200%, 25% 단위이며 새 100%는 월드 기준 2배입니다.
- 저장 데이터·오브젝트·충돌·이동 좌표는 기존 `768×512` 월드 단위를 유지합니다. 고해상도 backing canvas 크기는 표시 크기나 월드 크기와 별개입니다.
- 좌우 패널은 같은 너비의 트랙을 사용합니다. `8 / 9 / 0` 단축키 및 UI를 숨겨도 지도 프레임의 크기를 바꾸지 않는 동작은 유지합니다.

## 하단 조작기와 단축키

- 조작기는 오른쪽 패널에서 지도 프레임의 왼쪽 아래로 옮겼습니다. 반투명 배경으로 지도 위에 가볍게 겹치며, 버튼 사이의 빈 공간은 지도 클릭을 가로채지 않습니다.
- 버튼 내부의 행동 이름과 방향 표시는 가로·세로 중앙에 정렬합니다. 좁은 화면에서 긴 행동 이름은 단어 경계로만 줄을 나눕니다.
- `버튼 숨기기(8)` / `버튼 보이기(8)`는 조작 버튼 묶음만 숨기거나 보여줍니다. `초기화(9)`는 이제 **페이지 새로고침**이며 아바타 위치를 직접 재설정하지 않습니다. `UI 숨기기(0)` / `UI 보이기(0)`는 전체 HUD를 제어합니다.
- 오른쪽 ‘오늘 할 일 / 함께하기’ 카드의 위쪽 둥근 모서리를 복원하고 탭 배경이 모서리를 덮지 않도록 카드 안에서 자릅니다.

## 글자 크기 세 단계

- 상단 `글자 크기` 선택기는 `작게 / 보통 / 크게`의 세 단계를 제공합니다. HTML 계약은 `#font-size-select`, 값은 `small / default / large`입니다.
- 화면 상태는 `body[data-font-size]`로 반영하며 배율은 `0.9 / 1 / 1.12`입니다. 글자만 조절하고 지도 캔버스나 카메라 배율은 바꾸지 않습니다.
- HUD의 본문은 보통 크기에서 주로 12–13px, 설명은 11px, 조작 버튼은 10px를 기준으로 하여 정보의 위계를 유지합니다. ‘크게’에서도 조작기가 불필요하게 커지지 않습니다.
- 선택값 저장·복원과 이전 두 단계 설정의 호환 처리는 게임 상태 코드에서 담당합니다.

## 수인 최신 UI에서 가져온 요소

참조는 이 저장소의 `src/frontend/suin/styles.css`와 `src/frontend/suin/index.html`입니다. 전체 스타일시트를 가져오지 않고 마지막 랜딩 팔레트와 폰트 목록만 숲 전용 스타일로 연결했습니다.

| 역할 | 최신 랜딩 값 |
| --- | --- |
| 배경·종이 표면 | `#f5f4ef` |
| 보조 표면 | `#eeeee8` |
| 기본 글자 | `#292e32` |
| 보조 글자 | `#51595d` |
| 브랜드 강조 | `#236657` |
| 강조 버튼 호버 | `#194f43` |

폰트는 `Pretendard, "Noto Sans KR", "Malgun Gothic", sans-serif`로 동일하게 사용합니다. 수인 원본에는 별도 웹폰트 파일·`@font-face`·폰트 CDN 링크가 없으므로 추가 폰트 다운로드나 HTML 링크를 만들지 않았습니다. 실제 표시 폰트는 기기에 설치된 폰트에 따라 결정됩니다.

지도·캐릭터 이미지의 색은 바꾸지 않습니다. 숲 도구, 양옆 패널, 채팅, 챌린지 설정과 입력 요소 등 DOM UI만 맞춥니다. 챌린지 UI가 뒤에 별도 스타일시트를 불러오므로 `.right-hud [data-challenge-v2]`에 한정된 선택자로 적용합니다.

## 좁은 챌린지 패널

- 제목은 14px, 새로고침 버튼은 12px로 표시합니다.
- 제목과 버튼의 글자 자체는 잘라서 여러 줄로 나누지 않습니다. 236px 패널 및 더 좁은 화면에서 공간이 부족할 경우 버튼 전체가 다음 줄로 이동합니다.
- 좌우 패널 폭을 넓혀 지도 영역을 줄이거나 제목을 숨기지 않습니다.

## 회귀 검증

`node --test tests/forest-hud.test.cjs tests/forest-ui-contract.test.cjs tests/forest-chat.test.cjs`

이 테스트는 두 배 대각선·최대 크기, 두 축의 공간 제한, 3:2 비율, 카메라 배율과의 독립성, 단축키·입력 보호·새로고침 위임, 원본 수인 팔레트/폰트 계약, 세 단계 글자 크기, 반투명 조작기 위치와 챌린지 제목/버튼 줄바꿈 규칙을 검사합니다. 실제 브라우저에서의 시각 검증은 별도로 수행합니다.

UI 동작 테스트는 실제 게임 소스의 관련 함수를 격리 실행합니다. 글자 크기 세 단계의 저장·재접속 복원·구형 설정 이전, 저장소 접근이 차단된 경우의 대체 동작, 초기화 버튼의 단일 새로고침 및 게임 데이터 보존, 카메라를 따라가는 닉네임의 일반 텍스트 처리와 화면 밖 숨김을 확인합니다. 채팅은 C/Enter 열기, C/Escape 닫기, 한글 조합·모달·다른 입력란 보호, Enter의 기존 전송 동작을 검사합니다.

### 실제 브라우저 점검 (2026-09-07)

`http://127.0.0.1:8012/forest?refresh=v153`에서 1935×1272 화면으로 확인했다. 게임 프레임은 약 1399×932.67 CSS px이고 실제 캔버스는 3072×2048이다.

- 작게·보통·크게 선택 시 DOM 글자 크기가 바뀌고 버튼·패널이 잘리지 않는다. 설명은 본문보다 작게 유지된다. 크게 선택 후 새로고침해도 설정이 복원된다.
- 카메라 50%와 200%에서 화면 프레임 크기는 같다. 최저·최대 배율 버튼 비활성화와 새로고침 후 100% 복귀를 확인했다.
- 8번 버튼 숨김/복원, 0번 UI 숨김/복원 시 프레임 유지, C로 하단 채팅 열기/닫기를 확인했다.
- 실제 불투명 캐릭터 영역을 기준으로 닉네임이 머리 위에 붙고, 50% 및 100%에서 선명한 DOM 글자로 보인다.
- 창고의 가구 24종과 젖소 미리보기 전체가 표시된다. 모닥불 클릭 ON/OFF에서 같은 돌·재 받침을 유지하고, 19시 이후 가구와 배경은 어두워지며 불 주변만 밝아진다.
- 젖소 클릭/Q의 유한 고개 움직임, 토끼 등장, 집 입장과 아래쪽 문 그림 제거를 확인했다. 테스트로 배치한 모닥불·젖소는 회수했고 원래 있던 분수 배치는 보존했다.
- 수인 서비스 로그인 페이지는 정상 표시되며 숲 위젯의 로그인 링크도 연결된다. 실제 계정 로그인·동의·챌린지 설정 저장은 사용자 직접 입력 전이므로 완료로 간주하지 않는다.

`tests/test_carrot_forest_pixel_game.py`의 독립 가구 에셋 검사는 Node로 실제 `ForestObjects.INDIVIDUAL_ASSETS`와 서비스 워커 캐시 목록을 읽고 Pillow로 24개 파일의 실제 알파를 확인하므로 Python 환경 외에 Node 실행 파일도 PATH에 있어야 합니다. 구형 아틀라스의 불꽃 추출 호환 계약은 유지합니다.
