# 데일리 뭐하징 Daily Task (8월 26일) — 세준

## 📝 목표 💻

- Sprint 3의 모델–API–DB–화면 연동 기준을 점검한다.
- 간당간당의 핵심 MVP와 선택형 확장 기능을 구분한다.
- 가족·친구 공동 챌린지와 `당근의 숲` 픽셀 게임팩을 기획한다.

## 뭐 했지⁉️

- 실제 모델 연동 QA 체크리스트와 모델–웹 공통 계약을 점검했다.
- `당근의 숲`을 핵심 의료 MVP와 분리된 선택형 Beta 기능으로 정의했다.
- 개인 3개·5인 공동 15개 챌린지와 무료 보물상자 보상 구조를 작성했다.
- 사진·웨어러블·간편 체크·가족 확인 인증 방식을 구분했다.
- 물·수면·스트레칭에는 사진 인증을 강제하지 않는 접근성 원칙을 반영했다.
- 웹 픽셀 맵·아바타·퀘스트·보상·인벤토리의 구현 범위를 정리했다.
- 가족 구독·기관 계약·꾸미기 상품의 수익모델 초안을 작성했다.

## 회의 안건

1. 당근의 숲을 선택형 확장 패키지로 개발할지
2. 가족·친구 공동 챌린지와 보상 구조가 적절한지
3. 챌린지별 인증 방식을 어떻게 구분할지
4. 웹 픽셀 게임으로 우선 검증하고 게임엔진 적용은 이후 판단할지

## 추가 논의사항

1. 고령 사용자의 사진 인증 부담과 간편 체크 대안
2. 가족 참여가 감시로 느껴지지 않도록 공유정보를 제한하는 방법
3. 기관 계약·가족 구독·꾸미기 상품 중 우선 검증할 수익모델
