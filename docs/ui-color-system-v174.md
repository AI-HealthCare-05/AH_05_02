# 메인 MVP·당근의 숲 공통 색상 체계 — v174

`src/frontend/suin/design-tokens.css`를 메인 MVP, 최신 서비스 화면과 당근의 숲이
공동으로 불러온다. 화면별 기존 CSS 뒤에 로드하여 같은 의미의 상태가 어느
화면에서도 같은 색을 사용하도록 한다.

## 의료 안전 예외

안전 상태는 일반 강조색으로 치환하지 않는다.

- 오류·위험: `#A32828`, 배경 `#FFF2EF`
- 주의·경고: `#8A4B08`, 배경 `#FFF4DF`

인증 오류, 잘못된 입력, 위험 안내에는 오류 팔레트를 사용한다. 의료 안내,
주의·경고에는 경고 팔레트를 사용한다. 챌린지 분야 구분은 의료 경고가
아니므로 공통 섹션·강조 색을 사용한다.

## 적용 범위와 검증

- `/`, `/service`, `/forest`의 기본 배경, 카드, 섹션, 구분선과 글자.
- 주요·보조·비활성 버튼 및 hover, 선택, 키보드 포커스.
- 완료 상태, 챌린지 보상, 아바타 편집기와 창고 선택 상태.
- 당근의 숲 PWA 오프라인 캐시에 공통 CSS 포함.
- `tests/ui-color-system.test.cjs`에서 모든 고정 색상과 의미별 연결을 검사한다.
