# 토끼 클릭 공격 복구 — v155

2026-09-08

## 확인된 문제

- 토끼/쥐 스프라이트의 클릭은 공격 버튼을 고정할 뿐 공격 의도를 만들지 않았다.
- `forest-state-updated`가 현재와 같은 `world` 장면을 알릴 때도 `setScene()`이 이동 경로와 예약 공격을 취소했다.
- 닉네임 편집 팝업 제거 후 두 보상 경로가 삭제된 `#profile-carrots`를 갱신했다. 실제 브라우저에서 포획 후 `Cannot set properties of null (setting 'textContent')`가 발생해 저장·완료 안내 전에 중단됐다.

## 변경

- 토끼/쥐 자체와 위에 나타나는 공격 버튼 모두 같은 클릭/터치 공격 경로를 사용한다. 먼 대상은 접근하고, 사거리 안에서 방향을 맞춘 다음 현재 무기 공격을 한 번 실행한다.
- 동일 장면의 저장·동기화는 이동/공격 의도를 보존한다. 실제 집/밭 장면 전환, 배치, 모달, 키보드 이동에 의한 취소는 유지한다.
- 삭제된 프로필 당근 표시 참조를 제거했다. 기존 상단/프리뷰 잔액 갱신, 효과음, 저장, 포획 메시지는 유지한다.
- 토끼 그림은 아직 교체하지 않았다. 귀여운 후보 탐색과 공격 버그 수정은 별도다.
- 웹/PWA 캐시와 두 수정 스크립트 버전을 갱신했다. 확인 주소: `/forest?rabbit=v155`.

## 회귀 검증

- `tests/forest-pointer-controls.test.cjs`: 스프라이트/버튼 × 마우스/터치 네 경로를 실제 `update → playAction → tryAttackRat`으로 실행. 이동 중 동일 장면 동기화가 있어도 토끼 포획·5당근 이벤트 한 번, 장면 전환 취소를 검증한다.
- `tests/forest-catch-reward.test.cjs`: 삭제된 프로필 요소가 없는 상태에서 실제 비동기 포획 핸들러로 토끼/펫 보상, 두 현재 잔액 표시, 저장, 종류별 메시지를 검증한다. 수정 전 오류 재현 후 통과했다.
