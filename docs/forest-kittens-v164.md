# 고양이 펫 — v164

## 적용 범위

사용자가 무료 범위부터 적용하도록 확인한 작업입니다. Last tick의
[공식 고양이 팩](https://last-tick.itch.io/animated-pixel-kittens-cats-32x32)에서
무료 `Free pack.zip`, `14 feb.zip`만 다운로드했습니다. 구매하지 않았습니다.

| 프리셋 | 펫 | 원본 구성 |
| --- | --- | --- |
| 3 달빛 마법사 | 눈꽃 고양이 | 흰색 |
| 4 숲의 엘프 | 리본 고양이 | 흰색 + 무료 빨간 리본 |
| 5 숲속 발명가 | 살구 고양이 | 치즈색 |
| 6 숲의 기사 | 구름 고양이 | 회색 |

1·2번 프리셋, 개인 코디, 현재 아바타를 초기화하지 않습니다. 3~6번 고정 카드의
펫만 갱신하며 기념사진에도 각 고양이가 함께 나옵니다. 기본 코디 마이그레이션
버전은 5로 유지하여 사용자의 현재 코디를 여성 기본룩으로 덮어쓰지 않습니다.

## 실제 동작

- 방향별 원본 걷기, 실제 앉은 자세.
- 정지하면 긴 휴식 사이에 짧은 입 움직임·하품·세수. 자동 울음 소리는 추가하지 않았습니다.
- 클릭/터치 먹이는 1,280ms 원본 먹기, 사냥 뒤 앞발 반응은 760ms.
- 앉기·먹기 중에는 사냥을 중단하고 발 위치를 유지합니다.
- 몸 전체의 흔들림·압축·기울이기 대신 원본 프레임만 사용합니다.
- 리본은 몸과 같은 셀·발 기준·배율로 겹쳐 그립니다.
- 모달·배치·숨겨진 탭·촬영 중에는 행동과 사냥 시계를 정지합니다.
- 기존 흰색/주황색 LPC 고양이 ID는 같은 색의 새 고양이로 연결됩니다.
  기존 강아지는 원본에 앉기 프레임이 없어 보행·정지까지만 유지합니다.

`forest-pets.js`가 Phaser, 스튜디오, 펫 카드, 2D 대체 화면, 기념사진의 공통
프레임 기준입니다. 새 PNG가 없는 환경에서도 기존 LPC 펫으로 안전하게 표시하며,
선택된 펫 ID나 사용자 저장 상태를 변경하지 않습니다.

## 소스 규격 및 설치

각 PNG는 352×1696, 11열×53행, 셀 32×32입니다. ASEPRITE에는 애니메이션
태그가 없으므로 팩에 포함된 공식 행 라벨과 Frame indexes 안내, 실제 불투명
픽셀을 대조했습니다. 원본을 재색칠하거나 재생성하지 않았습니다.

- 앉기: 0행, 6방향.
- 걷기: 4~11행, 방향별 4/4/8/8/6/6/6/6프레임.
- 먹기: 20~27행, 각 8프레임.
- 앉은 입 움직임/하품/세수: 28/32/36행.
- 앞발: 44~51행, 방향별 실제 존재하는 셀만 사용.

저장소 루트에서:

```powershell
.\scripts\import_forest_kittens.ps1 -Download
```

또는 공식 ZIP을 직접 받은 뒤:

```powershell
.\scripts\import_forest_kittens.ps1 -FreePackZip 'path\Free pack.zip' -ValentineZip 'path\14 feb.zip'
```

스크립트는 공식 무료 페이지에 노출된 파일명과 upload ID를 모두 검사합니다.
정확한 PNG 엔트리만 고정 경로로 추출하고 PNG 시그니처·규격을 확인합니다.
로그인·이메일·결제·브라우저 쿠키는 사용하지 않습니다.

## 라이선스와 제외 항목

개인/상업 게임 사용은 허용되지만 원본 자산의 별도 재배포/재판매는 금지된
커스텀 라이선스입니다. 원본 ZIP·PNG는 공개 Git에 포함하지 않고
`src/frontend/assets/animals/licensed-kittens/`에 로컬 설치합니다. 배포 담당자는
공식 파일을 직접 확보하여 게임의 일부로만 포함해야 합니다. 펫 메뉴와
`src/frontend/assets/animals/ATTRIBUTION.md`에 Last tick 출처를 표시했습니다.

무료 ZIP에는 펫 가구가 없습니다. 8유로 이상 전체 Kittens pack과 별도 3유로 이상
Room pack은 구입·다운로드하지 않았으며 창고에 빈 카드나 대체 가구를 넣지 않았습니다.

## 검증

원본 셀 범위·불투명 픽셀, 리본 일치, 이동/대기/먹기/사냥, 중복 보상 방지,
미리보기 즉시 반영, 저장 상태 보존, 기념사진 복원, 서비스워커 캐시 계약을
회귀 테스트합니다. 원본 PNG 검사는 로컬 설치본이 있을 때 실행하며 CI에는
라이선스 제한 원본을 테스트 픽스처로 넣지 않습니다.

확인 주소: `/forest?kittens=v164`.
