# Universal LPC 기반 아바타·펫 엔진

## 적용 범위

`당근의 숲` 아바타는 Universal LPC Spritesheet Character Generator의 공식 레이어만 사용해 동일한 `64×64` 프레임 규격으로 합성한다. 기존 완성형 프리셋과 자체 얼굴 합성은 제거했다. 몸·머리·얼굴·하의·신발·상의·헤어·안경·모자를 매 프레임 같은 좌표에 그리므로, 코디를 바꿔도 인접 스프라이트나 원래 의상이 비치지 않는다.

- 체형: 성인 남성·성인 여성·근육형·슬림형. 서비스 대상과 맞지 않는 아이·임산부 바디는 빌드와 화면에서 제외한다. 선택 체형을 실제로 지원하는 레이어만 목록에 표시한다.
- 공식 LPC 원본에서 성인 체형과 호환되는 얼굴·헤어·팔 장식·의상·신발·모자·안경·도구·무기·이동 보조 자산을 자동 생성한다. 상의 메뉴에는 티셔츠·셔츠·카디건·재킷처럼 몸통을 실제로 덮는 완성 의류만 표시한다. 신발 메뉴에도 발 전체를 덮는 운동화·구두·부츠·신발 갑옷만 표시하고, 양말·발끝 장식·샌들·슬리퍼처럼 축소 화면에서 맨발로 보이는 부분 레이어는 제외한다. 주머니·끈·소매·등짐·망토 장식처럼 다른 옷과 조립해야 하는 부분 레이어는 단독 상의에서 제외한다.
- 공식 생성기 순서에 맞춰 `체형 → 피부 → 얼굴 → 헤어 → 모자 → 팔 → 상의 → 하의 → 신발 → 도구 → 무기`로 구성한다. 얼굴 안에서는 얼굴형·표정·눈썹·코·특수 눈·주름을, 헤어·상의·하의·신발 안에서는 모양과 색을 각각 고른다.
- 피부·헤어·상의·하의·신발 색상 필터
- 얼굴 탭은 공식 LPC 머리형·표정·눈썹·코·특수 눈·주름을 하나의 목록으로 제공한다. 항목을 선택하면 해당 LPC 슬롯만 교체되어 다른 얼굴 요소와 함께 합성된다.
- 기본·걷기·달리기·앉기·점프·감정표현·수확·낚시·문 열기·공격 동작
- 공격 효과에 맞춰 검은 휘두르기, 화살은 사격, 마법은 주문 시전, 잎 칼날은 찌르기 동작을 사용
- 얼굴·헤어·안경·모자는 공식 LPC 원본의 방향별 프레임과 레이어 순서를 그대로 사용한다.
- 체형 카드는 실제 남성·여성·근육형·슬림형 바디를, 피부 카드는 선택 색이 머리·귀·손·몸에 적용된 민머리 바디를 렌더링한다. 이모티콘과 단색 원은 선택 미리보기로 사용하지 않는다.
- 앉기는 반복 재생하지 않고 마지막 자세를 유지하며 `X`를 다시 누르면 해제
- 아우라·순간 이펙트·탈것·펫을 별도 레이어로 유지

## 입력과 동작

- 플레이어 아바타는 공식 LPC 레이어 엔진만 사용한다. 이전 프리셋·모듈러·수제 아바타 아틀라스는 초기 로딩, 서비스 워커 캐시, 렌더링 실패 대체 경로에서 제외했다.
- LPC 매니페스트나 개별 레이어가 로딩 중이면 구형 캐릭터를 대신 표시하지 않고 잠시 숨긴다.
- 공식 앞치마는 흰 티셔츠 위에 겹쳐 그려 상체 노출과 동작 분리를 방지한다.
- 공식 휠체어의 방향별 2프레임은 팩 빌드 시 `idle`, `walk`, `run`, `sit` 행으로 정규화한다.
- 도구와 무기는 평상시 숨기고 `Q` 상호작용 또는 `Z` 공격 동안에만 해당 LPC 동작과 함께 표시한다.

| 입력 | 동작 |
| --- | --- |
| 방향키 / WASD | 4방향 걷기 |
| R + 이동 | 달리기 |
| Q | 가까운 대상에 따라 당근 수확·낚시·문 열기 |
| Z | 공격 모션 |
| 0 | 댄스 |
| X | 아바타와 펫이 함께 앉기·일어나기 |
| F | 보유 당근 1개를 펫에게 먹이로 주고 하트 표시 |
| E | 탈것 승하차 |

펫은 아바타 컨테이너에 고정하지 않는다. 플레이어의 최근 이동 좌표를 짧은 경로로 보관하고 약 `330ms` 뒤의 지점을 따라가며, 좌우 방향·보행 바운스·정지 호흡을 따로 표현한다. 춤에서는 좌우 이동과 점프·기울기를 함께 적용하고, 앉기에서는 플레이어 가까이 이동해 낮은 자세를 유지한다.

LPC 합성 캔버스의 실제 발바닥 좌표를 Phaser 컨테이너 원점에 맞춰 캐릭터 발과 그림자가 붙도록 한다. 남성·여성·근육형·슬림형 바디 원본을 선택하고 몸·공식 머리·얼굴 레이어에 같은 피부 색 필터를 적용한다. 얼굴 세부 요소는 바디와 같은 `64×64` 좌표계를 사용하며 헤어·안경·모자보다 먼저 그린다.

머리와 턱 위치는 공식 LPC 몸·머리 레이어의 공통 프레임 좌표를 따른다. 외부 캐릭터 세트로 교체할 때도 체형·피부·얼굴·헤어가 같은 프레임 규격과 방향별 앵커를 제공하는지 먼저 확인한다. 초상화 전용 또는 한 방향 전용 세트는 월드 이동 아바타 대체재로 사용하지 않는다.

휠체어 원본의 `64×64`, 방향별 2프레임은 표준 LPC `idle·walk·run·sit` 행의 필요한 칸 전체에 반복 배치한다. 탑승자의 몸은 앉은 자세를 유지하고, 이동 중에는 휠체어 레이어만 걷기 또는 달리기 행을 순환한다. 따라서 방향 전환이나 이동 프레임에서도 휠체어가 빈 프레임으로 사라지지 않는다.

## 재현

```powershell
.\.venv\Scripts\python.exe scripts/build_lpc_avatar_pack.py `
  --source "<Universal-LPC-Spritesheet-Character-Generator 경로>" `
  --output src/frontend/assets/lpc-pack
.\.venv\Scripts\python.exe scripts/build_lpc_pet_pack.py
node --check src/frontend/lpc-avatar-engine.js
node --check src/frontend/forest-phaser.js
.\.venv\Scripts\python.exe -m pytest -q tests/test_carrot_forest_pixel_game.py
```

생성 파일은 `src/frontend/assets/lpc-pack/`에 저장된다. `manifest.json`은 런타임 레이어·애니메이션 행을, `credits.json`은 각 원본 파일·저작자·라이선스를 기록한다. 새 아이템을 추가할 때는 빌드 스크립트의 카탈로그에 원본 레이어를 등록하고 pack을 다시 생성한다.

아이템 카드는 그림과 선택 상태만 시각적으로 노출하고 이름은 접근성용 `aria-label`에 유지한다. 동작 탭은 보유 여부와 단축키만 확인하는 읽기 전용이며, 대량 레이어는 선택 시점에 지연 로딩한다.

선택 전 미리보기 역시 이모티콘으로 대체하지 않는다. 체형·피부·얼굴·헤어·의상·신발은 해당 LPC 레이어가 합성된 캐릭터를 축소 렌더링하고, 색상 카드는 선택 색이 해당 부위에 적용된 캐릭터를 보여준다. 동작 카드는 실제 LPC 자세를, 말풍선 카드는 서비스에서 표시되는 도형을 캔버스에 직접 그린다.

일부 LPC 의상은 정지(`idle`)·달리기(`run`) 이미지를 제공하지 않는다. 이 경우 정지는 같은 방향의 `walk` 정지 프레임, 달리기는 같은 방향의 `walk` 순환 프레임으로 대체한다. 주문·공격 프레임을 일상 동작에 섞지 않으므로 몸과 옷이 서로 다른 자세로 분리되지 않는다. 편집기에는 현재 체형용 원본 레이어가 실제로 존재하는 항목만 표시하며, 평범한 티셔츠·셔츠·카디건을 목록 앞에 배치한다.

## 출처와 라이선스

- 원본 프로젝트: [Universal LPC Spritesheet Character Generator](https://github.com/liberatedpixelcup/Universal-LPC-Spritesheet-Character-Generator)
- LPC 에셋은 파일별로 CC0, CC-BY, CC-BY-SA, OGA-BY, GPL 등 조건이 다르다.
- 배포 전 `src/frontend/assets/lpc-pack/credits.json`의 저작자 표시와 라이선스 조건을 최종 확인해야 한다.
- 이 저장소의 자체 코드 라이선스가 개별 LPC 에셋의 라이선스 조건을 대체하지 않는다.
