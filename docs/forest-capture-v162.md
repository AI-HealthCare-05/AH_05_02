# v162 · 토끼와 쥐 포획 보상

- 토끼를 잡으면 당근을 정확히 1개 지급하고 `토끼가 당근 1개를 놓고 갔습니다.`를 안내한다. 필드의 보상 표시는 `+1 🥕`이다.
- 쥐를 잡으면 당근을 지급하지 않고 `쥐를 잡았습니다.`를 안내한다. 당근 보상 팝업은 만들지 않는다.
- 포획 결과는 게임 화면 상단에 4초 동안 표시한다. 기존 안내 전체를 되살리지 않으며, 클릭·터치 이동을 가로막지 않는다. 화면 읽기 알림은 기존 `game-status`에서 한 번만 전달하고, 기념사진 촬영 중에는 포획 결과 배너를 숨긴다.
- 직접 공격(Z), 마우스로 공격 버튼을 눌러 접근 후 공격, 펫의 자동 사냥 모두 같은 규칙을 사용한다. Bunbun과 Last tick 토끼에도 동일하게 적용한다.
- 보상은 포획 알림의 `amount`가 아니라 동물 종류로 결정한다. 현재 출현 기록과 포획 ID가 일치하면 출현 당시 종류를 우선한다. 이전 버전이 `amount: 5`를 보내도 추가 지급하지 않는다.
- 포획 ID를 저장 작업 전에 처리 완료로 기록하므로 중복 포획 알림이 와도 보상·효과음·안내는 한 번만 발생한다. 이전 포획 알림이 뒤늦게 도착해도 현재 다른 동물의 출현 기록은 지우지 않는다.
- 기존 당근 잔액과 저장 코디·배치 오브젝트는 초기화하지 않는다. 기존 보유량을 소급 조정하지 않고 이번 버전부터 포획 보상을 적용한다.

관련 검사: `forest-catch-reward.test.cjs`, `forest-game-animal-integration.test.cjs`, `forest-rabbit-behavior.test.cjs`, `forest-pointer-controls.test.cjs`, `test_carrot_forest_pixel_game.py`.
