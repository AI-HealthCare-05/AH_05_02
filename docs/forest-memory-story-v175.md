# 추억사진 연출 v175

## 화면 문구

- 촬영 카드의 `숲속 추억사진` 제목과 PNG 저장 방식 설명은 노출하지 않는다.
- 사진관을 닫는 `사진관에서 나가기`, 재촬영, 수동 저장 조작만 남긴다.
- 진행·오류 문구는 스크린 리더용 상태 영역에서만 알린다.

## 추억 연출

- 컬러 PNG를 먼저 2560×1440 오프스크린 렌더로 만든다.
- 저장이 준비된 뒤에만 실제 게임 캔버스가 5.2초 동안 흑백으로 변한다. 저장된 PNG에는 이 CSS 필터가 적용되지 않는다.
- 촬영 화면은 별도의 캘리그래피 문구를 겹치지 않고 장면과 흑백 전환에 집중한다.

## 쥐와 고양이

- 기념사진에는 쥐를 등장시키지 않는다.
- 프리셋을 따라온 네 고양이는 물가에서 꼬리를 말고 자기, 앉기, 발명의 준혁 앞에서 길게 누워 자기, 해결의 세준 앞에서 그루밍하기로 서로 다른 자세를 사용한다.
- 해당 고양이 원본 텍스처를 불러오지 못해도 LPC 흰 고양이가 같은 위치에 표시된다.
