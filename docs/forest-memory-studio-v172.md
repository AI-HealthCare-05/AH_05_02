# 기념사진 사진관 연출 v172

## 사용자 흐름

- 카메라를 누르면 프리셋 1~6과 숯속 동물이 당근집 앞에 모인다.
- 촬영이 끝나도 바로 필드로 복귀하지 않고 촬영 구도를 그대로 보여준다.
- `사진관에서 나가기`를 누르거나 Escape를 누를 때만 원래 필드 상태와 카메라로 복귀한다.
- `다시 찍기`는 기존 사진을 정리하고 새 촬영 세션을 시작한다.

## 컬러 원본과 추억 연출 분리

- 2560×1440 PNG는 화면 효과를 적용하기 전 오프스크린 렌더 텍스처에서 컬러로 캡처한다.
- 캡처가 완료된 뒤에만 실제 게임 캔버스에 5.2초 흑백 전환 연출을 적용한다.
- CSS 화면 효과는 저장 데이터에 들어가지 않으며, 다운로드되는 사진은 항상 컬러 PNG다.
- 동작 줄이기 설정에서는 긴 전환 애니메이션 대신 즉시 흑백 화면을 보여준다.
