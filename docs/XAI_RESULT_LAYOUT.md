# XAI 결과 영역 표시 규칙

- 분석 화면의 오늘이·내일이 설명 카드에 `result-xai.css`를 공통 적용한다.
- 제목 22px, 변수명 18px, 방향·변경 가능 여부 15px, 본문 16px 기준의 rem 단위를 사용한다. 큰 글씨 모드는 유지한다.
- 요인은 작은 방향 아이콘과 텍스트로 정렬하고 구분선으로 나눈다. 모바일에서는 여백과 아이콘만 축소한다.
- 긴 변수명과 설명은 줄바꿈한다. 고정 높이로 설명을 자르지 않는다.
- 승인·표시 허용·설명 검증 조건, SHAP 값, 요인 선택 및 모델 결과는 변경하지 않는다. 미준비 상태에서 임의 설명을 표시하지 않는다.
- 소개 화면은 실제 분석 화면과 구조가 달라 적용 대상에서 제외한다.
- 오늘이와 내일이의 방향이 다른 두 경우에는 비교 안내를 주황색 강조 카드로 표시하고, 제목과 핵심 안내 문장을 일반 설명보다 크게 표시한다. 동일 방향 결과의 일반 안내에는 이 강조를 적용하지 않는다.
- 모델별로 위험 범주에 맞춰 주의/긍정 요인을 2:1로 제한한다. 오늘이에 이미 표시된 같은 변수가 내일이에서 반대 방향이면 내일이 공개 후보에서 제외하고 다음 순위 요인을 사용한다.
- 설명 문구에는 위·아래 화살표 문자를 반복하지 않는다. 주의 방향은 빨간색, 긍정 방향은 초록색으로 표시한다. 내부 `modifiable` 메타데이터는 사용자 화면에 노출하지 않는다.
