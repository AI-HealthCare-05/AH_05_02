# 기념사진 — 당근집 앞 단체사진 (v165)

## 변경 범위

- 기념사진에 등장하는 두 번째 프리셋의 별명을 `꾸준한 당근`에서 `꾸준한 상균`으로 변경했다. 개인 닉네임, 저장된 옷장 이름과 코디는 변경하지 않는다.
- 별도 배경 이미지를 합성하지 않고, 실제 메인 필드의 당근집 앞을 촬영한다. 집의 잎 지붕과 문 앞 길이 보이는 월드 영역 `(0, 0, 640, 360)`을 16:9로 담아 2560×1440 PNG로 저장한다.
- 여섯 친구는 집 앞 길을 따라 모이고, 동물과 고양이도 그 앞에 배치한다. 집결 연출은 가로 방향으로만 움직여 연못 쪽으로 내려가지 않게 한다.
- 사진 영역과 겹치는 배치 가구는 실제 표시 경계로 판정하여 촬영 중에만 숨긴다. 촬영/취소 뒤에는 원래 가시성, 플레이어 위치, 카메라와 입력 상태를 복구한다. 저장된 가구 배치는 건드리지 않는다.
- 필드의 사진기 위치 및 클릭 촬영 방식은 그대로 유지한다.

## 확인 항목

- 기념사진 전용 별명, 원본 코디 불변, 프레임/PNG 크기, 집결 위치와 큰 가구의 경계 판정을 자동 테스트한다.
- 촬영 성공/실패/취소 뒤 상태 복구 및 Canvas/WebGL 저장 경로의 기존 테스트를 유지한다.
- HTML 스크립트와 서비스 워커 캐시 버전을 함께 갱신한다.
