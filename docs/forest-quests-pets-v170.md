# 퀘스트 기록·고양이 휴식/장비 — v170

## 오늘의 퀘스트

- `자세히 보기`의 모든 직접 기록 양식에 선택형 상세 메모를 제공한다. 식단처럼
  서버가 내용을 요구하는 항목은 기존 필수 조건을 유지한다.
- 직접 기록(T3) 과제는 `인증하기` 한 번으로 남은 회차의 수행 확인과 상세 메모를
  기존 세션 API에 저장한다. 서버 응답이 완료일 때만 `인증완료`가 표시된다.
- 사진(T1/T2), 실제 음료량(H02), 영양표시(D02)는 값이나 파일을 만들지 않는다.
  `인증하기`가 상세 입력을 열고 실제 자료를 받은 뒤 기존 검증을 거친다.
- `나에게 맞게 다시 설정하기`를 누르기 전에는 설정·안전 안내·보상 설명을 숨긴다.

## 고양이

- 공식 무료 색상은 흰색·회색·치즈색 3종 모두 제공한다.
- 정지 시간 10/30/60/90/120초에 원본 행 0/12·13/14·15/16·17/18·19를
  사용해 앉기, 앞발 넣기, 앉아 자기, 머리 내리기, 쭉 뻗어 자기로 전환한다.
- 공식 무료 `Winter accessories.zip` 4종과 `14 feb.zip` 11종을 펫 카테고리의
  `고양이 장비 · 공식 무료 홀리데이` 그룹에 추가한다. 장비는 몸과 같은 셀·방향·
  뒤집기·발 기준을 사용한다.
- 8유로 이상 전체 고양이 팩과 별도 유료 방/가구 팩은 포함하지 않는다.
  원본 PNG는 라이선스상 Git에 넣지 않고 공식 다운로드 설치 스크립트로만 받는다.

## 조작 패드

- 공격 버튼의 별도 호박색·반짝이·키 배지를 제거하고, 상호작용 등 다른 행동 버튼과
  같은 형태와 `공격 (Z)` 표기를 사용한다. 단축키와 공격 동작은 바꾸지 않는다.
