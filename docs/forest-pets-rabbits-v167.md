# 움직이는 펫 목록 정리와 토끼 색상 확장 — v167

## 변경 범위

- 사용자 정정에 따라 **정지 그림 펫 6종은 복원하지 않는다**.
  펫 메뉴는 기존 LPC 보행 3종과 새 고양이 4종, `없음` 포함 8개 카드다.
  자세한 목록과 동작 제한은 `forest-pet-restoration.md` 참고.
- 토끼: 원본 2종 + 게임 내 털색 변형 6종 = 8종을 기존 출현 순환에 연결.
  몬스터 밀도나 주기는 바꾸지 않고, 기존 쥐도 유지한다.
- 코디, 저장된 펫 ID, 프리셋 3~6의 고양이, 배치 오브젝트, 퀘스트는
  초기화하거나 마이그레이션하지 않는다.
- 토끼 포획은 당근 +1, 쥐 포획은 보상 없음. 클릭·키보드·펫 자동 포획과
  중복 보상 방지 경로는 그대로 유지한다.

## 토끼 색상과 모션

| 원본 팩 | 원본 | 게임에서 추가한 털색 | 원본 동작 범위 |
| --- | --- | --- | --- |
| Bunbun | 회백색 얼룩 | 크림, 갈색, 검정 | 8동작 / 18개 토끼 셀 |
| Last tick | 회색 | 흰색, 크림, 갈색 | 46그룹 / 219개 셀 |

공식 ZIP은 각각 원본 색상 1종만 제공한다. 추가 색상은 다운로드한 추가
원화가 아니라 `forest-animals.js`의 런타임 팔레트다. 털의 검증된 RGB만
교체하고 눈·윤곽선·분홍 귀·당근·알파 값은 원본 그대로 둔다.
원본 PNG/ZIP을 수정하거나 색상별 PNG를 새로 저장하지 않는다.

`registerRabbitSkins`가 Phaser preload 후 32×32 프레임의 파생 텍스처 6종을
한 번 등록한다. 각 변형은 원본 가족의 프레임 순서·타이밍·이동 방향·
동작 줄이기 설정을 그대로 따른다. 잘못된 이미지 크기나 준비 오류는 해당
변형만 건너뛰고, 정상 원본 또는 기존 LPC 대체 토끼로 게임을 계속한다.

출처와 배포 제한: `src/frontend/assets/animals/ATTRIBUTION.md`.
원본 팩은 Git에서 제외하며 기존 `scripts/import_forest_rabbits.ps1`로 설치한다.

## 검증

- 사용자 정정을 반영한 전체 Forest/챌린지 설정 Node 테스트 **338개 통과**.
- Forest Python 및 챌린지 API 테스트 **79개 통과**.
  기존 FastAPI 사용 중단 예고 경고 3건은 별도 사항이다.
- 실제 원본 PNG에서 18/219 셀 전체의 털색 치환, 알파·눈·귀·당근 보존,
  원본 불변, 프레임 경계, 전 동작 순환, 파생 텍스처 재등록 및 오류 격리 검증.
- 기존 보행/새 고양이 동작, 과거 ID 호환, 선택 변경,
  먹이·포획·숨김·프리셋·기념사진 경로 회귀 검증.
- 로컬 브라우저에서 8개 선택지, 정지 그림 메뉴 제외, 과거 저장 ID가
  현재 고양이 카드의 선택 상태로 올바르게 표시되는 것을 확인했다.
- 토끼 검수 화면에서 원본과 털색 변형 8종의 실제 표시 및 동작 선택 확인.
  게임과 검수 화면의 브라우저 경고·오류 로그는 비어 있었다.
- HTML 및 오프라인 캐시를 v167-2로 함께 갱신. 기존 정지 그림 펫,
  아바타/아우라 자산은 재도입하지 않는다.
