# 숲 챌린지 완료 연출 v171

## 화면 동작

- 오늘의 퀘스트는 V3 영역을 `물`, `식단`, `운동`으로 짧게 표시한다.
- `나에게 맞게 다시 설정하기`는 퀘스트 3개 아래에서 설정·안내를 함께 여닫는다.
- MVP에서는 `인증하기`를 누르는 즉시 해당 일자의 카드가 `인증완료`로 바뀐다.
- 자세히 보기에서 인증 전이나 인증 후에 작성한 선택 기록은 일자·과제 ID와 함께 로컬 MVP 기록으로 보관한다.
- 서버가 직접 기록형 과제를 받을 수 있으면 기존 세션 API에도 같은 기록을 동기화한다.
- 완료 연출은 추가 당근 지급이 아니라 실천을 응원하는 시각 피드백이다.

## 이미지 생성 기록

- 도구: Codex 기본 제공 `imagegen`
- 참조: `carrot-forest-world-v6.png`
- 공통 프롬프트 요약: 따뜻하고 선명한 고해상도 픽셀 동화풍 당근 숲, 프리셋 1~6을 닮은 농부·사냥꾼·달빛 마법사·숲의 엘프·근육형 발명가·기사 여섯 명, 글자와 UI 없이 협력하는 장면.
- 개별 프롬프트: 물주기, 퇴비/거름주기, 잡초 제거가 각각 명확히 보이도록 서로 다른 구도를 사용한다.
