# KLoSA·국민건강영양조사 전처리 결과 공유

## 1. 작업 요약

KLoSA 1–10차와 국민건강영양조사(KNHANES) 2016–2024년 원자료를 공식 코드북 기준으로 전처리했습니다. 두 조사는 관측 구조와 예측 시점이 달라 행 단위로 합치지 않고, 공통 변수의 의미·단위·결측 규칙·역할을 통합 변수 명세로 연결했습니다.

- KNHANES: 67,019건
- KLoSA: 74,834개 패널 관측행
- 중복 키: 0건
- 전처리 테스트: 10개 통과(전체 저장소 테스트 21개 통과)
- 원자료 및 행 단위 정제 데이터: GitHub에 업로드하지 않음
- GitHub 공유 범위: 재현 코드, 변수 명세, 원본 무결성 기록, 집계 품질보고서, 전처리 프로토콜

## 2. 모델 데이터 구성

### KNHANES

- 대상: 19세 이상·40세 이상·65세 이상 3개 연령 집단
- 질환: 고혈압·당뇨병
- 타깃: 공식 임상상태 파생변수에 따른 현재 위험 선별
- 대상자 조건: 해당 질환을 진단받지 않았다고 명시적으로 응답하고 타깃이 관측된 사람
- 분할: train 2016–2020 / validation 2021–2022 / test 2023–2024

| 질환 | 연령 | 표본 수 | 양성 수 | 양성률 |
| --- | ---: | ---: | ---: | ---: |
| 고혈압 | 19+ | 38,905 | 4,333 | 11.14% |
| 고혈압 | 40+ | 25,737 | 3,662 | 14.23% |
| 고혈압 | 65+ | 6,709 | 1,308 | 19.50% |
| 당뇨병 | 19+ | 44,828 | 1,945 | 4.34% |
| 당뇨병 | 40+ | 32,089 | 1,788 | 5.57% |
| 당뇨병 | 65+ | 10,774 | 761 | 7.06% |

### KLoSA

- 연령별로 나누지 않고 단일 패널 모델로 구성
- 질환: 고혈압·당뇨병
- 타깃: 질환 이력이 없는 사람이 인접한 다음 조사차수에서 신규 진단을 받았는지 여부
- 분할: 동일 PID가 한 split에만 포함되도록 그룹 분할

| 질환 | 분석 표본 수 | 양성 수 | 양성률 |
| --- | ---: | ---: | ---: |
| 고혈압 | 38,235 | 2,315 | 6.05% |
| 당뇨병 | 51,807 | 1,299 | 2.51% |

## 3. 데이터 누수 방지

다음 변수는 타깃 구성·적합성 확인·감사용으로만 보존하며 모델 입력에서 제외했습니다.

- 수축기·이완기 혈압
- 공복혈당·HbA1c
- 고혈압·당뇨병 진단 및 복약 정보
- 공식 질환상태 파생변수
- KLoSA 과거·현재 질환사건 변수

결측치 대치, 스케일링, 범주 인코딩도 정제 파일 전체에서 미리 학습하지 않았습니다. 모델 학습 단계에서 각 train split으로만 적합합니다.

본 결과는 의료 진단이나 처방이 아니라 위험 선별과 건강교육을 위한 모델 개발 자료입니다. KNHANES와 KLoSA는 조사설계와 타깃 시점이 다르므로 두 데이터의 행을 직접 결합하거나 양성률·성능을 단순 비교하지 않습니다.
