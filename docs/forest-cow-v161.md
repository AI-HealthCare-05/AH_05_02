# v161 · 젖소의 휴식·풀 먹기·쓰다듬기

- 평소 12~22초 동안 쉬다가 약 3.2초 동안 고개를 숙여 풀을 먹고 다시 쉰다. 개체별 시드로 주기를 분산한다.
- 머리를 클릭하면 풀 먹기를 중단하고 고개를 든 뒤 앞을 잠깐 바라본다. 몸을 클릭하거나 Q로 토닥이면 제자리에서 발을 잠깐 움직인다. 클릭 반응에 먹기 동작을 반복 재생하지 않는다.
- 기존 로컬 LPC `lpc-cow-eat.png`와 `lpc-cow-walk.png` 원본 프레임을 사용한다. 몸 전체를 흔들거나 늘리지 않고, 저장된 배치 위치·회전·크기를 유지한다. 풀/땅 이미지를 젖소에 붙이지 않는다.
- 클릭·Q에는 기존 음메 효과음을 유지한다. 자동으로 풀을 먹을 때는 소리를 반복 재생하지 않는다. 기존 효과음 음량·음소거를 따른다.
- 연속 클릭은 짧게 제한한다. 실내·숨긴 탭·배치·기념사진 중에는 행동 시간을 진행하지 않으며 재개 시 긴 시간이 한꺼번에 반영되지 않는다. 동작 줄이기는 정지 자세를 사용하고 반응을 예약하지 않는다.
- 다른 설정이나 오브젝트를 저장해도 젖소의 일시적인 행동 상태는 보존한다. 실제 상태 저장 형식과 창고 아이템 코드는 변경하지 않는다.

공유 동작 함수는 `ForestAnimals.createCowState/updateCowState/touchCowState/cowPose`이며 Phaser와 2D 대체 렌더러가 동일하게 사용한다. 기존 `cowFrame`은 썸네일과 기념사진의 호환성을 위해 유지한다. 자산 라이선스는 기존 `src/frontend/assets/animals/ATTRIBUTION.md`를 따른다.

관련 검사: `forest-cow-behavior.test.cjs`, `forest-cow-fallback.test.cjs`, `forest-object-motion.test.cjs`, 기존 동물·사진·배치·오프라인 회귀 검사.

2026-09-08 검증: 전체 Node 숲 검사 250개, Python 게임 검사 56개 통과. 브라우저에서 기존 분수·리버덕·바람개비를 유지한 채 젖소를 빈 잔디에 배치하고, 자동 고개 숙이기, 머리 클릭 시 먹기 중단/고개 들기, 몸 클릭 시 발 동작과 각각의 상태 안내를 확인했다. error/warn 없음. 검증용 1440×900 viewport는 확인 후 해제했다.
