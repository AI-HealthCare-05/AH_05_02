# 조작 버튼 배치와 공격 피드백 — v156

2026-09-08

## UI 배치와 복원

- 좌측 하단 조작 패널 머리글은 `버튼 숨기기(8) | 초기화(9) | UI 숨기기(0)` 순서다. 확대/축소 영역의 UI 버튼은 제거했다.
- 동일한 3열 `minmax(0, 1fr)` 그리드, 너비 100%, 높이 36px을 세 버튼에 공통 적용한다. 모바일에서도 열 비율과 높이는 유지하며 필요한 경우 글자만 줄바꿈한다.
- 패널 머리글 폭을 명시해 UI를 숨겨도 복원 버튼 폭이 달라지지 않게 한다. 모바일에서 닉네임이 버튼 글자를 가리지 않도록 조작 패널을 이름표보다 위에 그린다.
- UI 숨김은 조작 패드와 8/9 버튼을 감추지만 0 버튼과 그 조상은 감추지 않는다. `UI 보이기(0)`를 누르거나 0 단축키로 복원할 수 있다.
- UI를 숨길 때 기존 채팅 닫기 동작이 포커스를 게임 캔버스로 돌려 WASD 이동을 유지한다. 복원 버튼은 클릭·Tab·0 단축키로 접근할 수 있다. 기존 입력창·모달·IME·조합키·자동반복 예외는 유지한다.

## 공격 피드백

- 조작 패드의 공격 버튼은 따뜻한 호박색, 작은 반짝이 아이콘, Z 키 배지로 구분한다. hover 밝기, 키보드 focus 테두리, 눌림 음영을 제공하며 기본 동작과 단축키는 그대로다.
- 동물 위 Phaser 공격 버튼은 둥근 판과 얇은 하이라이트를 갖는다. 포인터를 올리면 밝아지고, 누르면 짧은 음영과 1px 눌림으로 반응한다.
- 동물/공격 버튼 클릭으로 접근하는 동안 `↗ 접근 중…`과 선택 테두리를 표시한다. 글자가 바뀌어도 Text의 112×38 월드 단위 크기와 클릭 영역은 고정된다. 화면 좌우 가장자리에서 버튼이 잘리지 않도록 위치를 제한한다.
- `prefers-reduced-motion: reduce`에서는 CSS 전환과 공격 버튼의 1px 이동을 없애고 색상 피드백만 유지한다. 반복 바운스나 새 타이머·트윈은 추가하지 않았다.
- 동물 클릭/터치 → 접근 → 사거리 68 안에서 방향 정렬 → 기존 장비 공격 → 포획/5당근 한 번의 v155 동작은 수정하지 않았다. 동일 장면 저장의 접근 보존, 모달·배치·실제 장면 변경·수동 이동의 취소도 유지한다.

## 회귀 검증

- `tests/forest-hud.test.cjs`: 머리글 순서/단일 UI 버튼/동일 크기 CSS, 복원 버튼과 0 단축키, 공격 버튼의 접근성과 reduced-motion 스타일.
- `tests/forest-pointer-controls.test.cjs`: 마우스/터치 × 동물/버튼의 실제 업데이트·공격·포획 4경로, 고정 클릭 영역, hover/pressed/접근 상태, reduced-motion, 가장자리, 배치/포획 시 판과 글자의 동시 숨김.
- Phaser 테스트는 실제 사용하는 Graphics·Text 메서드만 제공하는 명시적 모의 객체를 사용하며, 무조건 성공하는 Proxy는 사용하지 않는다.

실행: `node --test tests/forest-hud.test.cjs tests/forest-pointer-controls.test.cjs tests/forest-ui-contract.test.cjs`.

## 실제 브라우저 확인

- `http://127.0.0.1:8012/forest?ui=v156`에서 기존 서비스 워커의 오래된 CSS가 섞이는 것을 확인했고, CSS 버전 갱신 후 다시 검증했다.
- 1280×720 데스크톱에서 세 버튼 각각 82×36px, 390×844 모바일에서 각각 72.6640625×36px로 같은 크기였다.
- 모바일에서 조작 패드 숨김 → UI 숨김 → Tab으로 복원 버튼 선택 → Space로 복원 성공. 조작 패드의 접힘 상태는 보존되며, UI 복원 버튼은 숨김 전후 같은 폭이다. 0 단축키의 숨김/복원도 확인했다.
- 공격 버튼을 Tab으로 선택하면 3px 갈색 포커스 테두리와 밝은 배경이 나타난다. 브라우저 오류·경고 로그는 비어 있었다.
- 검증 화면은 `tmp/ui-v156-desktop.png`, `tmp/ui-v156-mobile.png`에 저장했다. 임시 모바일 화면 크기를 원상복구하고 검증용 탭을 닫았다. 저장된 코디나 배치는 조작하지 않았다.
- 최종 v156-2 캐시·22개 새 이미지 통합 후 전체 Node forest 테스트 143개 통과, Python forest 게임 테스트 56개 통과. 마지막 CSS 폭/겹침 보정 후 관련 HUD·포인터·채팅 테스트도 통과했다.
