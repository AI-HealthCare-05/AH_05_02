# 간당간당 프론트엔드 MVP 재현·리뷰 가이드

## 변경 목적

- 대시보드에 기능을 한꺼번에 노출하지 않고 `홈`, `챌린지`, `리포트`, `함께하기`, `건강도구`로 분리한다.
- 결과 설명 화면에 해부도가 아닌 친근한 3D 캐릭터형 `내 생활습관 지도`를 제공한다.
- 일러스트는 질환 발생 부위나 모델 영향도를 표현하지 않고 사용자가 입력한 생활습관을 찾는 탐색 장치로만 사용한다.
- 3D 캐릭터는 생년월일로 계산한 20대·30대·40대·50대·60대·70대 이상 연령 구간과 선택한 성별에 따라 전환되고, 키와 몸무게 입력값을 이용해 높이와 폭을 제한된 범위에서 참고 조정한다.

## 로컬 재현

저장소 루트의 PowerShell에서 실행한다.

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\scripts\run_mvp_demo.ps1
```

브라우저에서 `http://127.0.0.1:8000/`을 연다.

## 화면 확인 순서

1. 서비스 안내에서 `시작하기`를 선택한다.
2. 신규 계정을 생성하거나 기존 개발 계정으로 로그인한다.
3. 건강정보 동의와 이용 가능 여부 확인을 완료한다.
4. 건강·생활습관 정보를 입력하고 개발용 예측을 완료한다.
5. `결과 설명` 화면에서 `내 생활습관 지도`의 1~4번을 선택한다.
6. 4주 챌린지를 시작하고 `나의 건강 홈`으로 이동한다.
7. 홈·챌린지·리포트·함께하기·건강도구 메뉴가 각각 독립 화면으로 전환되는지 확인한다.

## 리뷰 체크리스트

- [ ] 홈 화면에는 핵심 요약 3개와 오늘 할 일이 우선 표시된다.
- [ ] 상세 기능은 다섯 개 메뉴로 분리되며 기존 폼과 API 연결이 유지된다.
- [ ] 키·몸무게로 계산한 BMI와 허리둘레는 입력 확인용 수치로만 표시된다.
- [ ] 일러스트에 진단 부위·장기 이상·SHAP 영향도라는 표현이 없다.
- [ ] 생활 리듬·활동·체형·걷기 항목을 키보드와 버튼으로 선택할 수 있다.
- [ ] 성별 변경 시 여성형·남성형 캐릭터가 전환된다.
- [ ] 생년월일 변경 시 만 나이에 해당하는 10년 단위 연령대 캐릭터가 전환된다.
- [ ] 키·몸무게 변경 시 발이 잘리지 않은 상태에서 캐릭터의 높이·폭이 완만하게 조정된다.
- [ ] 모바일에서 메뉴를 가로로 탐색하고 일러스트가 한 열로 배치된다.
- [ ] 전체 Pytest와 JavaScript 문법 검사가 통과한다.

## 의료·개인정보 영향

- 예측 결과를 진단·처방으로 표현하지 않는다.
- 임의 생활습관 규칙을 실제 모델 설명이나 SHAP 결과로 표시하지 않는다.
- 추가 개인정보를 수집하거나 외부 서비스로 전송하지 않는다.
- 웨어러블·식단·OCR은 실제 제공자 연동 전까지 개발용 어댑터임을 표시한다.
