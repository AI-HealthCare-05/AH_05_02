# v153 숲 그림체 교체 기록

2026-09-07. 기존 오브젝트 코드·저장 좌표·보유 내역은 유지하고 그림만 교체했다.

## 생성 경로와 결과

내장 ImageGen으로 각각 독립된 투명 배경 PNG를 생성했다. 하나의 합성 시트에서 여러 물건을 잘라내지 않는다. 원본을 검토한 뒤 아래 위치에 복사했으며 실행 시 공통 프레임으로 정규화한다.

- `src/frontend/assets/furniture-v153/`: 24개 독립 가구 PNG
- `src/frontend/assets/carrot-forest-world-v6.png`: 배치 가능한 빈 공간을 확보한 메인 필드
- `src/frontend/assets/carrot-forest-home-v3.png`: 아래쪽 독립 문 그림을 제거한 실내

가구는 허수아비 1024×1536, 나머지 1254×1254 RGBA다. 두 배경은 1536×1024다. 해상도 확대와 게임 카메라 배율은 별도로 처리한다.

## 최종 프롬프트 구성

공통 방향은 사용자가 제공한 당근의 숲 포스터의 따뜻한 동화풍 픽셀 일러스트다. 이끼·올리브·세이지 초록, 당근 주황, 따뜻한 참나무와 크림색, 손으로 그린 듯한 픽셀 질감, 게임의 기존 내려다보는 시점을 요청했다. 한 이미지에는 지정된 물건 하나만 넣고 전체 실루엣, 여백, 투명 배경을 유지하도록 지시했다. 글자·프레임·다른 물건·배경·잔디 판은 넣지 않는 조건을 사용했다.

## 고정 구조와 움직임

분수는 물의 색·밝기만 변하며 돌은 고정된다. 바람개비는 날개 부분의 색만 순환하고 막대나 이미지 전체를 회전하지 않는다. 모닥불은 같은 꺼진 받침 위에 별도 불꽃을 겹친다. 오리는 자체 투명 이미지에 작은 움직임만 적용한다. 상세 API와 픽셀 검증은 [독립 아트 파이프라인](forest-individual-art-pipeline.md)을 참고한다.

젖소·토끼는 생성 이미지 대신 라이선스가 확인된 LPC 애니메이션을 사용했다. 출처와 저작자 표시는 [동물 에셋 기록](FOREST_ANIMAL_ASSETS.md)과 `src/frontend/assets/animals/ATTRIBUTION.md`에 보존했다.

## 확인 범위

24개 PNG의 존재·RGBA·투명 모서리·중복 없는 매니페스트·오프라인 캐시를 검사한다. 분수 고정 픽셀, 바람개비 색 분리, 모닥불 받침 유지와 프레임 격리를 자동 테스트한다. 저장된 사용자 배치는 지우지 않는다. 새로 밝아진 배경에 구형 오브젝트가 잠시 표시되지 않도록 전체 독립 이미지 로딩 이후에 게임을 공개한다.
