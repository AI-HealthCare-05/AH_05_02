# 연령대별 임계값 및 3단계 위험구간 실험 보고서

## 결론

- KNHANES의 전역 임계값 `0.02791`을 연령대별 임계값으로 교체하면 Test 전체 Specificity가 `0.496 → 0.608`로 개선되고, 양성 판정 비율은 `52.0% → 40.6%`로 감소했다.
- 그 대가로 Test Recall은 `0.890 → 0.723`으로 낮아졌다.
- 65세 이상은 Specificity가 `0.202 → 0.612`로 크게 개선됐지만 Recall은 `0.938 → 0.670`으로 감소했다.
- 검증셋만으로 만든 `낮음·주의·높음` 구간은 모든 연령대에서 실제 양성률이 순서대로 증가했다.
- KLoSA는 관찰 연령이 45세 이상이고 신규 진단 사건이 적으므로 연령별 임계값을 운영 정책으로 채택하지 않고 단일 임계값의 연령별 성능만 감사한다.
- 이 결과는 내부 실험이며 의료 진단 기준이나 개인 확정 발병확률로 사용하지 않는다.

## 실험 원칙

- 모델과 확률 보정기는 이전 전체 표본 실험의 `Stacking + Sigmoid`를 고정했다.
- 연령대는 `19~44세`, `45~64세`, `65세 이상`으로 구분했다.
- 임계값은 Validation에서만 산출하고 Test에는 고정 적용했다.
- 기본 정책은 연령군마다 `Specificity ≥ 0.60`을 만족하는 값 중 Recall이 가장 높은 임계값이다.
- Test 결과를 보고 임계값이나 모델을 다시 선택하지 않았다.

다음 표는 정책 선택을 위한 탐색 결과다. Test 결과를 보고 특정 행을 소급 채택하면 안 된다.

| 0.55 | 0.759 | 0.555 | 0.123 | 0.458 |

목표 Specificity가 높아질수록 거짓 경고는 감소하지만 놓치는 위험군이 증가한다. 다음 확증 실험의 정책 목표는 Test를 다시 보지 않고 서비스 목적과 오류 비용을 먼저 합의한 뒤 사전등록해야 한다.

## 낮음·주의·높음 구간 후보

- 낮음 경계: Validation Recall을 0.90 이상 유지하는 임계값
- 높음 경계: Validation Specificity를 0.80 이상 확보하면서 낮음 경계보다 높은 임계값
- 두 경계 사이: 주의

| 연령대 | 낮음 경계 | 높음 경계 | Test 낮음 양성률 | Test 주의 양성률 | Test 높음 양성률 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 19~44세 | 0.01851 | 0.02418 | 0.28% | 0.69% | 4.96% |
| 45~64세 | 0.02700 | 0.09200 | 1.56% | 4.57% | 9.72% |
| 65세 이상 | 0.03600 | 0.12500 | 2.26% | 6.79% | 12.00% |

세 연령대 모두 `낮음 < 주의 < 높음` 순으로 관찰 양성률이 증가했다. 다만 19~44세 주의군은 Test 144명 중 양성 1명으로 불안정하므로 부트스트랩·외부검증 전에는 화면 정책으로 확정하지 않는다.

## 다음 결정

1. KNHANES의 다음 사전등록 후보로 `연령대별 Specificity 0.60 정책`을 사용할지 팀 합의한다.
2. 3단계 위험구간은 의료 진단명이 아니라 `생활습관 안내 강도`로만 표현한다.
3. 연도별·연령별 부트스트랩 신뢰구간과 외부검증을 완료하기 전에는 개인 화면에 확률값을 노출하지 않는다.
