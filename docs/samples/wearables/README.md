# Wearable test fixtures

이 폴더의 파일은 전처리 개발과 테스트를 위한 **합성 데이터**입니다.
실제 사용자 정보나 의료 데이터가 아니며, 모델 성능 평가나 의료적 판단에 사용하지 않습니다.

- `apple_health_export_sample.xml`: Apple Health `export.xml` 형태의 예시
- `android_health_connect_sample.json`: Android Health Connect Record 형태의 예시

공통 정제 결과에는 원본 출처, 기기, 기록 방식, 시간대, 단위와 품질 플래그를 보존합니다.
