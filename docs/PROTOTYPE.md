# 웹서비스 프로토타입

## 구현 범위

- 사용자 흐름: 서비스 안내 → 가입·건강정보 처리 동의 → 적합성 확인 → 건강정보 입력 → 당뇨 3단계 위험 선별 결과 → 위험·보호 요인 → 4주 챌린지 선택 → 일일 기록 → 대시보드
- 백엔드: FastAPI와 메모리 저장소
- 프론트엔드: FastAPI가 제공하는 반응형 HTML/CSS/JavaScript
- 추론: `MockDiabetesInferenceAdapter`의 결정적 mock 계산
- 확장: `disease_type`을 유지하며 고혈압 모델 상태를 `planned`로 노출

## 실행

```bash
python -m uvicorn src.backend.main:app --reload
```

브라우저에서 `http://127.0.0.1:8000`을 연다. OpenAPI 문서는 `http://127.0.0.1:8000/docs`에서 확인한다.

## 프로토타입 한계

- 계정, 동의, 건강정보, 예측, 챌린지 기록은 서버 메모리에만 저장되며 재시작 시 삭제된다.
- 비밀번호는 형식만 확인하고 저장하지 않는다.
- mock 추론은 화면·API 통합 검증용이며 임상 모델이나 의료 예측이 아니다.
- 공복혈당 입력값은 저장되지만 mock 점수 계산에는 사용하지 않는다.
- 챌린지는 일반 건강교육 예시이며 개인별 치료나 약물 조언이 아니다.

## 안전·접근성 기준

- 모든 결과 화면에 진단·처방이 아니라는 안내를 표시한다.
- 진단 이력, 혈당강하제 복용 또는 긴급 증상이 있으면 예측 흐름을 중단하고 의료기관 상담을 안내한다.
- 기본 본문 18px, 고대비, 주요 입력·버튼 44px 이상, 키보드 초점, 텍스트와 색상 중복 표현을 적용한다.

## 검증

```bash
pytest -q
```

테스트는 전체 사용자 흐름, 미성년자·기진단자 차단, mock 표시, 고혈압 미구현 상태, 기본 접근성 문구를 확인한다.
