# 날씨·시간 및 전체화면 (v137)

- 승인된 시안 기준으로 맵 위에 지역·날씨·기온·한국 시간을 표시한다. 날씨는 표시 전용이며 비·눈 필드 효과는 없다.
- 상세 주소를 외부로 전송하지 않는다. 잠원동 대표 좌표 37.51799, 127.01285를 사용하며 건물 관측값이 아닌 **인근 모델 기반 날씨**임을 표기한다.
- 좌표 근거: https://geographic.org/geographic_names/name.php?c=south_korea&fid=3526&uni=10598832
- 날씨: https://open-meteo.com/en/docs (`temperature_2m`, `weather_code`, `Asia/Seoul`). 서버 캐시 10분, 실패 재시도 간격 1분. 장애 시 1시간 이내 이전 값은 이전 정보라고 표시하고, 그보다 오래되면 연결 대기를 표시한다. 무료 API의 상업 배포 조건은 출시 전 재확인한다.
- `GET /api/v1/forest/weather`: 로그인 없이 고정된 지역 날씨만 반환. 사용자 위치 입력이나 임의 외부 URL을 받지 않는다.
- 종소리: 화면이 활성 상태로 정각을 통과할 때 한 번. 시작·복귀 시 밀린 종소리를 재생하지 않는다. 브라우저 오디오 정책에 따라 첫 클릭/키 입력 이후 작동하며 기존 효과음 음량·음소거를 따른다. 외부 음원이 아닌 Web Audio 합성 벨이다.
- 시간 효과 ON: 05시(.30), 06시(.16), 07시(0), 18시(.16), 19시(.30), 20시(.42) 음영으로 부드럽게 전환. 그 외 심야는 .42, 주간은 0. 전환 알림은 6초 후 사라진다. 움직임 줄이기 설정 시 애니메이션은 생략한다.
- 시간 효과 OFF: 주간 밝기, 정각 종소리·전환 알림 중지. 날씨와 시계는 유지한다.
- 확대 보기: 게임 영역을 Fullscreen API로 확대하며 Esc / 전체화면 나가기로 복귀. 미지원 환경에서는 이를 안내하고 창 전체 보기로 대체한다. 맵 비율과 조작 버튼을 유지하고 배치 오브젝트 목록은 전체화면에서 숨긴다.
- 검증: `node --test tests/forest-atmosphere.test.cjs`, `pytest tests/test_forest_weather.py tests/test_carrot_forest_pixel_game.py -q`.
