# 프론트엔드 공통 디자인 시스템 리팩터링 요청

현재 프론트엔드의 홈·챌린지·리포트·함께하기·건강도구 화면을 하나씩 수정하지 않고, 공통 디자인 시스템을 적용하는 방식으로 정리해 주세요.

## 목표

- 여러 화면에 반복되는 카드·버튼·제목·탭·입력창을 공통 스타일로 통합
- 공통된 부분은 한 번 수정하면 전체 화면에 반영되도록 구성
- 각 화면의 기능과 목적에 따른 차이는 유지
- 첨부된 Figma 화면의 따뜻한 픽셀 게임 분위기와 현재 간당간당 브랜드를 반영
- 기존 API 연결·사용자 흐름·의료 안전 문구는 변경하지 않음

## 먼저 할 일

1. `src/frontend` 전체를 확인해 반복되는 HTML 구조와 CSS를 찾아주세요.
2. 다음 항목이 화면마다 따로 작성되어 있는지 표로 정리해 주세요.
   - 페이지 전체 레이아웃
   - 콘텐츠 영역의 최대 너비와 여백
   - 카드
   - 제목·본문·보조 문구
   - 주요·보조·위험 버튼
   - 탭과 메뉴
   - 입력창·선택창
   - 상태 배지
   - 안내·경고·오류 박스
   - 모달
3. 각 항목을 다음으로 분류해 주세요.
   - 공통화 가능
   - 화면별 변형 필요
   - 해당 화면에만 유지

분석 결과를 먼저 보여준 다음 실제 수정을 진행해 주세요.

## 구현 방식

현재 프로젝트가 HTML·CSS·JavaScript 기반이면 React나 새로운 UI 프레임워크를 추가하지 마세요.

### 1. 디자인 토큰 정의

색상·여백·모서리·그림자·글자 크기를 CSS 변수로 통합해 주세요.

예시:

```css
:root {
  --color-primary: #237b68;
  --color-primary-dark: #15594b;
  --color-surface: #fffaf0;
  --color-surface-soft: #f5efe2;
  --color-text: #212529;
  --color-muted: #68706a;
  --color-warning: #fff4d6;
  --color-danger: #b84a4a;

  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-6: 24px;
  --space-8: 32px;

  --radius-sm: 8px;
  --radius-md: 14px;
  --radius-lg: 20px;

  --shadow-card: 0 8px 24px rgb(52 42 24 / 12%);
  --content-max-width: 1200px;
}
```

기존 프로젝트의 색상을 먼저 조사하고 실제 값에 맞게 조정하세요.

### 2. 공통 클래스 생성

다음과 같은 공통 클래스를 만들고 기존 화면에 적용해 주세요.

```text
.app-shell
.page-container
.page-header
.content-grid
.ui-card
.ui-card--compact
.ui-card--highlight
.ui-card--warning
.ui-button
.ui-button--primary
.ui-button--secondary
.ui-button--danger
.ui-badge
.ui-notice
.ui-form-field
.ui-modal
```

모든 카드를 완전히 똑같게 만들지 말고, 기본 카드에 화면별 modifier를 추가하는 방식으로 구현해 주세요.

예시:

```html
<section class="ui-card challenge-card"></section>
<section class="ui-card report-card"></section>
<section class="ui-card together-card"></section>
```

### 3. 공통 화면 틀 적용

홈·챌린지·리포트·함께하기·건강도구에 다음 공통 구조를 적용해 주세요.

```html
<main class="app-shell">
  <div class="page-container">
    <header class="page-header"></header>
    <section class="page-content"></section>
  </div>
</main>
```

- 헤더와 메뉴 위치 통일
- 콘텐츠 시작 위치 통일
- 페이지별 최대 너비 통일
- 카드 사이 간격 통일
- 모바일·태블릿·데스크톱 반응형 적용

## 중요한 디자인 원칙

- 첨부 화면처럼 배경 일러스트 위에 콘텐츠를 배치할 때는 화면 중앙을 무조건 비우지 말고, 콘텐츠 가독성과 시선 흐름을 기준으로 배치
- 배경 위 카드에는 반투명 처리보다 충분한 명암 대비를 우선 적용
- 카드 크기를 고정 픽셀로만 지정하지 말고 `max-width`, `min()`, `clamp()`를 사용
- 화면이 넓어져도 카드가 과도하게 커지지 않도록 제한
- 글자 확대 기능을 사용해도 카드와 버튼이 깨지지 않도록 구성
- 모바일에서는 한 열, 넓은 화면에서는 필요한 경우 두 열로 표시
- 색상만으로 위험 상태를 구분하지 말고 글자·아이콘을 함께 사용

## 유지해야 하는 화면별 차이

- 홈: 전체 기능 요약과 오늘 할 일 중심
- 챌린지: 선택·수행·인증 행동 중심
- 리포트: 수치·그래프·기간 선택 중심
- 함께하기: 그룹·초대·공동 진행률 중심
- 건강도구: 건강교육·퀴즈·의료기관 안내 중심
- 당근의 숲: 픽셀 게임 Canvas와 게임 HUD 중심

공통 디자인을 적용하되 기능적 차이를 없애지 마세요.

## 작업 순서

1. 현재 중복 스타일과 구조 조사
2. 디자인 토큰 작성
3. 공통 클래스 작성
4. 대표 화면 1개에 시범 적용
5. 기존 화면과 시각 비교
6. 문제가 없으면 나머지 화면에 순차 적용
7. 사용하지 않는 중복 CSS 제거
8. 전체 테스트와 화면 캡처 수행

## 검증 기준

- 홈·챌린지·리포트·함께하기·건강도구가 동일한 디자인 언어를 사용하는가?
- 각 화면의 기능적 차이는 유지되는가?
- 360px, 768px, 1440px 화면에서 레이아웃이 깨지지 않는가?
- 글자 크게 기능에서 잘림이나 겹침이 없는가?
- 키보드 포커스와 명암비가 유지되는가?
- 기존 버튼 ID·이벤트·API 호출이 유지되는가?
- 의료 안전 문구가 삭제되거나 축약되지 않았는가?
- 기존 프론트 테스트와 전체 테스트가 통과하는가?

## 산출물

- 중복 UI 조사표
- 디자인 토큰과 공통 클래스
- 변경한 파일 목록
- 화면별 적용 전·후 캡처
- 유지한 화면별 차이
- 테스트 결과
- 아직 공통화하지 않은 영역과 이유

별도의 대규모 재작성은 하지 말고, 기존 기능을 보존하면서 작은 단위로 리팩터링해 주세요. 우선 분석과 공통화 설계를 보여주고, 확인을 받은 뒤 코드 수정에 들어가 주세요.
