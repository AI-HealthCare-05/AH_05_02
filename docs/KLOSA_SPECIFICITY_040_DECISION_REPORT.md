# KLoSA Recall 우선 모델의 Specificity 0.40 기준 검토

## 결론

- `Specificity ≥ 0.40`을 정답처럼 보장하는 보편적인 의학·통계 기준은 없다.
- 본 프로젝트에서는 이를 **위양성률(FPR)을 0.60 이하로 제한하면서 Recall을 최대화하는 개발 단계의 운영 제약**으로 정의할 수 있다.
- 이 제약은 모든 사람을 양성으로 분류해 Recall 1.0을 만드는 퇴행적 해법을 막지만, 음성 1,000명당 약 600명의 오경보를 허용하므로 단독으로 충분한 서비스 승인 기준은 아니다.
- 테스트 점추정치가 0.40을 넘는 것만으로는 부족하다. 사전 고정한 독립 평가에서 Specificity의 **단측 95% 신뢰하한이 0.40 이상**인지 확인하는 방식이 더 타당하다.
- 이번 실험의 0.40 정책은 점추정치 `0.4022`였으나 단측 95% 하한이 `0.3850`이므로 통계적으로 0.40을 안정적으로 보장했다고 볼 수 없다.
- 검증 세트 목표에 완충치를 둔 `0.41~0.42 정책`은 테스트 Specificity `0.4193`, 단측 95% 하한 `0.4011~0.4023`, Recall `0.7846`이었다. 다만 여러 정책을 본 뒤 고른 탐색 결과이므로, 이 정책을 동결하고 새로운 외부·시간 분리 표본에서 재확인해야 한다.

## 1. 0.40의 이론적 위치

| 항목 | 해석 |
| --- | --- |
| Specificity | 실제 비발병자 중 음성으로 올바르게 분류한 비율 `TN / (TN + FP)` |
| Specificity 0.40 | 비발병자 40%를 음성으로 거르고 60%는 경고 대상으로 분류 |
| FPR | `1 - Specificity`; 본 기준에서는 최대 0.60 |
| Neyman–Pearson형 제약 | `FPR ≤ 0.60`을 만족하는 임계값 중 Recall이 가장 높은 값을 선택 |
| 퇴행 방지 | 전원을 양성으로 예측하면 Specificity가 0이므로 기준 미달 |
| 한계 | 0.40이라는 숫자 자체는 통계 이론이 정하지 않으며 서비스 비용·후속 확인 역량·위해성으로 정해야 함 |

Neyman–Pearson 분류는 한 종류의 오류를 미리 정한 수준으로 제어하면서 다른 성능을 최적화하는 틀을 제공한다. 따라서 본 프로젝트의 방식은 통계적으로 설명 가능한 **제약 최적화**이지만, 허용 수준 `0.40`은 팀이 운영 목적에 맞게 정한 값이다.

## 2. 0.40을 개발 단계 하한으로 사용할 수 있는 조건

1. 결과를 진단·처방이 아니라 **추가 건강 확인을 권하는 저위해성 위험 선별**로만 사용한다.
2. Recall을 최우선으로 하되 `AUPRC`, `Specificity`, 혼동행렬, 예측 양성률을 함께 공개한다.
3. 음성 1,000명당 약 600건의 오경보를 후속 안내가 감당할 수 있는지 확인한다.
4. 임계값은 검증 세트 또는 OOF 예측에서만 정하고 테스트 세트에서 조정하지 않는다.
5. 독립 평가에서 Specificity의 신뢰구간을 보고한다.
6. 모델의 순편익은 `모두 안내`, `아무도 안내하지 않음` 전략과 Decision Curve Analysis로 비교한다.

## 3. 재실험 설계

- 대상: t0 당뇨 미진단자의 다음 인접 조사 신규 당뇨 진단
- 분할: 참여자 ID 기준 Train/Validation/Test 분리
- 입력 비교:
  - 기본 8개: 나이, BMI, 주관적 건강, 전일 식사 횟수, 성별, 규칙적 운동, 현재 흡연, 현재 음주
  - 확장 16개: 기본 8개 + t0까지 확인된 고혈압·암·만성폐질환·간질환·심장질환·뇌혈관질환·정신과질환·관절염 이력
- 제외: 당뇨 진단, 미래 차수 정보, 치료·투약, 진단 시기, 만성질환 합계
- 모델: Logistic Regression, Random Forest, XGBoost, 동일 가중 Soft Voting
- 임계값: Validation에서만 Specificity 목표 `0.40~0.55`별 선택
- 불확실성: 참여자 단위 1,000회 군집 부트스트랩

## 5. 권고안

- **개발 비교 기준:** `Specificity ≥ 0.40`을 유지하되 `Recall만 높이는 모델 방지용 최소 제약`이라고 명시한다.
- **다음 검증 후보:** XGBoost 기본 8개, Validation 최소 Specificity `0.42` 정책을 동결한다.
- **승격 조건:** 새 독립 표본에서 Specificity 단측 95% 하한 `≥ 0.40`, Recall·AUPRC·Brier/보정·연령군별 성능·Decision Curve를 함께 충족해야 한다.
- **서비스 제한:** 현재 후보는 정밀도가 약 3.3%로 매우 낮으므로 개인의 미래 발병확률이나 진단 결과로 노출하지 않는다. 개발용 위험 선별 후보로만 유지한다.
- **개선 방향:** 표본 확대보다 먼저 라벨 품질, 신규진단 시점, 조사 간격, 누수 없는 시간가변 변수, 결측 구조를 재검토하고 외부·시간 분리 검증을 수행한다.
