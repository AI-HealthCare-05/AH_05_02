## 회원가입 안내판 확대

- 8023 회원가입 안내판을 큰 화면에서 최대 1360px로 확대. 입력칸·글씨·동의 카드도 확대하며 배경 이미지는 유지.
- 작은 화면은 기존 세로 배치 유지. 높이는 콘텐츠에 따라 늘어나며 페이지 스크롤 가능.
- 로그인 안내판도 추가 요청에 따라 회원가입과 같은 최대 1360px 폭으로 확대. 이메일·비밀번호 입력칸, 라벨, 로그인 버튼 확대. 높이는 두 입력 항목에 맞춰 조정.
- `tests/frontend/signup_board_layout.cjs`: 3066/1440/390px에서 가로 잘림, 로그인/회원가입 폭 일치 및 비밀번호 보기·숨기기 확인. 실제 가입·로그인 요청은 보내지 않음.
- 이용대상 확인 안내판도 왼쪽 영역에서 최대 1320px로 확대. 질문·입력·선택 버튼을 함께 확대하고 오른쪽 집 배경 및 적합성 판단 로직은 유지. 같은 브라우저 검사에서 예/아니요 선택과 안전 문진 팝업 열기 확인.
- 건강정보 입력 안내판은 1200px 이상 화면에서 최대 1600px로 확대하고 왼쪽 여백 확보. 8개 선택 버튼·입력 카드·글씨·CTA 확대.
- 입력사항 확인 안내판도 별도 요청에 따라 최대 1480px로 확대. 기본정보·생활습관 3열, 세부 건강정보 4열과 기존 표시 순서를 유지하며 카드·글씨 확대. 큰 화면의 수정/분석 버튼은 한 줄로 배치하고 작은 화면은 기존 세로 배치 유지.
- `tests/frontend/health_board_layout.cjs`: 3022/1440/390px에서 건강정보 8개 패널과 확인 화면의 안내판 경계·가로 넘침 검사 통과. 음주 화면 시각 확인 완료.
