# 가용 공간을 채우는 게임 레이아웃 — v157

2026-09-08

## 배율과 렌더링

- 이전 50%가 새 100% 기본값이다. 기존 사용 가능 범위를 그대로 환산해 100–400%, 50%포인트 간격으로 표시한다. 기존 3:2 창에서 새 100%는 전체 768×512 월드를 보여준다.
- 창 비율이 달라지면 `max(viewportWidth / 768, viewportHeight / 512)`의 단일 배율로 채우고 남는 축만 카메라 경계에서 잘라낸다. 아바타를 따라가되 빈 월드 가장자리를 드러내지 않는다. 좌표·충돌·이동 속도·자산 크기는 변경하지 않는다.
- Phaser `Scale.NONE`과 명시적 backing resize를 사용한다. 기본 2배 해상도, 긴 변 4096px 제한으로 초대형 창의 GPU 사용을 제한한다. 캔버스 크기 변경 후 카메라 크기·중심·포인터 역변환·닉네임 위치를 즉시 갱신한다.
- 처음에는 Phaser 영역이 숨겨져 있으므로 이미 배치된 부모 프레임을 측정한다. 로딩 완료 후에도 다시 측정해 최초 렌더링의 찌그러짐을 방지한다.

## UI 공간 배분

- 데스크톱은 실제 상단 도구 모음 높이를 제외한 남은 화면을 flex로 할당한다. 상단 UI 높이를 62px로 추정해 빼지 않으므로 글자 크기와 창 크기 변화에 따라 자연스럽게 맞는다.
- 좌우 HUD는 같은 너비를 유지하고, 중앙은 날씨 UI를 제외한 가로·세로 공간을 모두 사용한다. 하단 채팅 열에는 60px와 기기의 안전 영역을 남겨 조작 버튼 위에 겹치지 않게 한다.
- `.canvas-workarea`의 실제 내용 영역이 크기 계약이다. `.canvas-frame`과 `#phaser-world`가 같은 영역을 채우며, 고정 3:2 비율·1536px 최대 너비·가로폭 기반 높이를 적용하지 않는다. 프레임에 테두리·패딩을 넣지 않아 Phaser의 측정 영역과 표시 영역이 일치한다.
- Phaser는 그 크기에 맞춰 backing buffer와 카메라를 조정한다. CSS로 기존 3:2 그림을 늘리는 방식이 아니다. 예외적인 구형 canvas 대체 화면에는 `object-fit: contain`을 적용해 왜곡을 막는다.
- 900px 이하에서는 중앙 게임 화면이 첫 화면의 가용 높이를 채우며, 기존 HUD 두 패널은 아래로 스크롤해 접근한다. 520px 이하에서는 두 패널을 한 열로 배치한다. 고정 `74vw` 높이를 쓰지 않는다.
- 게임 위에서 휠을 내려도 아래 패널로 이동한다. 터치 사용자는 하단 `옷장·창고 ↓` 바로가기를 사용할 수 있어 게임 터치 조작을 변경하지 않는다. 내부 패널을 스크롤할 때도 클릭 좌표의 원점을 갱신한다.
- 요소 전체화면과 `game-fullscreen`에서도 기존 atmosphere 스타일의 3:2 제한을 덮어쓴다. 컨트롤 패널의 조상 높이가 고정되어 복원 버튼을 가리지 않게 한다.
- v156의 `버튼 숨기기(8) | 초기화(9) | UI 숨기기(0)` 동일 크기 행과 숨김/복원 동작은 그대로다. UI 숨김 시 기존 좌우 HUD·날씨 자리도 유지한다.

## 검증

- 카메라 테스트는 3:2·정사각형·세로형·울트라와이드·4K/8K 크기, 초기 숨김 상태, backing 제한, 줌·좌표·닉네임·포인터 역변환을 검사한다.
- 실제 브라우저 1920×1080: 좌우 HUD 각236px, 게임1384×894px, backing2768×1788px. 확대150%에서도 프레임 크기 동일.
- 실제 브라우저390×844: 게임364×664px, backing728×1328px. 첫 화면 전체 높이 활용, 휠로 옷장까지 이동 확인. 크기 변경 후 클릭 이동도 화면 위치와 일치.
- CSS 계약 검사: `node --test tests/forest-responsive-layout.test.cjs`. 전체 `tests/forest-*.test.cjs` 및 `pytest tests/test_carrot_forest_pixel_game.py -q` 실행.
- 전체 Node 155개 및 Python 56개 통과 후, 터치 바로가기의 내부 스크롤 회귀 검사를 추가했다. 변경된 HUD·레이아웃·서비스워커 검사 32개와 Python 56개 재통과(최종 Node 검사 수156개). 모바일 바로가기 클릭 후 상단바 y=0, 패널 y=66으로 외부 문서가 움직이지 않음을 확인했다.
- 아바타 코디·창고·배치 기록·모닥불·분수·가구 자산은 수정하지 않는다. 오프라인 셸 버전과 HTML 자산 버전을 함께 갱신한다.
