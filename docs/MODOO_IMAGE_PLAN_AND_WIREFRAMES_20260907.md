## 1. 1차 신청서에서 유지할 것과 바꿀 것

1차 신청서에는 발표 사진과 캐릭터·설명 문구를 결합한 이미지, 시니어 교육 현장 사진, 앱 화면 합성, 확장 비전, 당시 6인 팀 이미지가 있습니다. 현장 활동의 실재성과 화면으로 설명하려는 방식은 유지합니다. 다만 사진·작은 인셋·캐릭터·긴 문구가 겹쳐 축소했을 때 읽기 어려웠으므로, 이번에는 한 장에 전달할 결론을 하나로 정합니다.

1차에서 비어 있던 Q3-2 수익구조와 Q4-2 멘토 요청은 이번 원고에서 구체화되었습니다. 이미지는 구매자·단가·제공 범위·유료 실증 계획을 먼저 설명해야 합니다. 이에 따라 제작 우선순위는 **06 수익모델 → 07 기관 상품·원가 → 02 세 모델 → 03 사용 흐름 → 08 실증 계획 → 나머지**입니다. 최종 배치는 01~10 순서를 유지합니다.

이전 6인 팀 사진을 현재 4인 개발팀 사진처럼 재사용하지 않습니다. 바로+ 앱 화면과 캐릭터도 현재 간당간당의 구현 화면인 것처럼 사용하지 않습니다. 사진 원본을 확보할 수 있다면 PDF에 들어간 작은 이미지를 확대하기보다 원본을 사용합니다.

## 3. 공통 제작 규칙

- 편집 원본은 **1920×1200px, 가로 8:5**를 권장합니다. 이는 제작 기준이며 접수 포털 규격을 확인한 결과가 아닙니다. 업로드 전 확장자·용량·장수 제한을 확인하고 필요한 크기로 내보냅니다.
- 최종 이미지에는 상단 제목, 중앙 핵심 시각물, 하단 설명·출처를 둡니다. 바깥 여백은 80px 이상 확보하고 긴 본문은 이미지 아래 노션 캡션에 둡니다.
- 사진은 01·10에 집중합니다. 02~09는 텍스트와 도형을 편집 가능한 상태로 제작한 뒤 PNG로 내보냅니다. 한국어 문장·가격표·성능 수치는 디자인 도구에서 직접 입력하고 검수합니다.
- 본문 글꼴은 읽기 쉬운 고딕체 한 종류를 사용합니다. 픽셀 글꼴은 게임 이름이나 짧은 장식에만 사용합니다. 흰색 또는 옅은 크림색 배경, 진한 글자, 동일한 강조색을 유지합니다.
- 모델 카드에는 항상 **오늘이·내일이·모레**를 씁니다. 오늘이·내일이의 재현율 수치는 ‘내부 탐색적 평가’와 함께 표시하고, 모레의 18년은 ‘설계 범위’로 표시합니다. 재현율을 정확도나 예방 효과로 바꾸지 않습니다.
- 앱 와이어프레임에는 ‘화면 설계안’, 계약 단가·원가에는 ‘가격·원가 가정’, 일정·전환·참여율에는 ‘실증 목표’를 표시합니다. 실제 계약·이용자 증가·질환 예방 효과를 확보한 것처럼 표현하지 않습니다.
- 기관 대시보드에는 개인 건강정보 대신 모임 운영에 필요한 집계 항목을 배치합니다. 가상 수치를 넣을 경우 화면 상단에 ‘예시 데이터’를 표시하고 실제 실증 성과와 같은 색·위치로 강조하지 않습니다.
- 아래 영역 비율은 전체 캔버스 면적에 대한 편집 기준입니다. 원본 사진 비율에 따라 조정할 수 있으나 제목과 여백을 줄여 내용을 억지로 넣지 않습니다.

### 축소 가독성 확인

이미지를 실제 노션 본문 폭과 **스마트폰 가로 390px** 화면에 배치해 확인합니다. 1920px 원본을 390px로 줄이면 글자도 약 20.3% 크기가 됩니다. 원본 72px 글자는 약 14.6px, 88px 글자는 약 17.9px로 보입니다. 제목·핵심 숫자·단계명은 이 수준을 출발점으로 잡고 실제로 읽어봅니다.

스마트폰에서 제목, 중앙 결론, 계획·가정 표시가 확대 없이 읽혀야 합니다. 세부 출처와 긴 조건은 이미지 하단의 작은 글씨에만 의존하지 않고 캡션에도 적습니다. 읽기 어려운 장은 문구를 줄이고 상세 조건을 캡션으로 옮깁니다. 캡션 없이 작은 글자로 모두 넣는 방식은 피합니다.

## 01. 현장 경험에서 문제 정의까지

**배치:** Q2의 국내 문헌 조사와 ‘가입·기록·실천 단계의 어려움’ 설명 뒤, 서비스 구상 문단 앞.  
**제목:** 봉사 현장의 질문을 당뇨 예방 서비스로 구체화했습니다  
**메시지:** 실제 현장 경험을 팀 논의와 문헌 조사로 검토해, 서비스로 지원할 문제를 정했습니다.

**영역:** 제목 12% / 실제 교육 사진 25% / 조사·논의 흐름 35% / 문제 정의 18% / 출처·캡션 표시 10%.

```text
┌──────────────────────────────────────┐
│ 봉사 현장의 질문을 서비스 문제로 구체화 │
├──────────────┬───────────────────────┤
│ 실제 교육사진 │ 현장 경험 → 팀 논의    │
│ 원본 1장 중심 │            ↓          │
│ 활동명·시기   │ 기사·국내 문헌 조사    │
├──────────────┴───────────────────────┤
│ 정보 이해 / 가입·기록 / 지속적인 실천  │
├──────────────────────────────────────┤
│ 사진 설명 · 기사와 논문 출처           │
└──────────────────────────────────────┘
```

**제작 방법·필요 원본:** 1차 교육 사진에서 현장 활동이 분명한 원본 1장을 중심으로 사용하고 추가 사진은 최대 1장만 둡니다. 사진 위에 캐릭터나 작은 화면을 겹치지 않습니다. ‘시니어스마트데이’, ‘청춘어람’ 등 활동명은 사진의 실제 촬영 맥락과 일치할 때만 씁니다. 오른쪽에는 MBC의 2025년 당뇨병 전단계 보도와 2026년 사고 보도를 짧은 출처 카드로 두고, 국내 논문은 ‘건강정보 이해·이용과 사회경제적 여건’으로 묶습니다. 기사 영상 장면을 크게 복제하거나 사고 사진을 중심 소재로 쓰지 않습니다.

**캡션:** 교육 현장에서 발견한 디지털 이용의 어려움을 PM·개발자들과 논의하고, 기사와 국내 문헌을 검토해 건강정보 이해·가입과 기록·지속적인 실천을 지원할 과제로 정했습니다. 사고 보도는 문제를 살펴본 계기이며, 서비스의 범위는 일상적인 생활습관 실천 지원입니다.

## 02. 오늘이·내일이·모레 비교

**배치:** Q3-1의 세 모델 설명과 성능·적용 범위 문단 뒤.  
**제목:** 현재·2년 후·장기 위험을 살피는 세 모델  
**메시지:** 세 모델은 서로 다른 데이터 구조와 시간 범위를 담당합니다.

**영역:** 제목 12% / 3개 모델 카드 66% / 시간축 10% / 평가 범위 설명 12%.

```text

│ 현재·2년 후·장기 위험을 살피는 세 모델 │
├────────────┬────────────┬────────────┤
│ 오늘이     │ 내일이     │ 모레       │
│ 국민건강   │ 고령화연구 │ 같은 종단  │
│ 영양조사   │ 패널       │ 자료 재구성│
│ 횡단자료   │ 종단자료   │ 이산형 생존│
│ 현재 선별  │ 2년 뒤     │ 2년 단위   │
│ Recall     │ Recall     │ 최대 18년  │
│ 93.8%      │ 약 84%     │ 설계 범위  │
├────────────┴────────────┴────────────┤
│ 현재           2년       …       18년│
```

**제작 방법·필요 원본:** 세 카드의 데이터·방법·시간·결과 위치를 동일하게 맞춥니다. 수치 근거로 모델 평가표나 실험 결과 원본을 준비합니다. 현재 수치를 사용할 때 평가집단·분할방식·지표명과 일치하는지 확인합니다. 모레는 검증된 생존곡선이 없는 상태에서 임의의 위험 곡선을 결과처럼 그리지 않고, 2·4·6·…·18년의 계산 구간만 보여줍니다.

**캡션:** 오늘이는 국민건강영양조사 횡단자료로 현재 위험을 선별하며 내부 탐색적 평가 재현율은 93.8%입니다. 내일이는 고령화연구패널 종단자료로 약 2년 뒤 신규 당뇨병 또는 고혈당 의사진단 보고를 예측하며 재현율은 약 84%입니다. 모레는 같은 종단자료를 재구성한 이산형 생존모형으로, 2년 단위 최대 18년의 누적 발병 위험을 전망하도록 설계했습니다. 재현율과 설계 기간은 서로 다른 개념이며 임상적 예방 효과를 뜻하지 않습니다.

## 03. 결과 확인·선택·기록 화면

**배치:** Q3-1의 ‘당근의 숲’ 이용 흐름 설명 뒤.  
**제목:** 위험 결과를 확인한 뒤 실천을 선택하고 기록합니다  
**메시지:** 분석 결과를 읽는 데서 끝나지 않고, 이용자가 다음에 수행할 행동을 보여줍니다.

**영역:** 제목 12% / 휴대전화 화면 3개 66% / 단계 연결·선택 경로 12% / 설계안 표시·캡션 10%.

```text
│ ① 나의 정보│ ② 챌린지  │ ③ 오늘 기록│
```

**제작 방법·필요 원본:** 실제 구현 화면이 확인되면 해당 화면에 ‘현재 구현 화면’을 표시해 사용합니다. 미구현 기능은 회색 와이어프레임으로 그리고 ‘화면 설계안’을 유지합니다. 개인 위험률은 임의로 만들지 않고 ‘결과 표시 영역’으로 둡니다. 각 화면의 대표 버튼은 하나만 강조합니다. ‘예측 없이 참여’ 경로를 화면 아래에서 ②로 연결합니다. 상세 결과 공유는 기본 동작으로 넣지 않습니다.

**캡션:** 화면 설계안입니다. 이용자는 모델 결과를 확인하거나 예측 단계를 건너뛴 뒤 생활습관 챌린지를 선택하고, 오늘의 완료 여부를 기록합니다. 기록은 공동 숲의 성장에 반영되도록 기획했습니다.

**제작 방법·필요 원본:** 현재 네 명의 사진이 있으면 같은 크기로 사용하고, 없으면 이름·경험·담당 산출물이 적힌 명함형 카드로 제작합니다. 이전 6인 팀 사진을 현재 팀 증빙으로 사용하지 않습니다. 정세준은 교육 운영·기획과 기관 실증, 양준혁은 데이터·모델 평가, 박빛샘은 권한·기록·기관 운영 API, 이수인은 가입·초대·기록 화면을 담당하도록 표시합니다. 기존 교육·발표·수상 사진은 실제 확인 가능한 원본 2장 이내로 하단에 모으고 활동명·수상명을 정확히 붙입니다. 당뇨 서비스로 받은 수상처럼 배치하지 않습니다.

**캡션:** 현재 간당간당 팀은 대표 정세준과 팀원 양준혁·박빛샘·이수인, 총 4명입니다. 약 5년·4,000시간 이상의 교육 운영과 발표·수상 자료는 대표의 기존 활동 경력을 설명하는 증빙입니다. 현재 사업의 기관 계약이나 임상 성과를 뜻하지 않습니다.
