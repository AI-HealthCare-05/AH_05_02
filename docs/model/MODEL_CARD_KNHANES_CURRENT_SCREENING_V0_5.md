# KNHANES 현재 당뇨 위험 신호 선별 모델 카드 v0.5

## 1. 목적

- 국민건강영양조사(KNHANES)를 이용해 당뇨병을 진단받지 않았다고 응답한 만 19세 이상 성인 중 현재 임상 당뇨 기준에 해당할 가능성이 높은 사람을 선별한다.
- 이 결과는 **현재 위험 신호 선별 보조값**이며 당뇨병 확진, 향후 발병확률 또는 치료 지시가 아니다.
- KLoSA의 약 2년 후 신규 당뇨 진단 모델은 별도 유지한다. 두 점수를 평균하거나 하나의 개인 발병확률로 합치지 않는다.

## 2. 데이터와 분할

| 구분 | 조사연도 | N | 양성 | 양성률 |
|---|---|---:|---:|---:|
| Train | 2016–2020 | 26,005 | 1,140 | 4.38% |
| Validation | 2021–2022 | 9,132 | 415 | 4.54% |
| Test | 2023–2024 | 9,691 | 390 | 4.02% |

- 원본 행은 Git에 포함하지 않는다.
- `fasting_glucose`, `hba1c`, 당뇨 진단·투약, 당뇨 상태 및 타깃은 입력에서 제외했다.
- 학습연도는 조사연도 단위 5-fold OOF를 사용했다.
- 결측 대치·범주 인코딩·스케일링은 각 학습 fold 안에서만 적합했다.
- 국민건강영양조사 조사 가중치는 학습과 가중 민감도 평가에 사용했다.

## 3. 모델 선택

- 후보: Logistic Regression 3종, Random Forest 3종, Extra Trees 2종, LightGBM 4종
- OOF에서 모델군별 우승 후보를 선정했다.
- 검증자료에서 모델군 확률 혼합 가중치를 0.1 간격으로 비교했다.
- 선택 순서: `Recall → AUPRC → Specificity`
- Test 특이도 목표 0.40에 대해 Validation 특이도 0.42를 안전 여유로 사용했다.
- 최종 혼합: **Logistic Regression 70% + Random Forest 30%**
- Platt 보정 후 검증자료에서 임계값 `0.023227179`를 고정했다.

## 4. 최종 성능

| 지표 | Validation | Test | Test 조사 가중 |
|---|---:|---:|---:|
| AUROC | 0.7868 | 0.7673 | 0.7880 |
| AUPRC | 0.1465 | 0.1122 | 0.1105 |
| AUPRC/유병률 | 3.22배 | 2.79배 | 3.00배 |
| Recall | 0.9614 | **0.9308** | **0.9242** |
| Specificity | 0.4201 | **0.4067** | **0.4555** |
| Precision | 0.0732 | 0.0617 | 0.0609 |
| Brier | 0.04116 | 0.03765 | 0.03436 |
| Brier Skill Score | +0.0512 | +0.0253 | +0.0304 |

Test 혼동행렬은 TN 3,783, FP 5,518, FN 27, TP 363이다. Recall 중심 선별 모델이므로 거짓 양성이 많으며, 양성 플래그는 검사 권고나 건강교육 안내의 근거로만 사용한다.

## 5. 연령별 한계

| 연령 | N/양성 | Recall | Specificity | AUPRC |
|---|---:|---:|---:|---:|
| 19–44세 | 3,358/45 | 0.844 | 0.730 | 0.085 |
| 45–64세 | 3,702/169 | 0.917 | 0.321 | 0.115 |
| 65세 이상 | 2,631/176 | 0.966 | 0.094 | 0.122 |

전역 임계값은 전체 Test 특이도 0.40을 통과하지만 고령층에서 거짓 양성이 지나치게 많다. 따라서 이 버전은 내부 후보이며, 65세 이상 사용자에게 이진 플래그를 직접 표시하지 않는다. 연령별 임계값은 별도의 사전등록 검증을 거쳐야 한다.

## 6. KLoSA 보조지표 사용 방식

| KNHANES 현재 신호 | KLoSA 미래 위험 | 서비스 해석 |
|---|---|---|
| 낮음 | 낮음 | 일반 생활습관 유지 안내 |
| 높음 | 낮음 | 현재 검사 확인 권고; 미래 위험이 낮다는 이유로 무시하지 않음 |
| 낮음 | 높음 | 장기 생활습관 챌린지와 추적 안내 |
| 높음 | 높음 | 검사 확인과 생활습관 관리 모두 우선 안내 |

- 서로 다른 조사 대상·타깃으로 학습했기 때문에 확률을 더하거나 평균하지 않는다.
- KNHANES 점수를 KLoSA 입력 변수로 넣지 않는다. 이를 하려면 동일 대상자에서 현재 신호와 미래 발병을 함께 관찰한 별도 자료가 필요하다.
- 사용자 화면에서는 `현재 위험 신호`와 `약 2년 후 위험`을 다른 축과 다른 문구로 표시한다.

## 7. 상태

`candidate_internal_not_for_diagnosis_or_personal_probability_display`

현재는 개발·비교·데모용 후보이다. 외부검증, 연령별 임계값 검증, 의료 문구 검토와 모델 승인 전에는 개인 확률로 노출하지 않는다.

## 8. 재현

```bash
python -m src.ml.modeling.knhanes_current_screening
python -m pytest tests/ml/test_knhanes_current_screening.py -q
```
