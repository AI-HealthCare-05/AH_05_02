# KLoSA R/S 균형 상위 5개 클래스 가중치 비교

- 실행일: 2026-08-24
- 상태: 연구 비교용, 운영 모델 미변경
- 대상: 동일 전체 코호트 R/S 균형 상위 5개
- 분할: 동일 PID 70/15/15
- 임계값: 각 가중치 변형마다 validation Recall 0.80 기준으로 재선택

## 가중치

Train은 양성 910건, 음성 35,394건이며 음성:양성 비율은 38.8945:1이다.

- Random Forest `balanced`: 음성 약 0.513, 양성 약 19.947의 자동 클래스 가중치
- Random Forest `balanced_subsample`: 각 bootstrap 표본에서 같은 공식을 다시 계산
- XGBoost `balanced_ratio`: `scale_pos_weight=38.8945`
- Logistic `balanced`: Random Forest `balanced`와 같은 자동 클래스 가중치 공식

가중치를 적용하면 점수 분포가 달라지므로 비가중 임계값을 재사용하지 않았다. 모든 변형의 임계값을 validation에서 독립적으로 선택했다.

## 재현 전처리 기준

| 구분 | 고정 기준 |
| --- | --- |
| 코호트 단위 | KLoSA 1→2차부터 9→10차까지의 person-period |
| 대상자 | t0 당뇨병 미진단(`5`)이며 t1 진단 상태가 `1` 또는 `5`인 관측 |
| 예측 목표 | 다음 조사 시점의 신규 당뇨병 의사진단 여부 |
| 입력 시점 | 결과를 알 수 없는 t0 변수만 사용하며 PID·t1 진단·표적 변수는 입력에서 차단 |
| 특수 결측 | 음수 응답 코드는 결측으로 변환하고, 알 수 없는 값을 비진단으로 치환하지 않음 |
| 범위 처리 | 키 120~220cm, 체중 25~250kg, 만족도 0~100, ADL 0~7, IADL 0~10, 악력 1~80kg 밖은 결측 |
| 파생 변수 | BMI는 유효 키·체중으로 계산, 가구소득은 음수가 아닌 값에 `log1p` 적용 |
| 데이터 분할 | PID 기준 70/15/15, PID의 전체 기간 사건 여부로 층화, `random_state=42`, 분할 간 PID 중복 0 |
| 수치형 | train 중앙값 대치와 결측 indicator; Logistic에만 train 기준 표준화 |
| 범주형 | train 최빈값 대치 후 one-hot, 미관측 범주는 무시 |
| 임계값 | validation Recall 0.80 이상 제약에서 Specificity를 최대화; test는 최종 보고에만 사용 |
| 확률 보정 | 적용하지 않음 |

전처리는 scikit-learn `Pipeline` 안에서 모델과 함께 적합하므로 중앙값, 최빈값, one-hot 범주와 표준화 통계가 validation/test에 의해 학습되지 않는다. 코호트 생성 단계의 범위 검사와 결정적 파생은 개인별 t0 값에만 적용하며 전체 표본 통계를 사용하지 않는다.

## 비가중 대비 변화

| 단계·모델 | 가중치 | ΔRecall | ΔSpecificity | ΔR/S 균형 |
| --- | --- | ---: | ---: | ---: |
| 3단계 RF | balanced | -0.0462 | -0.0566 | -0.0514 |
| 3단계 RF | balanced_subsample | -0.0410 | -0.0507 | -0.0459 |
| 4단계 RF | balanced | -0.0256 | -0.0445 | -0.0351 |
| 4단계 RF | balanced_subsample | -0.0154 | -0.0502 | -0.0328 |
| 2단계 RF | balanced | -0.0154 | -0.0413 | -0.0283 |
| 2단계 RF | balanced_subsample | -0.0051 | -0.0511 | -0.0281 |
| 4단계 XGBoost | balanced_ratio | -0.0359 | -0.0074 | -0.0216 |
| 4단계 Logistic | balanced | +0.0051 | -0.0087 | -0.0018 |

가중 Logistic만 양성 누락이 44건에서 43건으로 1건 감소했지만 위양성이 4,251건에서 4,318건으로 67건 증가했다. 다른 가중 변형은 Recall과 Specificity가 모두 감소했다.

가중 모델의 임계값은 약 0.40~0.43으로 상승했고 Brier score도 비가중 약 0.024에서 약 0.185~0.230으로 크게 악화됐다. 이는 가중 목적함수의 원시 점수를 실제 발생확률로 해석할 수 없음을 보여주며, 별도 확률 보정 없이는 사용자 위험확률로 표시하면 안 된다.

## 결론

1. 상위 5개 후보 모두 현재 validation 임계값 정책에서는 비가중 변형이 R/S 균형 최상이다.
2. 전체 순위 1위는 비가중 3단계 25개 Random Forest, 임계값 0.02241084를 유지한다.
3. 클래스 가중치는 운영 후보에 적용하지 않는다.
4. 결과는 진단·처방이 아닌 위험 선별·건강교육 연구에만 사용한다.
