# 초기 8변수 모델과 튜닝 RF25: Validation Specificity 0.40 비교

기존 학습 Artifact와 Train 전처리기를 고정하고 재학습 없이 평가했다.
범위는 초기 Logistic/RF/XGBoost 각 가중·무가중 6개와 튜닝 RF25의 기존 관측값/
선택 17개 전부 결측 조건 2개다. KNHANES와 생존 앙상블은 이 비교 대상이 아니다.

- 코호트: KLoSA 다음 차수 신규 의사진단, PID 70/15/15, random_state=42
- Validation: 7,605행·사건 195건; Test: 7,903행·사건 195건
- 임계값: Validation Specificity >=0.40 중 Recall 최대, 동률이면 Specificity 최대
- 모든 임계값을 확정한 다음 Test 평가. Test는 반복 확인된 historical holdout이다.
- 기존 6개 Artifact 체크섬 확인. 기존 임계값의 혼동행렬과 AUROC/AUPRC 재현 확인.
- 단일 스레드 추론으로 경계값 부근 병렬 합산의 부동소수점 변동을 제한했다.
- 결측 조건은 추론 시 선택 17개를 NaN으로 바꾸며 학습된 대치·전처리기를 그대로 사용한다.

## 해석

Validation 제약은 모든 조건이 통과했으나 Test Specificity 0.40은 전부 미달했다.
Validation 제약이 다른 표본의 성능을 보장하지 않는다는 결과이며 Test에서 임계값을
다시 골라 통과시켜서는 안 된다.

필수 입력만 넣은 RF25는 기존 임계값 0.0211536028의 Test R/S 0.6154/0.5616에서
새 임계값의 0.7744/0.3748로 변했다. FN은 75에서 44로 줄었지만 FP는 3,379에서
4,819로 늘었다. AUROC 0.6326, AUPRC 0.0398은 임계값 조정 전후 동일하다.

필수 입력 전용 후보 선택은 Validation 기준으로 8변수 Logistic 무가중이 가장 높다.
Test Recall이 더 높은 RF를 Test 기준으로 새로 선택하지 않는다. 다음 실험은 Train
PID OOF를 통한 임계값 안정성·Specificity 여유 폭 검토 후 독립 평가로 진행한다.
기존 서비스 Manifest나 운영 임계값은 변경하지 않았다. 위험 선별·건강교육 연구 결과다.
