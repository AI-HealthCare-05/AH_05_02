# 오늘이·내일이 모델 경계

| 구분 | 오늘이 | 내일이 |
| --- | --- | --- |
| `model_key` | `diabetes_current_screening` | `diabetes_incidence` |
| 데이터 | KNHANES | KLoSA |
| 목적 | 현재 당뇨 관련 위험 신호 선별 | 약 2년 후 신규 의사진단 위험 선별 |
| 대상 | 만 19세 이상 미진단 성인 | KLoSA 관찰 범위의 기준시점 미진단 성인 |
| 화면 제목 | 현재 위험 신호 | 향후 발병 위험 |
| 결합 | 내일이 점수와 합산 금지 | 오늘이 점수와 합산 금지 |

두 모델은 같은 사용자의 서로 다른 질문에 답한다. 오늘이 결과를 진단으로 표현하지 않고, 내일이
결과를 정확한 발병 시점으로 표현하지 않는다. 프론트엔드는 별도 카드로 표시하고 백엔드는
`prediction_type`과 `model_key`를 모두 저장한다.
