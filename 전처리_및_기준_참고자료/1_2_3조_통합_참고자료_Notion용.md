## 2조 추가 데이터 — KLoSA 1~10차 자료

| 항목 | 내용 |
| --- | --- |
| 데이터명 | 고령화연구패널조사(KLoSA) 1~10차 기본조사 |
| 조사기관 | 한국고용정보원 |
| 조사기간 | 2006~2024년 짝수 연도 기본조사, 총 10차 |
| 최초 조사대상 | 2006년 당시 제주도를 제외한 지역의 일반가구 거주 45세 이상 중·고령자 |
| 조사 성격 | 동일 대상자를 반복 조사하는 종단 패널자료 |
| 주요 영역 | 인구학적 배경, 가족관계, 건강상태, 고용, 소득·소비, 자산, 주관적 기대감, 삶의 질 |
| 제공 형식 | 원자료, 구조변환 자료, 라이트 버전, 설문지, 코드북, 유저가이드 |
| 공식 자료 | [KLoSA 조사개요](https://survey.keis.or.kr/klosa/klosa04.jsp) · [1~10차 자료받기](https://survey.keis.or.kr/klosa/klosadownload/List.jsp) · [유저가이드](https://survey.keis.or.kr/klosa/klosaguide/List.jsp) |

### 프로젝트 활용 방향

- 고령자의 만성질환 보유 여부와 건강·생활습관 변화를 차수별로 추적하는 데 활용할 수 있음.
- 단면자료인 국민건강영양조사와 달리 동일 대상자의 시간 변화와 신규 질환 발생을 분석할 수 있음.
- 고혈압·당뇨·심장질환·뇌혈관질환 등 다중 만성질환 연구와 고령자 확장 모델에 적합함.
- 1~10차를 사용할 경우 `person_id`와 조사 차수·연도를 기준으로 long format을 구성하고, 예측 시점 이후의 정보를 입력 변수로 사용하지 않아야 함.

### 확인 및 결정 필요

- [ ] 1~10차 전체를 사용할지, 최근 차수 또는 특정 시점 구간만 사용할지 결정
- [ ] 서비스 1차 타깃이 40세 이상 전체인지 고령층인지 결정
- [ ] 신규 발병 예측과 현재 보유 질환 분류 중 예측 문제 확정
- [ ] 차수별 변수명과 설문 문항의 동일성 확인
- [ ] 패널 탈락과 결측에 대한 처리 기준 확정
- [ ] 개인 단위로 학습·검증·테스트를 분리해 동일인이 서로 다른 세트에 들어가지 않도록 처리
- [ ] 10차 자료를 사용할 경우 공식 최신 정제본과 코드북 사용

## 8. 전처리 및 데이터 설계 참고

### 확인된 1조 전처리 현황

- 국민건강영양조사 1998~2024년 21개 CSV, 총 251,455행을 연도 정보와 함께 세로 결합함.
- 2016~2024년 자료는 67,019행이며 만 19세 이상 필터 적용 후 55,342행임.
- 추적 정보, 기본 정보, 신체 측정, 혈압·혈액검사, 생활습관·가족력, 영양 변수 등 26개 공통 컬럼으로 정리함.
- `family_history_diabetes=9` 4,052건만 우선 결측 처리함.
- 연속형 측정치의 `66`, `77`, `88`, `99`는 실제 임상 수치일 수 있으므로 코드북 확인 전에는 결측 처리하지 않음.
- 결측률은 대체로 4~12%이며 가족력과 영양 항목이 상대적으로 높음.

## 9. 모델 및 평가 기준

- 베이스라인: Logistic Regression
- 비교 모델: Random Forest, XGBoost, LightGBM
- 설명 가능성: SHAP 기반 주요 위험·보호 요인 표시
- 불균형 데이터 지표: AUROC와 함께 AUPRC, 민감도, 특이도, F1 확인
- 확률 신뢰성: Brier score와 calibration curve 확인
- 공정성 점검: 연령·성별 등 하위집단별 성능 확인
- 결과 표현: 진단·처방이 아니라 위험 선별·건강교육으로 제한

### 확정된 관계와 운영 원칙

- `User 1:N HealthCheckup`: 최초 입력과 재평가를 누적 저장함.
- `HealthCheckup 1:N Prediction`: 같은 검진자료로 모델을 다시 실행할 수 있으며 최신 결과만 대시보드에 표시함.
- `Prediction 1:N RiskFactor`: 예측 1건에 여러 위험·보호 요인을 연결함.
- `User 1:N ChallengeCycle 1:N UserChallenge 1:N ChallengeLog`: 4주 사이클, 선택 챌린지, 일별 기록을 분리함.
- 최초 대비 위험도 변화는 중복 저장하지 않고 조회 시점에 계산하는 방향을 권장함.
- 적합성 재확인에서 기진단이 확인되면 기존 기록을 수정·삭제하지 않고 새로운 부적합 이력을 추가함.
- `FollowUpAction.trigger_source`로 적합성 확인과 예측 결과 중 권고 발생 위치를 구분함.
- 계정정보와 건강정보를 분리하고 건강정보는 별도 동의와 암호화 저장 대상으로 분류함.

### ERD 보완 필요사항

- [ ] `Prediction`에 `checkup_id`, `is_latest` 또는 최신 결과 판정 규칙 명시
- [ ] `waise_cm`을 `waist_cm`으로 수정
- [ ] `users_glucose_lowering_drug`, `referrend_to_medical` 등 컬럼명 오탈자와 명명 규칙 정리
- [ ] 민감정보 암호화 범위, 보관기간, 삭제·철회 정책 정의
- [ ] 건강검진 입력항목을 최종 모델 변수와 일치시키기
- [ ] 개인정보 최소수집 원칙에 따라 사용하지 않는 건강정보 제거

## 2조 와이어프레임용 페르소나 — 이수인

### 페르소나 분류 체계

| 라벨 | 대상 | 와이어프레임에서 확인할 차이 |
| --- | --- | --- |
| A-1 | 건강검진 결과가 있는 미진단 사용자 | 검진 결과 입력·불러오기 후 바로 위험 예측 가능 |
| A-2 | 건강검진 결과가 없는 미진단 사용자 | 설문 중심의 간편 선별과 검진 권고 필요 |
| B-1 | 고령 사용자 | 큰 글씨, 단순한 화면, 쉬운 용어, 입력 부담 감소 필요 |
| C-1 | 2형 당뇨병 미진단 고위험 사용자 | 혈당·HbA1c·가족력·비만·생활습관 중심 결과와 챌린지 필요 |
| C-2 | 고혈압 미진단 고위험 사용자 | 혈압·흡연·음주·활동·체중 중심 결과와 챌린지 필요 |

### 활용 원칙

- A 라벨은 모든 사용자에게 공통되는 서비스 이용 조건으로 계속 발전시킴.
- B 라벨은 연령·접근성 특성을 추가하는 보조 페르소나로 관리함.
- C 라벨은 선택한 질환에 따라 추가하거나 교체할 수 있는 질환별 페르소나로 관리함.
- 최종 페르소나는 `검진자료 보유 여부 × 연령 특성 × 질환 위험`을 조합해 사용함.

### 1차 와이어프레임 기준 제안

- 주 페르소나: **A-1 + C-1**, 건강검진 결과가 있는 40세 이상 2형 당뇨 미진단 고위험 사용자
- 보조 페르소나: **A-2 + C-1**, 검진 결과가 없어 간편 설문과 검진 권고가 필요한 사용자
- 접근성 검토 페르소나: **B-1 + C-1**, 고령층 사용성을 점검하는 사용자

### 페르소나 기반 필수 화면

1. 서비스 소개 및 의료적 한계 안내
2. 회원가입·건강정보 처리 동의
3. 대상자 적합성 확인
4. 검진자료 보유 여부 선택
5. 건강검진·생활습관 입력
6. 질환 위험도와 위험·보호 요인
7. 검사 또는 의료기관 방문 안내
8. 추천 챌린지 선택
9. 일일 챌린지 기록
10. 위험도·생활습관 추적 대시보드

### 추가 작성 필요

- [ ] 각 페르소나의 이름·나이·직업·건강상태·디지털 숙련도
- [ ] 사용 목표, 불편, 서비스 이용 계기
- [ ] 화면별 행동과 이탈 가능 지점
