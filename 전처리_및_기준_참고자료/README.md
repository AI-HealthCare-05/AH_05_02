## 사용 시 주의사항

- 다른 조의 자료를 참고 목적으로 보관한 사본이며, 우리 조의 최종 전처리 기준으로 확정된 문서는 아니다.
- 연도별 국민건강영양조사 공식 코드북을 확보한 뒤 변수 매핑과 무응답 코드를 재검증한다.
- `family_history_diabetes` 원본 매핑이 부·모·형제자매 중 어느 가족력을 뜻하는지 확인하고 `father`, `mother`, `sibling`, `any`로 분리할 수 있다.
- 타깃 확정 후 진단·약물·검사치 등 정답을 직접 결정하는 변수를 입력 특성에서 제외할지 검토한다.
- 학습·검증·테스트 분리 전에 전체 데이터로 결측 대치, 스케일링, 특징 선택을 수행하지 않는다.
- 원본 의료 데이터와 개인정보는 Git에 커밋하지 않는다.
